## 二、客群画像（结论版）

### 2.1 不是一个客群，是三个

| | **P1 审美型** | **P2 考据型** | **P3 教育型** |
|---|---|---|---|
| 买什么 | 金句手机壁纸 ¥19 | 字形线 ¥12/朝、成书稿 | 实体书、字帖、套装 |
| 为什么买 | 好看、有气质、和别人不一样 | 有据、成体系、值得收藏 | 给孩子/学生用，得是好东西 |
| 决策速度 | 冲动（秒级） | 慢（看内容厚度、比对版本） | 中等（看适龄性） |
| 客单价 | ¥12–39 | ¥129–499 | ¥129–499，且愿多买几套 |
| 文案关键词 | 气质、留白、每日一换 | 版本、考据、三千年演变 | 给孩子讲明白、不误人子弟 |
| 阵地 | 小红书、抖音 | 知乎、B 站、豆瓣、公众号 | 小红书（母婴/教育）、家长群、视频号 |

**P3 是被低估的一群**：新手父母与中小学教师为「下一代」付费的心理阈值远高于为自己，
一本书买三套（自己 / 孩子 / 送人）很常见，是实体书众筹的天然买家。
> 状态：**我方推断，待验证**。

### 2.2 年龄层【外部数据】

| 数据源 | 结论 | 含义 |
|---|---|---|
| 摩点出版类 | 注册 18–35 集中，**主力消费 18–25** | C 档众筹主攻 18–30，不是 35+ |
| 摩点整体 | 78% 为 25–40 岁城市中产 | 别用整体数据套出版类 |
| 国风非遗人群 | **20–35 占近六成** | A/B 档数字品主攻 20–35 |
| 新中式服饰 | 核心 25–34，主力价 500–2000 | 愿意为「文化 + 设计」付中高客单 |
| 青年国潮调查 | 90 后 / 95 后年消费 2000+ 占比最高 | 20–30 岁是真掏钱的一代 |

**主线锁 20–35 岁，C 档众筹再下拉到 18–25。**
45 岁以上不是主战场（审美偏好红金繁复，与留白极简水墨不对味）。

### 2.3 ⚠️ 性别是分裂的（本轮最重要发现）

| 场景 | 性别结构 | 应对 |
|---|---|---|
| 国风审美消费 | **女性近 80%** | A 档、审美向内容 → **对女性说话** |
| 摩点出版/众筹支持者 | **男 5.5 : 女 4.5** | 众筹页、考据向内容 → **对男性说话** |

→ **同一个品牌，两类产品的文案性别要反过来。一套文案通吃必然两头不讨好。**

### 2.4 地理位置

| 层级 | 范围 | 优先级 |
|---|---|---|
| 超一线 | 北上广深（客单最高、线下文化活动多） | P0 |
| 新一线 | **成都、杭州**（摩点点名）、武汉、西安、南京 | P0 |
| 二三线 | 有量但客单低、价格敏感 | P2 顺其自然 |
| 海外 | 北美/东南亚华人、汉学与书法爱好者、东方美学设计圈 | **P1 单独一条线** |
| 下沉市场 | ¥0.1/张红海 | **放弃，不打** |

### 2.5 反画像（别浪费力气）

- 要「古风美女 / 仙侠壁纸」的人 → 我们太硬核
- 一次买 100 张只图便宜的人 → 我们的 ¥0.59/张在他们眼里是抢钱
- 追求学术权威的文史专业读者 → 我们是创作与整理，不去那个场子辩
- 45 岁以上偏好传统吉祥图案者 → 审美不匹配

### 2.6 付费心理与决策链

```
A 档 ¥12–19   ：无需决策，凭眼缘 → 唯一 KPI 是留邮箱
B 档 ¥39–129  ：需要「这版凭什么」的答案 → 商品页第一屏讲版本
C 档 ¥129–499 ：需要三样信任状 → ① 稿已写完 ② 装帧样品 ③ 众筹故事
```

【外部】摩点图书客单价 2020/2021/2022 = 200 / 230 / **270 元，逐年上涨**
→ C 档 ¥129–499 定价合理，**可以往上限靠**。

## 三、推广方法：不投流，靠内容飞轮

**为什么**：投流买一次性曝光，内容飞轮买可复利的资产。我们现金为零，
唯一能持续投入的是内容——而 9.5 万字 + 119 事件 + 16 朝字形恰好已经写完。

```
内容源：9.5 万字 + 119 事件 + 16 朝字形
   ├→ 小红书图文钩子（P1 女性）
   ├→ 抖音/视频号 字形演变片（P1 + P3）
   ├→ 知乎/公众号 深度长文（P2 男性）
   ├→ 站内 SEO 朝代页（长尾）
   └→ 众筹项目页（内容 = 信任状）
              ↓
        邮箱名单（唯一自有资产）
              ↓
   A 档留邮箱 → B 档首卖 → C 档众筹
```

### 四阶段节奏（别跳步）

| 阶段 | 目标 | 动作 | 禁止 |
|---|---|---|---|
| 0 冷启动 | 0 → 100 邮箱 | 一张最好的图换邮箱；发 5 条内容找「哪条有人理」 | 不谈钱、不推众筹、不投流 |
| 1 名单积累 | 100 → 300 | 每月 ≥1 张新免费图；内容方向收敛；**启动 SEO** | 不扩平台 |
| 2 首卖验证 | A/B 档开卖 | 要的是**转化率数字**，不是收入 | 不提价 |
| 3 众筹 | C 档 | 摩点预热页 + 提前 30 天联系圈层达人 + 高频更新 + 控价 | 不与通贩版同质 |

### 五个动作（按性价比排序）

1. **字形演变短视频「一个字的三千年」** —— 15 秒看一个字从甲骨文变到楷书：动线 + 悬念 + 知识 + 品牌记忆，**这个题材没人做好过**，素材我们现成。**P0**
2. **免费图换邮箱** —— 名单是所有变现的前置条件。**P0**
3. **站内厚内容 SEO** —— 唯一属于自己的、可持续的流量。**P0**
4. **圈层社群先给价值**（书法/篆刻/汉服/文博）—— 转化率远高于大盘。P1
5. **合作互推** —— 我们出内容，对方出受众，零现金。P1

### 明确不做

❌ 不投流（名单 <300 之前）　❌ 不打价格战　❌ 不做全平台（先跑通一个）
❌ 不蹭与五千年无关的热点　❌ 不买粉不互刷

## 四、获客渠道

### 国内

| 渠道 | 人群 | 形态 | 优先级 |
|---|---|---|---|
| 站内 SEO（16 朝厚内容） | P2 + 搜索 | 长文页 | **P0** |
| 免费品换邮箱 | 全部 | 壁纸/字帖 | **P0** |
| 抖音 / 视频号 | P1 + P3 | 15 秒字形演变 | **P0** |
| 小红书 | P1 女性 + P3 家长 | 九宫格 + 知识图文 | **P0** |
| 知乎 / 公众号 | P2 男性 | 深度长文 | P1 |
| B 站 | P2 | 中视频 5–15 分钟 | P1 |
| 垂直社群 | P1 + P2 | 先给价值 | P1 |
| 摩点预热 | P2 + 众筹 | 项目页 + 高频更新 | P1 |
| 付费投流 | — | — | **冻结** |

### 海外线（单独一条，别和国内混着做）

| 渠道 | 形态 | 说明 |
|---|---|---|
| Instagram | 竖图 + Reels | 视觉产品天然适配 |
| Pinterest | 图钉 | 长尾流量，一次发布长期有效 |
| Reddit（r/ChineseLanguage、r/Calligraphy、r/ChineseHistory） | 图 + 解释 | 硬核人群接受度高，**反感硬广** |
| Gumroad | 商品页 | 美元定价，合规最优解 |

**三个理由**：① 国内「网络出版物」需书号、个人拿不到 → 数字品走海外是合规最优解；
② 美元心理阈值 $5–12 ≈ ¥35–85，比国内 ¥12–19 高一倍；
③ 东方美学在海外设计圈是稀缺供给，竞争远小于国内红海。

## 五、待验证的三个假设（验证成本都很低）

| # | 假设 | 验证方法 | 判据 |
|---|---|---|---|
| 1 | 用户更在意「好看」还是「有据」 | 两版钩子各发 5 条比互动率 | 差距 >2 倍即定调 |
| 2 | P3（家长/教师）是否成立 | 发 1 条「给孩子讲汉字」向内容 | 收藏/转发明显高于均值即成立 |
| 3 | 海外线是否值得投入 | 同一组图发 Instagram + 小红书比互动 | 海外互动成本更低则加注 |

**免费品留邮箱时加一道单选题**（成本为零，同时验证人群与用途）：
> 你更想把第七境的图用在 —— A 手机壁纸 / B 收藏与打印 / C 给孩子看 / D 做设计参考
