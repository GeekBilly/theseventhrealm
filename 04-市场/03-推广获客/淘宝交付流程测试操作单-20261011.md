# 淘宝交付流程测试 · 操作单（2026-10-11）

> 目标：验证「买家付款 → 我们发货 → 买家拿到文件」这条链路能不能跑通
> ⚠️ 现在两个商品都在【仓库中】，仓库中的商品买家看不到、下不了单
> ⇒ **必须先上架才能测**

---

## 一、为什么必须先上架

```
淘宝的流程：
  仓库中  ⇒ 只有你自己能看到，买家搜不到、下不了单
  出售中  ⇒ 公开可见，可以下单

⇒ 要测交付，只能先上架，用小号拍一单
```

---

## 二、完整测试步骤

### 第 1 步 · 上架（挑一个商品先测）

```
我的商品 → 仓库中 → 找到【单朝任选 ¥12】
⇒ 点【编辑商品】或列表里的【上架】按钮
⇒ 或者：编辑页里把「上架时间」改成【立刻上架】，重新提交
```

**⚠️ 建议先用 ¥12 那个测**（金额小，测试单退款损失小）

### 第 2 步 · 用小号拍一单

```
① 用另一个淘宝账号（家人/朋友，或你自己的买家小号）
② 搜到你的商品（搜「第七境 十六朝」或者直接发链接给他）
③ 选一个朝代规格，拍下付款
④ 收货地址随便填（虚拟商品不发实物）
```

**⚠️ 别用自己的卖家号拍自己的商品**（会被判定刷单）

### 第 3 步 · 发货（关键）

```
卖家后台 → 交易 → 已卖出的宝贝 → 找到这一单 → 点【发货】

⭐ 正确做法：选【无需物流】
  · 虚拟商品发货时不需要真实物流单号
  · 直接选「无需物流」提交 ✅

🔴 千万不要这么做（会踩坑）：
  · 选「有物流 / 自己联系物流」，然后填假单号
  · 理由：24 小时内无揽收记录 ⇒ 判定【虚假发货】
    ⇒ 后果：商品下架 / 删除 / 限制发布 ⚠️⚠️

⇒ 发货后，把下载链接通过【旺旺】发给买家
⇒ 并保留凭证（聊天记录、交付截图），以防被排查虚假交易
```

**⚠️ 但这里有个未知数**：
```
我们的类目发布页显示「提取方式：使用物流配送」（唯一选项）
⇒ 那个发货界面到底有没有「无需物流」选项？⚠️
⇒ ⇒ 只能实际进发货界面试才知道
⇒ 如果确实没有 ⇒ 【别填假单号】，先问客服怎么办
```

**⇒ 交付给买家的内容（复制给买家）**：

```
您好，感谢购买。

这是您要的朝代壁纸（含桌面横版 1x + 4K 三档，并附赠手机竖版 32 张）：

https://theseventhrealm.com/dl/phone

电脑：右键图片 → 设为桌面背景（选「填充」或「适应」）
手机：长按图片 → 存储 → 设置 → 墙纸

有任何问题随时联系我。
```

### 第 4 步 · 验证买家端

```
用小号登录，看：
  □ 订单状态变成「已发货」了吗
  □ 能收到旺旺消息和链接吗
  □ 链接能打开吗 ⚠️（淘宝内置浏览器会不会拦？）
     ⇒ 这是要重点验证的
```

---

## 三、⚠️ 三个必须验证的点

```
① 发货能不能成功
   ⇒ 强制物流的类目，填"其他 + 运单号无"能不能通过？

② 交付链接能不能打开
   ⇒ 我们的短链 https://theseventhrealm.com/dl/phone
   ⇒ ❌ 在微信里被拦（已知）
   ⇒ ❓ 在淘宝内置浏览器里会不会也被拦？
   ⇒ ⇒ 【这是最大的未知数】

③ 如果链接打不开，怎么办
   ⇒ 备选：用【百度网盘】链接（淘宝一般不限）
   ⇒ 或者：直接把图片分批发给买家（旺旺能发图）⚠️ 32 张很麻烦
```

---

## 四、测试完怎么收尾

```
① 测试单：点【退款】关闭（自己买自己退，不影响评分，但少做为好）
② 商品：决定继续卖，还是先下架
③ 如果链接打不开 ⇒ 换交付方案，再测一次
```

**⚠️ 测试单的注意**：
```
· 别反复用同一个号拍（可能被判刷单）
· 一个商品测一次就够
· 测完尽快退款关闭
```

## 五、⭐ 一个更省事的替代方案

```
如果不想上架测（怕影响店铺），可以：

方案 B · 只看「发货」界面有什么选项
   ⇒ 不用真下单，先看后台发货界面长什么样

   ⇒ ⚠️ 但没订单就看不到发货界面 ⚠️
   ⇒ ⇒ 所以还是得真下一单

   ⇒ ⇒ 这个最快，不用冒险下测试单 ✅
```

**⇒ 我的建议：先走方案 C（问客服），确认发货方式，再决定要不要下测试单**
