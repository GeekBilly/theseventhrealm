## 一、为什么官方自动发货用不了

### 1.1 淘宝「电子交易凭证」—— 类目不支持 ❌

```
淘宝官方的自动化交付方案叫【电子交易凭证】，
但它只支持这几类（O2O 线上买、线下核销）：

  · 电影/演出/体育赛事
  · 本地化生活服务
  · 景点门票/度假线路/旅游服务
  · 休闲娱乐/购物卡
  · 外卖/外送/订餐服务
  · 餐饮美食/面包券

⇒ ❌ 我们的「设计素材/源文件」类目【不在支持列表】⚠️
⇒ 所以官方发码用不了
```

### 1.2 淘宝的「自动发货」功能

```
淘宝确有"自动发货"，但主要针对【卡密类】商品
  · 每拍一次发一个卡号/密码
  · 需要卡密库

⇒ 我们的交付物是【文件 + 下载链接】⚠️
⇒ 是否支持需要看发布页有没有对应字段
⇒ （我们发布时没看到"自动发货"选项）
```

## 六、🔴【电子交易凭证】已确认：不能用，建议取消勾选

**用户 2026-10-11 22:39 截图了该功能的面板，字段如下**：

```
✅ 电子交易凭证（已勾选）
   ⚠️ 提示：「若后续您需要退出平台时店铺存在未核销的电子凭证订单，
            您将无法完成退出流程！」

设置有效期：*
  ○ [日期] 至 [日期]
  ○ 购买成功日至 [日期]
  ○ 购买成功后 [__] 天内有效

属性设置：
  ☐ 支持预约门店
  ☑ 支持核销打款
  ☑ 支持过期退款      退款比例 100 %
  ☐ 支持售中自动退款

⚠️「勾选即意味着您已授权同意该码商对电子交易凭证的核销、退款、验证等操作」

核销门店库：* [请选择核销门店库]
```

**⇒ 结论：这是【O2O 线下核销】功能，不是发货功能** ❌

```
判断依据：
· 「设置有效期」    ⇒ 凭证有效期（像团购券）
· 「支持预约门店」  ⇒ 线下预约
· 「支持核销打款」  ⇒ 到店核销才算完成
· 「核销门店库」*   ⇒ 【必须有线下门店】，我们没有 ⚠️

⇒ 这是给电影票 / 团购券 / 景点门票那一类设计的
⇒ 对我们的「下载壁纸」完全没用
```

**⇒ 而且有真实风险**：
```
勾了它，买家订单会进入【待核销】状态
⇒ 没有门店核销 ⇒ 订单一直挂着
⇒ 以后想退出平台都退不了 ⚠️

⇒ ⇒ 【建议取消勾选】
```

**⇒ 最终结论**：
```
❌ 电子交易凭证 —— 不适用
❌ 官方自动发货 —— 类目不支持
✅ 半自动方案 —— 自动回复 + 秒级提醒 + 快捷短语 ≈ 30 秒/单
```
