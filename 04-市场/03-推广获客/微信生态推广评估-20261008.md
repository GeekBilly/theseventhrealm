## 一、核心差别：有没有「公域流量」

| 形态 | 入口 | **公域流量** | 素材复用 |
|---|---|---|---|
| **微信图文**（贴图 / 小绿书） | 公众号后台「贴图」 | ✅ **「看一看」有推荐** | ✅ 16 张壁纸是天然素材 |
| **视频号** | 微信发现页 | ✅ **推荐流**（非关注者也能刷到） | ✅ 有 5 秒视频 + 16 朝静态图 |
| 公众号文章 | 订阅号消息 | ❌ **只有关注者能看到** | ✅ 已有 22 篇 |
| 微信小店 | 微信内 | 🟡 | ⚠️ 虚拟商品类目限制 |
| 搜一搜 | 搜索 | 🟡 需内容积累 | —— |

**⇒ 一句话**：
```
公众号文章 = 只能触达【已关注的人】 ⇒ 沉淀，不获客 ⚠️
微信图文   = 「看一看」推荐给【没关注的人】 ⇒ 获客 ✅✅
视频号     = 推荐流给【没关注的人】 ⇒ 获客 ✅✅
```

**⇒ 而用户的公众号后台已经有这两个入口**：
```
新的创作：文章 ｜ 选择已有内容 ｜ 【贴图】 ｜ 【视频】 ｜ 转载 ｜ 播客 ｜ 直播
                                        ↑         ↑
                                   微信图文     视频号
```

## 二、三个形态逐项评估

### 2.1 微信图文（贴图 / 小绿书）⭐ 首推

```
是什么：微信 2024 年推出的图文功能，形态接近小红书
        （图片 + 短文案，可点赞/收藏/转发）
入口：  公众号后台 → 新的创作 → 【贴图】
流量：  ⭐ 微信「看一看」有推荐流量 —— 这是关键
```

**为什么最适合我们**：
```
① 我们最强的资产就是【静态成品图】（16 朝 × 多规格）
② 小红书素材包已经写好（起号素材包-第一批.md）
   ⇒ 图文只需【改标题 + 换图序】，可直接复刻 ✅✅
③ 成本几乎为零
④ 「看一看」推荐不看粉丝量，看【完读率 + 互动率】
   ⇒ 新号也有机会 ✅
```

**做法**：
```
· 一次发 9–16 张（16 朝壁纸）
· 标题参考小红书那套（知识钩子型）
· 首图：商（甲骨文辨识度最高）或唐
· 文案：200 字以内，末尾一句引导关注
· 挂公众号文章链接（导流到深度内容）
```

### 2.2 视频号 ⭐ 次推

```
是什么：微信的短视频平台
入口：  公众号后台 → 新的创作 → 【视频】；或微信发现页
流量：  ⭐ 推荐流（非关注者也能刷到）
优点：  · 可与公众号互相挂载
        · 可挂微信小店商品
```

**我们的素材**：
```
✅ 已有：wallpaper-商-竖版-1080x1920.mp4（5 秒）
✅ 可做：16 朝壁纸轮播（静态图 + 转场，剪映即可）
✅ 可做：字形演变过程动画（素材齐，但渲染成本高）
⚠️ 注意：5 秒在视频号也偏短，建议 15–30 秒
```

**做法**：
```
· 把 16 朝壁纸做成 20–30 秒轮播（每张 1.5 秒 + 转场）
· 配一段舒缓音乐（版权免费）
· 文案：「五千年，十六朝，一句原句一件文物」
· 主页挂公众号链接
```

### 2.3 公众号文章（已有，保持）

```
定位：深度内容 —— 考据长文、朝代解析、创作过程
作用：沉淀关注者，建立信任
现状：22 篇原创 / 132 用户
```

**⇒ 与图文/视频号的关系**：
```
图文 / 视频号  → 获客（把人引进来）
公众号文章     → 沉淀（把人留住）
留言 / 私信    → 转化（把人变成客户）
```

## 四、优先级与排期建议

| 动作 | 成本 | 获客潜力 | 优先级 |
|---|---|---|---|
| **微信图文**（贴图） | 极低（素材复用，1 小时） | 高（看一看推荐） | ⭐⭐⭐ **本周就做** |
| **视频号轮播** | 低（剪映，2 小时） | 高（推荐流） | ⭐⭐⭐ |
| 公众号文章（保持） | 中（已有节奏） | 低（只触达关注者） | ⭐⭐ |
| 微信小店 | 中 | 中 | ⏸ 等交付链路 |
| 搜一搜优化 | 中 | 低 | ⏸ |

**⇒ 建议**：
```
第一步（本周）：微信图文 × 3 条
  · 第 1 条：16 朝壁纸总览（引关注）
  · 第 2 条：单朝深挖（如「商·玄鸟」的来历）
  · 第 3 条：创作过程（AI 水墨底纹是怎么做的）

第二步（下周）：视频号轮播 × 2 条
  · 16 朝壁纸轮播（20 秒）
  · 字形演变（商 → 周 → 秦 → …）

第三步：观察数据，再决定是否加码
```

## 五、⚠️ 一个策略提醒

```
【图文 / 视频号 是「获客」，不是「卖货」】

现在平台对【站外导流】管得很紧：
  · 小红书：留网址会限流 ⚠️
  · 微信：站外链接受限 ⚠️

⇒ 所以正确的路径是：
   内容平台（获客）→ 微信内（沉淀）→ 邮件/微信（成交）

⇒ 而不是：
   内容平台 → 直接甩网址（会被限流）⚠️
```

**⇒ 我们的优势**：品牌名和域名一致（第七境 / theseventhrealm.com）
```
⇒ 用户搜「第七境」就能找到
⇒ 但 ⚠️ 现在百度搜「第七境」全是同名游戏
⇒ ⇒ 所以要把【公众号名 / 小红书名】做成能搜到的锚点
```
