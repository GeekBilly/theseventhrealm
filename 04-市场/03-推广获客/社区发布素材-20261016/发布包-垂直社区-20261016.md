## 七、不要在社区做的事（红线）

| 项 | 原因 |
|---|---|
| 简介写职业 / 单位 / 城市 / 收入 / 副业 | **R-19**（在职金融从业，压制经营身份暴露） |
| 写「全程 0 AI」「纯手工」 | 不实——底纹是 AI 辅助生成；击穿考据可信度 |
| 留微信号 / 手机号 / 邮箱 | 平台判引流违规；且属个人身份信息。官网表单已能承接 |
| 写真实姓名 / 家庭地址 | 同上 |
| 写「老子预言了大爆炸」类表述 | 伪科学口径，毁品牌可信度（MEMORY #69） |
| 一次性铺 5 个平台同一批图就停更 | 社区权重看持续更新；宁可**先做透一个**再铺开 |
