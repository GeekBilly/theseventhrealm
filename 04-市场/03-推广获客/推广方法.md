# 推广方法 v1（2026-09-29）

> 与 `渠道清单.md` 的分工：**本文件讲「怎么打」，渠道清单讲「在哪打」。**
> 一句话概括我们的打法：**不投流，靠内容飞轮；不追爆款，追名单。**

---

## 一、核心打法：内容飞轮（一次生产，五次分发）

我们最大的资产不是图，是**已经写完的稿子**：9.5 万字成书稿、119 个事件节点、16 朝字形演变图。
同一份资产，切五种形态分发，边际成本几乎为零——这是我们能以一敌十的唯一方式。

```
        ┌──────────── 内容源：9.5 万字 + 119 事件 + 16 朝字形 ────────────┐
        │                                                                │
   ┌────┴─────┐  ┌──────────┐  ┌──────────┐  ┌────────┐  ┌────────────┐
   │ 小红书    │  │ 抖音/视频号│  │ 知乎/公众号│  │ 站内 SEO│  │ 众筹项目页 │
   │ 图文钩子  │  │ 字形演变片 │  │ 深度长文  │  │ 朝代页  │  │ 内容=信任状│
   │ (P1女)   │  │ (P1/P3)  │  │ (P2男)   │  │ (长尾)  │  │ (C档转化)  │
   └────┬─────┘  └────┬─────┘  └────┬─────┘  └────┬────┘  └─────┬──────┘
        └──────────────┴────────────┴─────────────┴──────────────┘
                                    ↓
                        邮箱名单（唯一自有资产）
                                    ↓
                        A 档留邮箱 → B 档首卖 → C 档众筹
```

**为什么这是对的**：投流买的是一次性曝光，内容飞轮买的是**可复利的资产**。
我们现金为零，唯一能持续投入的就是内容——而内容恰好是我们已经有的。

## 二、四阶段节奏（别跳步）

### 阶段 0：冷启动（0 → 100 邮箱）
- **只做一件事**：把最好的一张图做成钩子，换邮箱。
- 同步发 5 条内容，不追求量，追求找到「哪条有人理」。
- **禁止**：此时不要谈钱、不要推众筹、不要投流。

### 阶段 1：名单积累（100 → 300 邮箱）
- 免费品持续供给（每月至少 1 张新图）。
- 内容方向收敛到**验证出来有效的那一条**，加倍投入。
- 启动站内 SEO（厚内容替换 16 朝页面，3–6 个月后才见效，**越早越好**）。

### 阶段 2：首卖验证（A/B 档开卖）
- 目标不是收入，是**转化率数据**：300 个邮箱能卖出几单？
- 这个数字决定 C 档目标额能不能定到 3 万。
- 商品页第一屏必须讲「版本」，不能讲「张数」。

### 阶段 3：众筹（C 档）
- 前置动作：摩点建**预热页**攒关注（这是平台机制，不用白不用）。
- 提前 30 天联系圈层达人（书法/篆刻/文博/历史类中小博主，粉丝 1–10 万性价比最高）。
- 上线后**高频更新项目动态**——故宫系项目验证过的打法。
- 回报档必须与未来通贩版做出差异（编号、装帧、赠品），并**提前定好控价规则**。

## 三、五种具体推广动作（按性价比排序）

| # | 动作 | 成本 | 为什么有效 | 优先级 |
|---|---|---|---|---|
| 1 | **字形演变短视频**（「一个字的三千年」） | 时间 | 天然有动线、有悬念、可视化，**这个题材没人做好过** | **P0** |
| 2 | **免费图换邮箱** | 零 | 名单是所有变现的前置条件 | **P0** |
| 3 | **站内厚内容 SEO** | 已成稿 | 唯一属于自己的、可持续的流量 | **P0** |
| 4 | **圈层社群先给价值** | 时间 | 书法/篆刻/文博社群转化率远高于大盘 | P1 |
| 5 | **合作互推** | 时间 | 我们出内容，对方出受众，零现金 | P1 |

### 动作 1 为什么排第一
「一个字的三千年」——从甲骨文到金文到小篆到楷书，一个字的形体在 15 秒里演变完成。
它同时满足：视觉冲击（动）、知识获得感（懂了）、情感共鸣（原来如此）、品牌记忆（第七境）。
**而且我们已经有素材**（16 朝字形图 + 9.5 万字解释），制作成本极低。

## 四、明确不做的事（省下的力气比做的更重要）

- ❌ **不投流**：名单不到 300 之前，投流是把钱倒进没有底的桶。
- ❌ **不参加价格战**：¥0.1/张的红海我们永远打不过，也不该打。
- ❌ **不做全平台**：先跑通一个平台再扩。建议小红书 + 抖音二选一起步。
- ❌ **不追热点蹭流量**：与五千年无关的热点会稀释品牌。
- ❌ **不买粉、不互刷**：小体量时数据真实性是唯一可信的东西。

## 五、衡量：每周只记三个数

```
访客数  ·  新增邮箱  ·  成交额
```

再加一个**滞后指标**：内容发布数（每周 ≥2 条，这是唯一能 100% 自控的变量）。

> 用户偏好提醒：这三项要**图形化**呈现（柱形图 + 趋势线），不用纯文字表。
