# 领取页上线说明（2026-10-13）

## 问题背景

用户用 QQ 邮箱点下载链接 → **网页显示乱码**。

**根因**（已诊断）：
```
短链 /dl/phone → 302 → .zip
zip 响应头缺 Content-Disposition: attachment
⇒ QQ 邮箱内置浏览器 / 部分 App 浏览器【不下载，而是把 zip 当文本显示】
⇒ 显示二进制内容 = 乱码
```

## 解决方案（两件一起做，缺一不可）

### ① 上线领取页 ⭐ 主方案

```
把 get/ 整个目录上传到：
  public_html/get/

上线后访问：
  https://theseventhrealm.com/get/

⇒ 用户看到的是一张正常网页（有预览图 + 下载按钮）
⇒ 点按钮才下载 ⇒ 不会出现乱码
```

### ② 加 .htaccess 强制下载 ⭐ 保险

```
把 htaccess-片段.txt 的内容追加到：
  public_html/.htaccess

⇒ 给 .zip 加 Content-Disposition: attachment
⇒ 浏览器一律下载，不再内联显示
```

## 上线后要改的地方

```
1. 邮件里的链接改成：
   https://theseventhrealm.com/get/     （领取页）
   （原来给的是 /dl/phone，直接 302 到 zip）

2. 短链 /dl/phone 可以：
   - 保持不动（作为直链备用）
   - 或者改成 302 到 /get/ ✅ 推荐
```

## 换短链指向的方法（CF Page Rules）

```
Cloudflare → 规则 → Page Rules → 找到 /dl/phone 那条
⇒ 把目标 URL 从 zip 改成：
   https://theseventhrealm.com/get/
⇒ 保存 ✅

（我没有 CF API 权限，这一步要你操作）
```

## ⚠️ 另一个发现：QQ 邮箱对本站的"屏蔽"

用户反馈「腾讯的 QQ 邮箱对我们的网站是屏蔽状态」

**可能原因**（和微信拦截同源）：
```
· 域名没有 ICP 备案
· 服务器在境外 + Cloudflare
· 域名信誉积累不足
```

**缓解办法**：
```
· 邮件里用【领取页】而不是直链 ⇒ 降低被判风险
· 提示用户「如打不开，请复制链接到浏览器打开」
· 长期：ICP 备案（根治）
```
