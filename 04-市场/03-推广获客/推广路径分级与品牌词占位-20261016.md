# 推广路径分级 · 与品牌词占位问题（2026-10-16）

> 触发：首页宇宙演化动画在制作中，问「有什么推广手段能提高网站访问量」。
> 结论：**访问量本身不是该追的指标**；真正该修的是**品牌词占位**——现在搜「第七境」搜不到本站。

---

## 一、三个实测事实（决定了整个策略）

### 1. 动画尚未上线
线上首页（2026-10-16 08:20 抓取）**不含**「道生一 / 三生万物 / 宇宙 / 混沌 / 动画」等任何关键字，只有主题自带的 `canvas`。
⇒ 动画还在本地阶段，任何"用动画引流"的动作都得等它上线之后。

### 2. 🔴 品牌词搜不到本站
搜「第七境 汉字 演变 壁纸 网站」，返回结果**没有一条是 theseventhrealm.com**：
- 汉字叔叔 `hanziyuan.net`（月访问 100 万+）
- `hanzi.run`、`zi.tools`、千千秀字
- 甚至混入网文《震惊，古文字修仙》，其中「第七境顺心天道境」是修仙境界设定

⇒ **「第七境」不是可独占的品牌词**，被"境界"这个通用用法稀释。
⇒ 所有平台内容若只说"搜索第七境"，用户搜到的是小说和别人。**这是当前最该修的一处。**

### 3. 2026 主流平台全部禁/降权外链
| 平台 | 外链现状 |
|---|---|
| 小红书 / 抖音 | 不能外链，只能"后台联系我" |
| B站 | 简介纯文本外链＝判定站外引流，**限流**；画面禁二维码；合规＝结尾口播引导主动搜索 |
| 知乎 | 正文禁二维码/联系方式；文末仅可作者账号标注；禁"关注领资料" |
| 头条 / 百家 / 搜狐 | 禁外链；百家号外链是 `nofollow`，无 SEO 价值，只能品牌占位 |

⇒ **"平台挂链接 → 导入站点"这条路已经堵死**。剩下能带真人访问的只有两条：
**① 用户主动搜索（前提是搜得到）② 允许放官网的垂直社区。**

## 二、首页动画的真实价值

它是本项目**第一次拥有大众级钩子**：

| | 受众池 |
|---|---|
| 现有内容（16 朝壁纸 / 汉字演变） | 小众：汉字、书法、朝代爱好者 |
| 动画主题（道生一…三生万物 × 宇宙演化） | **大众**：宇宙、天文、哲学、国风 |

但动画**本身不产生访问量**——它只能产生"看到的人"。这些人要落到站点，仍要靠上面那两条路。

⚠️ 口径红线（MEMORY #69）：只能说「面对同一个问题，两条路给出结构相似的回答」；
**禁说**「老子预言了大爆炸 / 科学证实古人」——伪科学，会击穿品牌考据可信度。

## 三、推广手段分级

### P0 · 必须做（成本极低，不做则后面全白费）

**① 修品牌词占位**
- 不要用裸的"第七境"——撞修仙境界设定。
- 改用**带限定词的完整品牌名**：`第七境 · 汉字演变` / `第七境壁纸` / `theseventhrealm`
- 各平台账号名统一，且与品牌名一致（B站合规姿势就是"结尾口播引导搜索"）
- 目标：搜「第七境壁纸」「第七境 汉字演变」第一条是本站

**② 动画录屏剪短视频**（这是手上最好的素材）
- 60–90 秒，抖音 9:16 / B站 16:9 / 视频号
- 结尾：**口播 + 字幕给品牌名**，不给链接（B站给裸链会限流）
- 现有定版资产：画卷 `16朝画卷-宣传片-完整版-4m10s-配乐.mp4`（MEMORY #49）

### P1 · 高匹配，且**允许放官网链接**

**③ 设计/作品社区**（对这个视觉项目最匹配）
- **站酷、UI中国、花瓣**：发作品集，**个人简介放官网**；权重高、受众＝国风/设计/书法爱好者
- **Behance / Dribbble**：国际端，配合已上线的英文站 `/en/`（WP 193）

**④ 开发者/文字社区**（可附站点链接，且会被搜索引擎收录）
- **V2EX**：域名权威分高，帖子被收录后稳定带中文搜索流量
- **Dev.to / Medium**（英文）：可放链接、DA 高，配合英文站
- **Reddit** r/SideProject、r/InternetIsBeautiful：必须写内容不能只贴链接

### P2 · 长期

**⑤ SEO 长尾**：线上仅 43 页，长尾严重不足。已有基础：sitemap 43 条 + IndexNow 已推 43 条 + 百度 API 43/43。
**⑥ 微信搜一搜**：国内百度权重在下降，微信搜一搜在上升，值得占位。

### P3 · 不做

- 买外链 / 批量目录站：2026 年打击更严，抓到恢复周期半年以上。
- 在禁外链平台硬挂链：限流 + 可能被判"引流违规"。

## 四、执行顺序的硬判断

现在**不适合**大规模推流量：
1. 阶段判据（MEMORY #54）：**产能过剩、转化未通** —— 先跑通 1 笔真实成交再谈放大；
2. **T-17 阻塞**：面包多未注册 ⇒ **收款通道没通**，流量来了变不了现；
3. 动画尚未上线。

⇒ 顺序应为：**动画上线 → 收款通道打通 → 再集中推**。
在此之前，只有 P0 的①（修品牌词）值得现在就做，因为它不依赖任何前置，且是后面所有动作的底座。
