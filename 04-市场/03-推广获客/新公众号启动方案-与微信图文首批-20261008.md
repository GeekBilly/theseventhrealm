**标题**：
```
商朝人相信：他们的祖先是一只鸟
```

**正文**：
```
《诗经 · 商颂》里有一句：

「天命玄鸟，降而生商。」

意思是：上天命令一只黑色的鸟飞下来，然后就有了商朝。

这不是比喻。商朝人真的相信这件事。
他们的始祖叫「契」，传说是有娀氏的女儿吞了玄鸟的蛋生下的。

所以商朝的青铜器上，到处都是鸟。

商 · 商。

一个是碑刻，一个是毛笔。
一个硬，一个软。
一个给石头看，一个给人看。
```

## 图文 ③ · 幕后 —— 一张壁纸是怎么做出来的

**标题**：
```
一张壁纸，我改了九版
```

**正文**：
```
不是画出来的，是排出来的。

第一步，定底纹。
每朝要选一个「意象」——必须出自那一朝的典籍或传说。
商选玄鸟（《诗经·商颂》），周选凤凰（《诗经·大雅》），
宋选瑞鹤（宋徽宗《瑞鹤图》），元选六月飞雪（关汉卿《窦娥冤》）。

第二步，生图。
用 AI 生成水墨底纹，但要控制墨的浓度——
太浓会吃掉主字，太淡又看不出是什么。

第三步，排版。
一个字，两种书体并列：碑刻 + 毛笔。
中间留一条细线，像两种字在对话。

第四步，调。
主字位置、金句方向、印章角度、年代字体……
我改了九版。

做到第九版的时候我意识到一件事：
真正贵的不是「画」，是「排」。
底图做一次就够，但排版要一遍一遍地磨。

十六朝，每一朝都这么磨过来的。

（回复【壁纸】拿全套 32 张）
```
