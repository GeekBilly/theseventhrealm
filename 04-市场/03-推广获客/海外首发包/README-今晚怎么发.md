## 二、文案（已按各平台语气调好，直接复制）

### 2.1 Instagram —— 知识钩子 + 审美，结尾要互动

```
3,000 years. One character.

商 (Shāng) — the name of the Shang dynasty.

First carved into turtle shell as oracle bone script,
then cast into bronze, then brushed, then printed —
until it became the character you just read without thinking.

I'm building a visual record of how Chinese characters
changed across five millennia. One character at a time.

Which character should I trace next?

#chinesehistory #oraclebonescript #chinesecalligraphy #hanzi
#etymology #chineseculture #calligraphy #historylovers
#typography #shangdynasty #bronzeinscription #chineseart
```

**Hashtag 的分层是有意的**：前 4 个是大流量池（百万级，但淹没快），中间 4 个是中量级，后 4 个是精准小池（容易进 Top 帖、带来真兴趣的人）。IG 允许 30 个，但 **12 个的效果通常最好**，别贪多。

---

### 2.2 Pinterest —— 搜索长尾，关键词要写进标题和描述

```
Title:
Chinese Character Evolution Wallpaper — Oracle Bone to Modern Script

Description:
How the character 商 (Shāng) changed over 3,000 years: oracle bone
script → bronze inscription → seal script → clerical script → regular
script. Minimal ink-on-paper wallpaper — phone and desktop sizes.
From TANTSE™, a project retelling 5,000 years of Chinese
history one character at a time.

Keywords: chinese character evolution, oracle bone script, bronze
inscription, seal script, hanzi etymology, chinese calligraphy wallpaper,
minimal chinese wallpaper, ink painting, shang dynasty
```

Pinterest 是**搜索引擎不是社交网络**：图钉的寿命以月计，标题里没有关键词就永远搜不到。描述里那串 keywords 不是给机器看的 meta 标签，是写给人搜的词——写进去能提升命中。

---

### 2.3 Reddit —— 去营销化，以分享者身份发帖

- 社区：`r/Calligraphy`、`r/ChineseLanguage`、`r/ChineseHistory`、`r/etymology`
- 标题：
  ```
  I traced 商 (Shāng) through 3,000 years of script — oracle bone → bronze → seal → clerical → regular
  ```
- 正文：
  ```
  I've been working on a visual record of how Chinese characters evolved,
  and 商 (Shāng) is one of the clearest examples — you can watch the turtle
  shell carving slowly straighten into the printed form.

  Right to left: the oracle bone script (c. 13th century BCE), the modern
  brush form, and the modern printed form.

  Happy to answer questions about the source forms — or tell me which
  character I should do next.
  ```

- ⚠️ **先别贴链接**。Reddit 对硬广零容忍，会被删帖甚至封号。
  正文里完全不提品牌、不放网址；等有人在评论里问"where can I get this"再给。
  图片落款自带品牌标（**重出后为 `TANTSE ™`**），该看到的自然会看到——这才是 Reddit 正确的方式。
