## 四、为什么第二条选周朝而不是别的

1. **资产现成**：周字壁纸 + 凤凰底纹已出（`gen-phoenix-full.py`，凤凰 .86 / 质心 (76%,34%)），零新增出图成本。
2. **金句最硬**：「周虽旧邦，其命维新」是《诗经·大雅·文王》原文，公有领域，且这句在中文互联网有极强的共鸣——英文侧也常被引用（"an old state with a new mandate"）。
3. **和第一批同框可比**：同一版式、同一平台、换了字。**两批数据一对比，就能看出「字形演变」这个钩子是图本身在起作用，还是只有第一条吃到了平台推荐**——这是第一批数据解释不了的问题，第二批能。
