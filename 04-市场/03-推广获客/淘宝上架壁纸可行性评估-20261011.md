## 四、⚠️ 淘宝的 3 个坑（必须提前知道）

### 坑 1 · 虚拟商品售后偏买家

```
数字商品最怕「仅退款」：
  买家拿到文件 → 申请仅退款 → 平台倾向买家 → 钱货两失

自保做法：
  · 商品详情写明「虚拟商品，下载后不支持退款」
  · 用【自动发货】保留凭证
  · 保留发货记录截图
  ⚠️ 但平台未必支持你，这是虚拟商品的通病
```

### 坑 2 · 免费壁纸遍地，比价严重

```
淘宝搜「中国风壁纸」⇒ 大量 ¥1–5 甚至免费
⇒ ¥98 套装在淘宝显得贵

应对：不卖「壁纸」，卖「十六朝字形考据 + 原创设计」
⇒ 差异化在【内容价值】，不在「壁纸」本身
⇒ 标题里要带「原创」「设计」这类词，避开低价区
```

### 坑 3 · 货架电商靠「被搜到」

```
淘宝不像小红书会主动推给用户
⇒ 需要：
  · 标题关键词优化（有人搜才有流量）
  · 或开直通车（要花钱）
  · 或从站外导流 ✅ ← 我们的优势
```
