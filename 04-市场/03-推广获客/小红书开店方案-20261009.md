## 四、商品设计建议

### 4.1 先上什么

```
建议先上【1 个 SKU】试水，别一次上四个：

  SKU-1：十六朝全套 · 手机竖版 32 张     ¥19（引流款）
  SKU-2：十六朝全套 · 含桌面横版 4K      ¥98（早鸟价）
  SKU-3：单朝 ¥12                        （后补）
  SKU-4：四辑套装 ¥39                     （后补）

⇒ 理由：小红书虚拟商品价格敏感，先用低价款测转化，
        验证有人买，再上高价款
```

### 4.2 ⚠️ 但要注意定价逻辑

```
原站定价（¥12 / ¥39 / ¥128 / 早鸟 ¥98）是【独立站逻辑】
⇒ 小红书用户习惯【¥9.9 / ¥19.9】这类价格锚点 ⚠️
⇒ 建议：
   · 引流款定 ¥19 或 ¥29（含全部 32 张手机壁纸）
   · 高价套装保持 ¥98–128（含桌面 4K）
   · 不一定要跟随独立站价格
```

### 4.3 商品详情页要有什么

```
① 首图：最好的一张壁纸（竖版，因为小红书是竖屏）
② 图 2–6：16 朝缩略图拼图 + 桌面版预览
③ 文案：
   · 一句钩子（五千年，十六朝）
   · 规格说明（iPhone 1179×2556 / Android 1080×2400 / 桌面 4K）
   · 使用说明（怎么设壁纸）
   · 版权说明（原创设计，古籍属公有领域）
④ 封面必须有【点击欲】—— 这是小红书的核心
```

## 六、风险与注意

```
① 虚拟商品审核较严
   ⇒ 上架时如实填写类目，别把虚拟商品包装成实物 ⚠️

② 版权要说清
   ⇒ 古籍原文属公有领域；价值在【选、编、注与版式设计】✅
   ⇒ 字体遵循 SIL OFL 1.1 ✅
   ⇒ 这些都写在商品详情里，避免纠纷

③ 自动发货的文件存放
   ⇒ 小红书一般让你上传文件到平台，或填外部链接
   ⇒ ⚠️ 如果填外部链接（我们的 zip 直链）⇒ 需要测试能否下载

④ 保证金可退，但有违规会扣
   ⇒ 别做刷单、别承诺无法兑现的东西

⑤ 小红书不让导流到站外
   ⇒ 所以【不要】在商品或笔记里放微信/网址 ⚠️
   ⇒ 全部站内成交 ✅
```
