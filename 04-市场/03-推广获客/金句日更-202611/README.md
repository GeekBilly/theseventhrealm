## 一、为什么选这个主题

按四条硬指标选（详见对话中的对比）：清单够长、每单元有文化钩子、壁纸本地零积分出图、领取链路现成。

| 候选 | 可发时长 | 出图成本 | 结论 |
|---|---|---|---|
| **每日一句古籍金句** | 原文 20 万字，摘 365 句无压力 | 本地渲染 0 积分 | ✅ 主推 |
| 每日一历史人物 | 224 人≈7 个月 | 人物画像要另做 | 备选（词表只有名字、无故事） |
| 每日一字 | 3 年以上 | 0 积分 | 不推荐（与百家姓撞形态） |

## 二、素材来源与合规

- **真句全部来自** `01-内容/典籍库/原文/`（20 万字，182 部典籍，A 类公有领域，P2 校对 88/88 过目）
- **逐条可定位**：30 条原句 + 30 条壁纸句均已脚本校验，能在源文件归一化后逐字找到
- **溯源铁律**：原句、出处照典籍库口径。带考据争议的已按本站口径标注：
  - 念念有词的「滚滚长江东逝水」标 **明·杨慎《廿一史弹词》**，不写《三国演义》开篇词
  - 「究天人之际」标 **《报任安书》（见《汉书·司马迁传》）**，不写《太史公自序》
  - 「横渠四句」原文有「立命/立道」异文，出处栏标明
  - 像「天视自我民视」这类牵涉伪古文辨伪的，出处照《孟子》引《泰誓》标
- **引号铁律**：所有文案正文的引号都是全角 `“ ”`（生成器强制规范化，禁半角 `"`——WP 会把半角全判成右引号）
