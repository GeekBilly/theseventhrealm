# 隐私政策页修复说明（2026-10-14）

## 一、问题现象

```
· 页面正文【完全不显示】（只有导航和页脚）
· 导航下方出现异常的悬浮下拉
· 页脚内容缺失
```

## 二、根因（已确诊）

```
🔴 正文里被粘贴了【整个网页的源码】—— 39,280 字节

具体：
  <div class="entry-content">
    <p><!DOCTYPE html>          ← 从这里
    <html lang="zh-Hans">
    <head>
      <meta charset="UTF-8">
      <title>第七境 THE SEVENTH REALM ...</title>
      ...（整个 head + CSS + body + nav + footer）...
    </html>                     ← 到这里（39,280 字节）
    <header class="hero">       ← 真正的正文从这里开始
      <h1>隐私政策</h1>
      ...
  </div>

⇒ 浏览器遇到嵌套的 <html>/<head> ⇒ 解析彻底错乱
⇒ 所以：正文消失、导航悬浮、页脚缺失 ✅
```

**混入内容的统计**：
```
<!DOCTYPE html>   1 次
<html> / </html>  2 次   ← 两层完整文档
<head> / </head>  1 次
<body> / </body>  2 次
<title>           1 次
```

## 三、修复方法（二选一）

### 方法 A · 精确删除垃圾段 ⭐ 推荐

```
1. WordPress 后台 → 页面 → 找到「隐私政策」→ 编辑
2. 右上角【⋮】→ 选「代码编辑器 / Code Editor」
3. 找到这一行（约在开头）：
     <p><!DOCTYPE html>
4. 从这里开始，一直选中到这一行【之前】：
     <header class="hero">
5. 删除选中的全部内容（约 39 KB）
6. 保存
```

**⚠️ 注意**：删除后开头应该直接是：
```html
<header class="hero">
<p class="zi-top">不 追 踪 · 不 出 售</p>
<h1>隐私政策</h1>
...
```

### 方法 B · 整段替换（更省事）

```
1. 编辑「隐私政策」页面 → 代码编辑器
2. 全选（Cmd+A）→ 删除
3. 把 privacy-正文-干净版.html 的全部内容粘贴进去
4. 保存
```

**⇒ 干净版文件**：`privacy-正文-干净版.html`（7,920 字节）

## 四、修复后还要做的两件事

### ① 关闭 Cloudflare 的邮箱混淆（解决 `[email protected]`）

```
Cloudflare 后台 → Scrape Shield → Email Address Obfuscation → 【关闭】
⇒ 全站 16 处邮箱恢复显示 ✅
```

### ② 顺手修 nav 里的注释写法（防止再出问题）

```
现在（多行注释，会被 wpautop 破坏）：
<!-- 分支上线后取消注释（「周边」须等商标注册下来再启用）：
<a class="todo" href="/novel">小说</a>
...
--><br />

建议改成单行：
<!-- 分支上线后取消注释：小说 / 动漫 / 电影 / 游戏 / 周边（等商标注册后再启用） -->
⇒ 把待启用的 <a> 代码存到本地文档，不留在 HTML 里
```

```

· 而不是只复制正文内容
⇒ 属于误操作，其他页面没有这个问题（已核对 /terms/ /faq/ 正常）
```
