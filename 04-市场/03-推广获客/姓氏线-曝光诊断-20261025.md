# 姓氏线曝光诊断 · 2026-10-25

> 起因：D04 已发，用户问「封面都像 16 朝一样发的，为啥还是没曝光，是不是题目也要改」
> 结论：**封面不像 16 朝，是「作品图」冒充「海报图」；标题和封面犯的是同一个错——在介绍作品，不在承诺利益。只改题目救不了。**

## 一、先破一个误解：封面根本不一样

用户以为「封面风格一致」（都是宣纸底 + 墨字 + 朱砂），但**结构完全不同**：

| | 16 朝篇（曝光 2301） | 姓氏线 D01–D04（曝光 238–286） |
|---|---|---|
| 第 1 张是什么 | **专门做的信息海报**（独立文件 `00-封面-16张朝代壁纸自取-3x4.png`） | **成品壁纸本体**（`蒋-1179x1572.png`） |
| 最大字号写的是 | `16 张朝代手机壁纸` ← **品类 + 数量** | `蒋` ← **单个内容** |
| 有「壁纸」二字吗 | 有，还是主标题 | 🔴 **图上完全没有** |
| 有数量/范围吗 | 有（16 张 / 16 个朝代全列） | 无（不知道有 100 姓、25 组） |
| 有行动指令吗 | 有，朱砂红大字 `想要原图 · 后台滴滴我` | 无 |
| 有规格说明吗 | 有（iPhone 1179×2556 · Android 1080×2400 · 无水印） | 无 |
| 图数 | **17 张** | **4 张** |

### 为什么这在信息流里是致命的

小红书信息流缩略图约 200px 宽。姓氏线图上所有辅助信息——
`一姓四体·三千年`、`自上而下·自草书至碑刻`、`草书 柳建毛草`、`蒋/蒋·源流 西周·c.950BC`、`www.theseventhrealm.com`
——**在缩略图下全部糊成一片，等于不存在**。用户在 0.5 秒内只看得到一个大字：`蒋`。

也就是说：**这张图作为壁纸是 90 分，作为封面是 30 分。** 它把最没信息量的元素（单个字）放在了最大的位置，把最有信息量的元素（品类/数量/钩子）要么没写，要么写成了看不清的小字。

16 朝封面反过来：最大的是「16 张朝代手机壁纸」，红色的「想要原图」是第二视觉焦点，**缩略图下依然可读**。

> 这是「作品展示逻辑」vs「信息流获客逻辑」的差别，不是审美差别。

## 二、标题：同一个病

| | 16 朝（ctr 16.40%） | 姓氏线 D01（ctr 8.00%） |
|---|---|---|
| 标题 | `16 张朝代手机壁纸，原图私信我` | `赵钱孙李｜赵武灵王到李广，四种写法（17 字）` |
| 含「壁纸」搜索词 | ✅ 有 | 🔴 **没有** |
| 剧透程度 | 只说「16 张」，**不说哪 16 张长啥样** | 四个姓 + 四个人 + 内容形式，**一次全给完** |
| 行动指令 | ✅ 「原图私信我」 | ❌ 无 |

两个硬伤：

1. **标题里没有「壁纸」二字** —— 而正文标签偏偏带了 `#手机壁纸` `#壁纸`。标签有搜索量，标题不含关键词，等于**搜索端和推荐端两头都没吃上**。
2. **剧透完 = 没有点进去的理由** —— 「赵钱孙李｜赵武灵王到李广，四种写法」，用户在标题里已经拿到了全部信息，不需要点开。而 16 朝只说「有 16 张」，**没说是什么样**，这才留出了点击动机。

## 三、第三个变量：图数 4 vs 17

小红书的初始流量池看**停留时长 + 滑动深度 + 互动率**。4 张图和 17 张图，停留时长差一个量级。

曝光 2301 对 286（差 8 倍），ctr 只差 2 倍（16.4% vs 8.0%）—— 说明**除了点击率，还有一层「初始池根本没给量」**。图数少是最可能的直接原因之一。

## 五、修复方案（按影响排序，全部 0 积分）

### P0 · 换封面（唯一能救 ctr 的动作）

做一张「海报型封面」模板，复用 16 朝已验证的结构：

```
第七境 · 百家姓
─────────────────────────
        100 个姓的手机壁纸
      赵 → 杨，第 4 组：蒋沈韩杨

  蒋 · 沈 · 韩 · 杨 四种写法
  （本组四个字平铺，示意内容量）

─────────────────────────
      想要原图 · 后台报姓
      iPhone 1179×2556 · Android 1080×2400
      无水印 · 可直接设为手机壁纸
              [第七境印章]
```

要点：
- 最大字号必须是 **品类 + 数量**（"100 个姓的手机壁纸"），不是单个字
- 朱砂红大字必须是**行动指令**
- 缩略图 200px 下仍可读 → 正文字号不低于主标题的 1/4
- 每篇只改中间那行「第 N 组：四字」，**其余固定**，可脚本批量出 25 张

### P1 · 改标题（结构照抄 16 朝）

弃用 `{四字}｜{人物到人物}，四种写法`

改为 **`100 个姓的手机壁纸，原图私信我`** 作主模板，只把组号塞进去：
- `100 个姓的手机壁纸｜第 4 组 蒋沈韩杨`
- `百家姓手机壁纸，原图私信我 · 第 4 组`

必须满足三条：**含「壁纸」/ 不剧透具体内容 / 有索取动作**。

### P2 · 图数 4 → 7

`海报封面 1 + 四字壁纸 4 + 100 姓总览 1 + 尾图钩子 1`

「100 姓总览」图本身也是收藏诱因（用户会存下来找自己的姓）。

### P3 · 正文去掉「第 N 天」

`【第 4 天 · 蒋沈韩杨】` → `蒋沈韩杨，四个姓，四种写法。`

「第 N 天」对刷到的人是噪音，还暗示这是连载（非粉丝不会追）。

### P4 · 钩子改一步动作

`要原图：后台 dd 我「壁纸」，告诉你怎么领`（两步）→ `要原图：后台发我一个字，高清图私给你`（一步，且与「报姓」钩子合并）

## 七、一句话总结

> 不是「封面风格不对」，是**把成品壁纸当封面用了**——作品展示逻辑撞上信息流获客逻辑。
> 标题同理：`赵钱孙李｜赵武灵王到李广，四种写法` 在介绍作品，`16 张朝代手机壁纸，原图私信我` 在承诺利益。
> **改题目有用，但必须和封面一起改，单改题目救不回来。**
