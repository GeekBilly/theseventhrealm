## 三、标题：唯一确定成立的问题（且尚未修过）

### 🔴 3.0 先说一个真 bug：已发出的 4 篇标题末尾都带着「（N 字）」

文案 md 里写的是：

```
**标题**：周吴郑王｜周瑜到王羲之，四种写法（16 字）
```

其中「（16 字）」是**给编辑看的字数标注**。但 `xhs-draft.mjs` 第 71 行原来直接整行取走：

```js
const title = (md.match(/\*\*标题\*\*：(.+)/) || [])[1]?.trim() || '';   // ❌ 标注一起进了标题
```

于是**线上实际发布的标题是**：

| 笔记 | 实际发布标题 |
|---|---|
| D01 | `赵钱孙李｜赵武灵王到李广，四种写法（17 字）` |
| D02 | `周吴郑王｜周瑜到王羲之，四种写法（16 字）` ← `draft-log` 可查 |
| D03 | `冯陈褚卫｜冯异到卫青，四种写法（15 字）` ← `draft-log` 可查 |
| D04 | `蒋沈韩杨｜蒋琬到杨业，四种写法（15 字）` |

⇒ 用户在信息流里看到的，是一个**带着制作备注的标题**。这比「剧透」更伤 ctr——括号里的「16 字」对读者毫无意义，只会显得像没写完的草稿。

**已修**：`xhs-draft.mjs` 标题提取改为剥掉末尾字数标注，`--dry` 验证通过（D04 → `蒋沈韩杨｜蒋琬到杨业，四种写法` 15 字；不再含标注）。

> ⚠️ 已发布的 D01–D04 **线上标题仍是带标注的旧版**，需要改稿才生效。

### 3.1 去掉标注之后，标题本身还有两个毛病

| | 16 朝（ctr 16.40%） | D04（去标注后） |
|---|---|---|
| 标题 | `16 张朝代手机壁纸，原图私信我` | `蒋沈韩杨｜蒋琬到杨业，四种写法` |
| 含「壁纸」搜索词 | ✅ 有 | 🔴 **没有** |
| 剧透程度 | 只说数量，不说长啥样 | 四姓 + 四人 + 形式，一次全给完 |
| 索取动作 | ✅「原图私信我」 | ❌ 无 |

1. **标题不含「壁纸」二字**，而正文标签却带了 `#手机壁纸`（96.9 亿）`#壁纸`（198.6 亿）。标签有搜索量、标题没关键词 ⇒ **搜索端和推荐端两头都没吃上**。
2. **全剧透 = 没有点进去的理由**。用户在标题里已经拿到全部信息。

> 封面已经修好了，标题是**唯一还没动过的那一环**。这也是「题目要不要改」的答案：**要改，而且现在最该改的就是它。**

## 五、🔴 CP1 的口径错误（比曝光本身更严重）

企划写死：**CP1（D5＝10-26）看「前 5 篇平均观看 ≥300，<150 ⇒ 停，换形态」**。

按当前数据：D01 观看 26、D02 观看 24 ⇒ 平均被拉到 25 左右，**明天必然落在 <150 档**。

**但这个平均值的分子混了两个版本：**

```
D01（无封面，旧版） 观看 26
D02（无封面，旧版） 观看 24
D03（有封面，新版） 数据未到
D04（有封面，新版） 数据未到
D05（有封面，新版） 明天才发
```

⇒ 用旧版的失败平均出新版的死刑，是**无效判据**。按字面执行会误杀正确方向。

**建议：CP1 顺延到 D03/D04 数据齐了（约 10-28）再判，且只算 D03 之后的篇目。**
若坚持 D5 判定，则结论只能写成「旧版（无封面）确认失败」——而这已经修完了，不需要停更。

## 六、修复方案（只做确定有效的，0 积分）

### P0 · 改标题（唯一还没修的变量）

弃用 `{四字}｜{人物到人物}，四种写法`，改为照抄 16 朝结构。三条必须满足：**含「壁纸」 / 不剧透 / 有索取动作**。

候选（同一篇 D04 的三种写法）：

| # | 标题 | 字数 | 逻辑 |
|---|---|---|---|
| A | `100 个姓的手机壁纸，原图私信我` | 16 | 完全照抄 16 朝结构，只换数量词。**最稳** |
| B | `百家姓手机壁纸 · 第 4 组，原图自取` | 18 | 带组号做进度感，适合追更 |
| C | `蒋沈韩杨，四种写法，原图自取` | 15 | 保留四姓做搜索匹配，但去掉「｜人物到人物」的剧透 |

> 推荐 **A**：16 朝已验证过一次，变量最少。B 的「第 4 组」对陌生人无意义，C 仍偏介绍作品。

### P1 · 正文开头去掉「第 N 天」

`【第 4 天 · 蒋沈韩杨】` → `蒋沈韩杨，四个姓，四种写法。`

### P2 · 钩子改一步动作

`要原图：后台 dd 我「壁纸」，告诉你怎么领`（两步）→ `要原图：后台发我一个字，高清图私给你`（一步，且与「报姓」合并）
