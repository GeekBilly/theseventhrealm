# 社会证明（正向反馈归档）

> 品牌舆论体系 L3 的归档地，对应 `11-运营/风险管控/品牌舆论管理.md`。
> **用途**：把散落各处的真实用户反馈沉淀成可复用的信任状 —— Y1 最大的短板不是内容，是"新站 + 名单 0，凭什么相信你"。

## 一、收什么

| 类型 | 例子 | 强度 |
|---|---|---|
| 用户原话 | 评论区/私信里的正面评价、使用感受 | ★★★ |
| 自发传播 | 有人主动转发、引用、二次创作 | ★★★ |
| 成果证明 | 用了壁纸/课程后的实拍、作业、笔记 | ★★ |
| 数据快照 | 阅读量、收藏、涨粉曲线的峰值截图 | ★★ |
| 第三方提及 | 他人文章/视频中提及本品牌（无负面） | ★ |

**不收**：自吹自擂的文案、无出处的截图、涉及他人隐私的内容（私信截图**必须打码对方头像与昵称**）。

## 二、命名规则

```
<YYYY-MM-DD>-<渠道>-<一句话摘要>.png|jpg
```

例：`2026-10-05-公众号-读者说长卷排版舒服.png`

- 渠道取值：`公众号` / `小红书` / `知乎` / `X` / `邮件` / `自站评论` / `其他`
- **必须带日期**，便于按季度挑"最近 3 个月"的素材上众筹页（陈年截图说服力弱）
- 原图放这里，**引用时另存一份到商品页素材目录**，本目录只做档案，不直接被页面引用

## 三、怎么用（这是关键，别只归档不用）

1. **商品页首屏**：挑 3–5 条最强原话做信任条
2. **众筹页**：需要 10+ 条，且集中在近 3 个月
3. **内容选题**：用户原话 → 进 `内容钩子库.md` → 变成下一批内容（闭环）
4. **法律侧**：同一批材料同时是商标"在先使用证据"的组成部分（见 `11-运营/风险管控/商标证据/README.md`）

> **一鱼两吃**：同一次截图，营销侧当信任状、法律侧当使用证据，边际成本 ≈ 0。归档时顺手把带日期的原件往 `11-运营/风险管控/商标证据/` 丢一份即可。

## 四、节奏

| 频率 | 动作 | 耗时 |
|---|---|---|
| 每周（工作日早段碎片） | L1 巡查，看到正向反馈**立刻截图**存这里 | 10 分钟 |
| 每月（月度中枢任务） | 汇总当月截图数量，记进 `11-运营/data/brand-patrol.csv` | 5 分钟 |
| 每季度 | 挑最强的 10 条，更新到商品页/众筹页 | 30 分钟 |
