## 0. 一页结论

漏斗主线的**真正断点不在支付，而在两端**：

- **入口端**：三个入口（自然搜索 / 站外 / 邮件回流）**目前全部≈0**，且百度侧爬取层此前归零。
- **转化端**：即使有人进来，**首页 0 次提到「免费壁纸」**；唯一能被留邮箱的地方是 `/collection/` 底部，而**同一个区块上方已经给了无条件直下链接**——邮件名单的**结构性转化率≈0**。

✅ 一个好消息：MailerLite 表单、自动化、交付邮件、`/collection/` 均已上线且实测可用（不涉及跨境信道、不需要营业执照）。
❌ 一个坏消息：**收款按钮在全站不存在**，付费品「桌面横版」全站无购买入口。

| 检查项 | 实测结果 |
|---|---|
| 交付邮件里有没有推付费品？ | ❌ **没有**。全文对付费品的唯一表述是「桌面横版（带底纹的那套）**还在做**，做好我会先告诉你」→ 连**价格、卖点、预期时间**都没有，更没有购买链接 |
| 站内有没有「免费用户 → 付费品」的自然路径？ | ❌ **没有**。免费下载与付费品之间**无任何衔接控件**；`/collection/` 上字形线仅一句「单朝 ¥12 · 商周套装 ¥19 · 含底纹」+ 两张图，**无按钮、无「想买」意向收集** |

## 5. 漏斗断点清单（按漏得最狠排序）

> 标记：🔴 致命 / 🟠 严重 / 🟡 中等。全部基于 2026-10-02 线上 HTML 实测。

### B1 🔴【实测】免费品无条件直下，直接绕过邮箱 —— 全站最致命
- **环节**：`/collection/` 落地 → 留邮箱
- **现象**：区块标题「直接下载」，正文「**不用留邮箱**，点下面的按钮就存到你的设备」，CTA 直链 `wallpaper-jinju-32-v2.zip`（HTTP 200，5.8 MB）。邮箱表单在其**下方**，文案是「**顺便**留个邮箱」
- **为什么漏**：免费品已 100% 交付完毕，用户拿到想要的东西后留邮箱的动机归零；offer 的**结果**（32 张图）与留邮箱**解耦**了。这是留邮箱转化率的**结构性归零**，不是优化问题
- **改法**：把「直接下载」改成「**留邮箱 → 邮件里给链接**」，与交付邮件（已跑通的自动化）对齐；若坚持保留直下，则把 zip 换成**手机可用的 4–6 张「试看包」**，全套 32 张锁在邮箱后面
- **附带**：英文页同样写「**no email required**」——同一策略错误在 EN 重演

### B2 🔴【实测】入口端四类路径全部≈0
- **环节**：陌生流量 → 落地
- **现象**：百度爬取层此前归零、Google 无外链无量级、站外 0 账号、品牌词被同名 Steam 游戏与百度百科占据
- **为什么漏**：**这是漏斗最上游，漏水时下游一切优化都乘 0**。名单目标 300 在当前访次下**数学上不可达**
- **改法**：唯一零成本可用的入口是**国内内容平台**（工作区 `MVP变现路线调研` 已论证：小红书/抖音品牌号、0 粉可发）。**内容飞轮必须先出站外**，不能等站内 SEO 起来

### B3 🔴【实测】付费品全站无购买入口，且邮件不提付费
- **环节**：留邮箱 → 付费
- **现象**：`/collection/` 无任何购买控件；交付邮件对桌面版只说「还在做」；全站无「想买」意向收集
- **为什么漏**：**用户就算想付钱也无处可付**。这不是转化率低，是转化通道不存在。（已知商品未上架＝事实，但**未上架不等于不能做意向收集**）
- **改法**：在 `/collection/` 字形线上加一个**「开售通知我」按钮**（复用同一个 MailerLite 表单，加 `group` 区分）；同时把 ¥12/¥19 写成**明确的开售预期**（如「预计 X 月」）

### B4 🟠【实测】首页 0 次提及免费壁纸
- **环节**：首页 → 藏品页
- **现象**：首页 `邮箱/壁纸/免费/领取/下载/¥/价格/买` 关键词计数**全部为 0**；入口只有 `七境之门` 区块里一行灰色小字链「藏品 · 把五千年带在身边 →」
- **为什么漏**：首页是最可能被分享/记住的一页，却**不含钩子**。用户读完「道境」长文**没有任何下一步可做**
- **改法**：首页首屏加一个**免费壁纸 CTA 区**（复用现有 ip 图 + 一行字 + 一个按钮），指向 `/collection/#free`

### B5 🟠【实测】英文入口页 0 表单，用混淆邮箱地址收名单
- **环节**：EN 落地 → 留邮箱
- **现象**：`/en/` 全站导航可达，但**无 MailerLite 表单**；只有「Write to me… no form, no tracking」+ Cloudflare `[email protected]` 混淆链接；EN 页有 zip 直链但**无 `no email required` 之外的任何留资设计**
- **为什么漏**：英文是**已投入成本做出来的入口**，却不落任何可运营资产；主动写邮件的比例极低（【推断】<1%），名单增长≈0
- **改法**：把 `/en/` 的「Write to me」替换为**同一个 MailerLite 表单的英文版**（1 字段，成本≈0）

### B6 🟠【实测】导航含 5 个死链（404）
- **环节**：全站信任 → 转化
- **现象**：nav 里 `小说` `动漫` `电影` `游戏` `周边` → `/novel` `/anime` `/film` `/game` `/merch` **全部 HTTP 404**（footer 里 `/merch` 也是 404）
- **为什么漏**：①新站最缺信任状，死链**反向证明「没做完」**；②**浪费抓取预算**，百度/Google 会因此降低整站质量评分
- **改法**：把 5 个死链从 nav 移除（HTML 里已有注释掉的正确写法，取消注释即可，成本≈5 分钟）

### B7 🟠【实测】`/collection/` 泄漏了后台编辑注释
- **环节**：藏品页 → 留邮箱
- **现象**：HTML 注释**未正确闭合**，导致一段内部说明以**可见文本**渲染在表单上方：「…`script` 属行内元素，不在 wpautop 的块级保护名单里，多行会被插 `<br />`、并被 `<p>` 包裹 → 按钮下方多出空行」「⚠️ 后台改表单后不会自动同步…」「⭐ 2026-10-01：表单为「单 opt-in」…」。同时列表容器内出现游离 `</p>` 标签
- **为什么漏**：付费页出现**内部备忘录**，直接击穿「一个人认真做的项目」这一核心信任资产；也是 wpautop 处理不当的技术债
- **改法**：把该段 HTML 注释移到 `<style>` 上方并确保 `-->` 闭合（或直接删）；检查 `/collection/` 表单区块避免 wpautop 插 `<p>`

### B8 🟡【实测】免费包两个版本并存，站内给旧版、邮件给新版
- **环节**：交付一致性
- **现象**：`/collection/` 直链 `2026/09/wallpaper-jinju-32-v2.zip`（5,816,335 B，实测 200）；交付邮件链 `2026/10/wallpaper-jinju-32-v3.zip`（实测 200，工作区记录 7,145,926 B）。两版**落款不同**（工作区记录 v3 改了英文落款）
- **为什么漏**：同一免费品**两个交付分支内容不一致**，用户间会出现「我拿到的怎么和你说的一样又不一样」；且站内未做版本提示
- **改法**：站内直链统一改指 `-v3.zip`（或保留 v2 但明确标注版本差异）

### B9 🟡【实测】页脚备案号仍是占位符
- **环节**：全站信任
- **现象**：footer 里备案代码是**注释状态下的 `X ICP备00000000号`**，实际不显示
- **为什么漏**：国内用户对「无备案 + 无主体」的收款站**天然低信任**；这既是合规议题也是转化阻力（不要求注册主体，但**应在 faq 里把「个人创作者、无公司」讲得更主动**——`/faq/` 已有一段，但只在 faq 里，未在购买路径上出现）
- **改法**：**不注册主体**的前提下，把 `/faq/` 已有的「一个个人创作者，不虚构公司或机构」这段话**上移到 `/collection/` 付费区附近**

### B10 🟡【实测】`/contact/` 与 `/about/` 均无免费品入口
- **环节**：信任页 → 转化
- **现象**：`/about/` 是长文叙事，无表单无 CTA；`/contact/` 无表单（设计如此，只有邮箱）、无 `/collection/` 链接
- **为什么漏**：读完「为什么做这件事」的读者**意愿最高**，却在此处**没有出口**；`/about/` 反而用「小说/动漫/电影/游戏 未启」进一步暗示项目空转
- **改法**：`/about/` 文末加一行「去看可以带走的东西 →」指向 `/collection/`

### B11 🟡【推断】表单无来源追踪，名单无法分层
- **环节**：名单运营
- **现象**：全站仅 1 个表单（同一 form id 嵌在 `/collection/`），无论从首页、朝代页还是英文页进入，**都进同一个 group**
- **为什么漏**：将来首卖时**无法区分「为字形线来的」与「为金句线来的」**，群发一刀切会伤打开率（行业数据：分段可将转化 1.2%→2.5%）
- **改法**：MailerLite 建 2–3 个 group（中文 / 英文 / 字形线意向），表单按页面嵌不同 group，成本≈0

- 若按 MailerLite 的 **22%** 捕获率，且**每个访客都会走到表单**：
  `300 名单 ÷ 22% ≈ 1,364 次有效落地`
- 但本站**实际走不到**这个数（B1 直下绕过 + B4 首页无钩子）：
  **当前结构下，捕获率 ≈ 0**，1,000 次访问可能产生 **0–10 个**邮箱
- **首卖测算【推断】**：300 名单 × 1.5%（文学/非虚构档）≈ **4–5 笔**首轮订单；客单 ¥12–19 → **首卖 ¥50–90**
  → **结论：把目标定成「300 名单」再开卖，首卖体量只有几十元；真正的瓶颈是名单质量与 SKU 客单，不是名单数量。**
- **无可靠数据**：未找到「中文历史文化主题独立站」的免费→付费转化率公开基准。中文同类站（古诗文网、汉典）为广告/会员模式，形态不同，不可直接套用。
