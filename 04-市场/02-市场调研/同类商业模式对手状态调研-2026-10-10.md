## 零 · 一句结论

**没有一个人同时踩在我们这三条线上。** 最接近的两个（汉字叔叔、小象汉字）各有一项与我们重叠、另一项截然相反，因此：
**我们的位置暂时是空的，但这不代表安全——空通常意味着“没人验证过这条路跑得通”。**

三条同时成立才算“同类商业模式”对手：

| 条件 | 说明 |
|---|---|
| ① 内容资产是汉字 / 古文字 / 通史 | 决定了受众与考据门槛 |
| ② 变现靠内容产品本身（数字品 / 书 / 会员），不是靠接广告带货 | 决定了能不能沉淀资产 |
| ③ 自有站或自有渠道成交，内容平台只做流量 | 决定了资产归谁 |

按这三条筛下来，真正进入视野的只有 3 个半，其余全是环境变量。

## 二、最像我们的：汉字叔叔（Richard Sears / 斯睿德）

### 他在做什么

一个人、自费、从 1994 年做起。把《说文解字》《六书通》《金文编》《甲骨文编》里的古字形扫描数字化，做成公开的**字源查询数据库**。

| 项 | 数值 |
|---|---|
| 收录古字形 | 约 **96,000** 个（其中甲骨文 31,876、金文 24,223、篆书 11,109 + 小篆 596） |
| 已分析现代字 | 约 **6,552 → 1.6 万**常用汉字 |
| 月访问量 | **超过 100 万人次** |
| 覆盖 | **170 多个国家** |
| 运营原则 | 免费、无广告、公益定位 |

### 现在的状态（这是本次调研最重要的发现）

- 2020-12 获**外国人永久居留身份证**，定居南京；2021-09 成立「汉字叔叔工作室」
- 自 2024 起每周更新「汉字叔叔的字源课」视频，发在 YouTube / B 站；同时在**小红书**等平台发短视频，**已积累二十多万粉丝**
- 2026-04 接受紫牛新闻采访时他**自己说：近几年已经没有更新网站**了，转向继续充实数据库 + 写书（已整理 1,000 个汉字基本构件成书稿）
- 变现方式始终是 **PayPal / 微信 / 支付宝捐赠**

### 对我们的两条硬结论

**① 他的“免费 + 捐赠”路径是一条死路，不要学。**
早期网站年均捐款**仅约 50 美元**——这是一个极端到有点离谱的数字，说明「免费 + 捐赠」在中文互联网几乎不成立。他后来的真实来源是：讲学、节目（央视《开学第一课》《朗读者》）、书、与机构合作的 AR 字源卡产品，**没有一样是捐赠**。
→ **印证我方现行策略：免费品换来的是“名单”，不是钱。名单之后必须落到具体商品。**（与 MEMORY 47「先名单后流量」一致）

**② 他正在把这块地让出来——这是我们的机会窗口。**
一个覆盖 170 国、月访问 100 万的字源站，站长本人已明确停更网站。这个位置迟早会有人补。**我们补得起的部分**：他做的是「查一个字」（工具，重数据），我们做的是「一次性看懂一个字怎么变到现在」（叙事，重编排）。这是两种东西，不直接冲突，但他腾出来的搜索流量和心智空间是真实的。

> ⚠️ 反过来说：**也别高估这块地的价值。** 他做到了月访问 100 万，但二十年没挣到钱。**流量 ≠ 收入**，这条对我们还未验证的 SEO 路线是最现实的一盆冷水。

## 三、正面参照：小象汉字（南京字然教育科技有限公司）

### 他是谁

2015 年成立，**未融资**（亿欧 2026-05-19 更新，运营中），官网 `like-chinese.com`。产品线：甲骨文字卡、汉字绘本、APP、动画。据其官方介绍，**已与殷墟博物馆达成官方合作**，教研团队含甲骨文研究专家、儿童心理学专家、儿童文学教授。

> ⚠️ 注意：另有一家「小象教育科技」（深圳，9 人）是另一家极易混淆的公司；还有「河小象」（杭州河象网络，B 轮 2 亿、社保 35 人、学员数百万）是书法美育赛道。**都不是**这里说的对手。

### 现在的状态：2026 还在出新品，而且卖得动

2026 新品《字字有来历》：**100 集水墨动画课 + 300 张字卡 + 500 个汉字**（覆盖 472 个小学常用字 + 28 个衍生字，对标新课标一二年级识字量）。

它的宣发文里有一句对我们极有价值的话：

> 「没有大张旗鼓地宣传，没有请博主团，连朋友圈都没怎么发。就是默默上架，默默发货，默默……被大家买走了。」
> 「客服小姐姐跑来说：那个……《字字有来历》好像卖得特别好。我们才后知后觉地意识到。」

**这条比任何收入数字都重要**：它证明「汉字内容的付费转化」不依赖流量运营，**只要打到刚需就能自然出货**。

### 价格与促销（这是现实的一面）

| 产品 | 原价 | 实际成交价 |
|---|---|---|
| 《你好，汉字》（3–7 岁） | ¥128 | **¥59** |
| 《字字有来历》（3–6 岁） | ¥298 | **¥99** |
| 《三十六个字故事盒子》 | ¥128 | ¥88 |
| 《字然课 1+2》 | ¥58/本 | ¥29.8/本 |
| 福利组合 | — | **¥99.9 任选 4 件** |

### 对我们的含义

**① P3（家长 / 教师）这条客群不要正面碰。**
他们在儿童汉字启蒙这个细分里已有三重压制：**专业背书（殷墟官方）+ 十余年教研（2015 起）+ 价格战（¥99.9 任选 4 件）**。我们的 16 朝字形线面向成人审美与考据，不是给 3–8 岁识字用的——**这个边界要守死**，否则会被拉进一场打不赢的价格战。

**② 但要抄他两件事：**
- **把内容锚定到一个“具体的刚需场景”**。他锚的是“一年级识字量”，所以不用推广也能卖。我们目前锚的是“审美 + 好奇”，这是弱需求，必须靠内容持续唤醒。
- **水墨动画讲字形演变**——这条他已在规模化做（100 集）。说明形式本身是被市场验证过的，我们能做（已有 16 朝画卷母版），但**不能是我们的唯一形态**。

## 五 · 环境变量：这块地板在塌

这一节不是对手，是**我们定价逻辑赖以成立的前提正在变化**。

### 5.1 AI 供给已经工业化

2026 年的公开教程里，这条链路已被完全标准化：

| 环节 | 公开数据（推算/媒体口径） |
|---|---|
| 单人日产量 | **200–500 张**高清原图 |
| 素材会员成本 | ¥20–30/月（通义万相 ¥28、稿定 ¥29） |
| 售价 | 单张 ¥1–3；20 张合集 ¥9.9–19.9；50 张节日包 ¥29–49 |
| 极端价格 | 已出现 **¥0.1–0.3** 的 AI 图集包 |

（来源：AI 变现经验帖 / 副业教程站，数字偏乐观，但**量级可信**）

→ **结论没有变，但更硬了**：MEMORY 32d「不能按张卖，要按版本卖」这条判断，在 2026 不是保守而是**唯一活路**。纯视觉的均衡价已经趋近零。

### 5.2 平台正在把「数字品的交付」自己接管掉

**小红书付费笔记**（这是我们今天核到的**最重要的一条外部变化**）：

| 项 | 内容 | 来源可信度 |
|---|---|---|
| 时间线 | 2025-12 低调内测 → **2026-01-05 开启内测**（面对摄影师、画师、长文创作者招募） | ✅ 百度百科「付费笔记功能」词条 |
| 三种模式 | ① **高清原图付费下载**（面向摄影师/画师，用户付费拿无水印原文件）② 长文试读后付费解锁 ③ 笔记合集付费解锁 | ✅ 同上 |
| 关键机制 | **付费内容界面不允许截屏**；付费笔记**发布后无法编辑 / 隐藏 / 撤销付费 / 删除** | ✅ 同上 |
| 开通门槛 | 平台**邀约制内测**，需粉丝 ≥100、近 90 天无违规、**完成实名认证** | ✅ 同上（百科口径） |
| 另一套门槛说法 | 注册满 6 个月 + 近 3 个月笔记均阅读 >5000 + 垂直度达标 | ⚠️ **单一低质来源，不可作决策依据**，以站内实际为准 |
| 分成比例 | 1–50 元档抽 30% / 51–100 抽 25% / 101–199 抽 20% | ⚠️ **同上，单一低质来源，存疑** |

**这里有一条能改写我们既有判断的东西**：

> MEMORY 32d / 行业基准 v1 里最痛的一条是「**手机壁纸品类防不住复制 → 展示图能看清就等于成品 → 只能免费**」。
> 而小红书付费笔记的「**付费界面禁止截屏**」是平台级实现，**正好把这个死结解开了**。
> 也就是说：**在小红书站内，手机壁纸理论上可以重新开始卖钱。**

**但我们有两道结构性障碍，现在都不能动：**

1. **🔴 R-19 合规**：内测开通要求「完成实名认证」，而产生成交后的提现同样须实名绑定。MEMORY 45 的既定纪律是「**S1 不成交 → 不提现 → 不实名**」。启用付费笔记必然打破这条纪律。**这需要你自己判断，我不建议自动化替你选。**
2. **⏳ 另一条路（小红书店铺「电子资源」类目）半年内物理关闭**：该类目属**定向邀约（需报白）**，公开门槛为
   - 账号注册 **≥180 天**（我们 2026-10-10 才起号 ⇒ 最早 **2027-04** 才够）
   - 垂直素材类笔记 ≥30 篇
   - 粉丝 ≥1000
   - 近 90 天无版权投诉 / 站外引流 / 严重违规
   - 流水三选一：**近 12 个月任意自然月 GMV ≥6000 元**
   - 保证金：个人店 ¥1000（个人店仅可上架 PPT/简历/头像壁纸；课件教案不可）
   > ⚠️ 来源为服务商招商页面（两家口径一致，且招商门槛类信息通常为真），**但服务商有销售动机，应标注「较可信，以千帆后台实际为准」**。另有「付费代报白」渠道报价，⚠️ **不建议接触**——要营业执照 / 个体户，与 R-19 直接冲突，MEMORY 22 已冻结个体户路线。

→ **结论：2027-04 之前，「在小红书站内卖」这条路对我们是关闭的，而且是平台门槛关闭，不是我们选不选的问题。**
→ 这反过来说明：**现有策略（小红书只做种草和引流，成交落在自有站）不是偏好，是唯一可走的路。** 原来那条“引流转私域”的顾虑也可以放下了——平台压根不给你开店的门。

## 六、C 档参照：摩点 2026 已卷到什么程度

实测几个正在跑 / 刚跑完的项目档位（2026-10 抓取）：

| 项目 | 主体 | 主力档位 | 已支持份数（抽样） |
|---|---|---|---|
| 《静静的顿河》纪念版 | **人民文学出版社官方文创** | ¥450（毛边 / 刷边两档） | 22 + 65 份；评论 865 条，好评率 99.1% |
| 《戴敦邦绘西游记》特装书 | 出版机构 | ¥599 / ¥688 / ¥899（限 499） | 21 / 61 / 35 份 |
| 《罪与罚》160 周年珍藏版 | 草鹭 | 荷兰进口漆布 + 80g 无酸纸 | — |
| 《罗伯特·洛威尔传》 | 出版机构 | 限定藏书票 + 复古拍立得 | 预热中 |

**看出三件事：**

1. **回报复杂度已经卷满**：译者亲签 + 编号 + 鲜章 + 刷边 + 钤印 + 十余项阶梯解锁 + 独家画册，一个人创作者**做不动**。
2. **但主力档位其实只有几十份**：¥688 档 61 份 ≈ ¥4.2 万。**这说明我方的 C 档目标额 ¥1–1.5 万（MEMORY 50 修正值）完全现实**——不是因为众筹好做，而是因为**这个市场的主力档位销量本来就是几十份量级**。
3. **几乎全是出版社在做，个人极少。** 我们的差异化不该是“做得更像出版社”，而是“做出版社做不了的”：**个人作者身份 + 考据过程透明 + 数字即时交付**。走重特装必输。

> 注：MEMORY 记的 M9 结论（目标额 ¥1–1.5 万、¥5 万是死线）**本次调研不予修正，反而被加强**。唯一的挂起项仍是「个人发起人需手持身份证半身照 vs R-19」。
