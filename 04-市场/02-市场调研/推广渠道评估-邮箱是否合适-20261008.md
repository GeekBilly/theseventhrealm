# 第七境 · 推广渠道评估（邮箱收集是否合适）

> 用户 2026-10-08：
> 「还有一个疑问，我们是中文站，也不是外文站，网站的推广用邮箱收集来做合适么？」

---

## 一、直接回答

```
邮箱在中国大陆：
  ① 作为【交付渠道】 → 🟡 能用，但不是最优
  ② 作为【长期触达】 → ❌ 基本无效

⇒ 「用邮箱做推广」方向偏了 ⚠️
```

**⚠️ 而我们自己的页面上就有这个信号的证据**：
```
藏品页写着：「没看到就翻一下垃圾邮件箱。」
⇒ 需要教用户去垃圾箱找 ⇒ 说明这个渠道本身就不理想
```

---

## 二、中国互联网的触达现实

| 渠道 | 触达率 | 门槛 | 我们的现状 |
|---|---|---|---|
| **微信公众号** | 高 | 低（扫码关注） | ✅ 已有「蕾主任和猴班长的日常」（22 篇原创 / 132 用户） |
| **小红书** | 高 | 低 | ✅ 起号素材包已备 |
| 小红书粉丝群 | 高 | 低 | 🟡 未建 |
| 企业微信 / 个人微信 | 最高 | 中 | 🟡 有封号与人工成本 |
| 视频号 / B站 / 抖音 | 中高 | 中 | 🟡 有一条 5 秒视频 |
| 短信 | 高 | 高（成本 + 骚扰感） | ❌ |
| **邮箱** | **低** | 低 | ⚠️ **现在在用** |
| 站内会员 | 中 | 高（要开发） | ❌ |

**⇒ 国内主流是【微信生态 + 小红书】，邮箱是补充，不是主力** ✅

## 三、邮箱在什么场景下才有效

| 场景 | 有效性 | 说明 |
|---|---|---|
| 英文站 / 海外用户 | ✅ 很高 | 海外邮箱是主流 |
| 国内 To B（企业客户） | ✅ 高 | 商务沟通靠邮箱 |
| 国内开发者 / 设计师 | 🟡 中 | 部分人用 |
| **国内普通消费者** | ❌ **很低** | 除工作外基本不查 |
| 作为交付渠道（发链接） | 🟡 中 | 能用，但不如网盘/微信 |
| 作为长期触达 | ❌ 很低 | 打开率极低 |

## 四、我们现在用邮箱做的两件事，性质不同

### 4.1 领取 32 张壁纸 = **交付**

```
现在：留邮箱 → MailerLite 自动发下载链接
⇒ 这只是【交付手段】，可以接受，但不是最优
```

**问题**：
```
① MailerLite 是海外服务 ⇒ 国内收信可能延迟、可能进垃圾箱
② 门槛高：要填邮箱、要查收、要下载
⇒ ⇒ 每一步都在流失用户 ⚠️
```

### 4.2 新品开售通知 = **触达**

```
现在：留了邮箱 ⇒ 开售时群发
⇒ 这个在国内【基本无效】⚠️⚠️
⇒ 用户留了，但不会去看
```

---

## 五、建议的组合方案

```
【三层，各司其职】

第一层 · 交付（零门槛优先）
  ⭐ 主路：直接给网盘直链（夸克/百度）
     ⇒ 不用填任何东西，点开就下
     ⇒ ⇒ 转化最高 ✅
  🟡 备路：留下邮箱再发（对愿意留的人）

第二层 · 沉淀（国内最主流）
  ⭐ 引导关注【公众号】
     ⇒ 关注后自动回复：壁纸网盘链接 + 新品消息
     ⇒ 这是国内唯一「关注了就能反复触达」的低成本渠道 ✅
  🟡 小红书关注（站内触达）

第三层 · 触达
  · 公众号群发（开售时）
  · 小红书笔记 + 粉丝群
  · 邮箱作为【海外用户】与【备份】保留 ✅
```

### 5.1 具体到页面改动

```
藏品页的「留个邮箱，32 张壁纸发你」表单
⇒ 建议改成两个入口：

  ┌─────────────────────────────────┐
  │ 32 张壁纸，两种拿法             │
  │                                 │
  │ ① 直接下载（不用注册）           │
  │    [ 网盘直链 → ]                │
  │                                 │
  │ ② 关注公众号，以后新壁纸自动送    │
  │    [ 扫码关注 ]                  │
  │    ⇒ 关注后回复「壁纸」即得链接   │
  └─────────────────────────────────┘

  ⚠️ 邮箱表单可以保留，但降级为「或留邮箱，我们发给你」
```

## 六、迁移成本与优先级

| 动作 | 成本 | 收益 | 优先级 |
|---|---|---|---|
| 加一条网盘直链 | 极低（半小时） | 高（转化率立刻上升） | ⭐⭐⭐ |
| 公众号自动回复配置 | 低（1 小时） | 高（沉淀渠道） | ⭐⭐⭐ |
| 藏品页文案与按钮调整 | 低 | 中高 | ⭐⭐ |
| 建小红书粉丝群 | 低 | 中 | ⭐⭐ |
| 撤掉邮箱表单 | 极低 | —— | ❌ 不建议（海外用户还要用） |

## 七、⚠️ 一个更重要的问题：现在不是「渠道」问题，是「公域曝光」问题

```
现状：
  · 百度收录 = 0
  · 品牌词被同名游戏占满
  · 站点没有外链

⇒ ⇒ 在【没有人来】的情况下，讨论"来的人用什么渠道沉淀"
     是【第二顺位】的问题 ⚠️

⇒ 更该先做的：
  ① 公域曝光（小红书 / 知乎 / 公众号内容）
  ② SEO（ICP 备案 or 换渠道）
  ③ 然后再谈私域沉淀方式
```
