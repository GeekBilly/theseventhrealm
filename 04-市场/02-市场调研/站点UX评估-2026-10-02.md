# 站点 UX / UI 与信息架构评估

**站点**：https://theseventhrealm.com （WordPress / 子主题 `seventhrealm-child`，父主题 Twenty Twenty-Five）
**评估日期**：2026-10-02
**方法**：curl 抓取线上真实 HTML + 子主题 CSS。抓取范围：首页、`/5000years/`、全部 16 个朝代页、`/collection/`、`/faq/`、`/about/`、`/contact/`、`/en/`、`/privacy/`、5 个 404 页（`/merch` `/novel` `/anime` `/film` `/game`）、`robots.txt`、sitemap、`qijing.css`、MailerLite 表单、字体 CDN、免费 zip。
**数据前提**：本站无 GA、无转化数据（名单 0、订单 0），故**所有判断均不引用站内数据**，仅基于真实 HTML 实测 + UX 通用原则 / 同类站行业基准推断。每条标注 **【实测】** 或 **【推断】**。
**约束遵守**：以下建议均不需要营业执照、不需要注册主体、不需要付费工具。

## 0. 影响首笔收入的问题（严重度排序）

严重度按"对**首笔收入**的影响"排，不按美学排。`S0` = 阻断（有钱进来之前必须先解决）；`S1` = 严重；`S2` = 中等；`S3` = 低。

---

### S0-1 · 全站没有任何购买入口，付费品尚未上架

- **问题**：全站抓取无购物车、无结账页、无"购买/加入购物车"按钮，无任何支付通道。`/collection/` 原文写"桌面横版还在准备中"。**唯一**出现"付款"二字的地方是使用条款里的退款说明。标价仅 ¥12 / ¥19。 **【实测】**
- **影响**：**变现**。首笔收入目前不是被 UX 卡住，而是**没有可卖的东西**。P2 目标客群（¥129–499）在全站找不到任何对应商品。
- **严重度**：**S0**
- **改法**：先上架已完成的"字形线 · 桌面横版"单朝 ¥12。免注册主体的收款方式：个人可用的数字商品交付（如爱发电 / 面包多 / Gumroad / Lemon Squeezy 等**由平台做收款主体**的模式），页面只放外链，站内不接支付。合规性以你实际核实为准。

### S0-2 · 首页 0 表单、0 按钮、0 产品图

- **问题**：首页 `<input>` 仅 6 个（1 个汉堡 checkbox + 5 个导航 radio），`<button>` **0 个**，`<img>` **1 个**（logo）。全页无任何邮箱输入框、无 CTA 按钮、无壁纸预览图。 **【实测】**
- **影响**：**变现**。变现主线"内容 → 邮件名单 → 站内直卖"在**首页这一层完全不存在**。首页对转化零贡献。
- **严重度**：**S0**
- **改法**：在首页"七境之门"区块前插入 /collection/ 那段 MailerLite 嵌入码（同一段代码，直接复制），并把文案从"留邮箱"改为结果导向："免费领 32 张手机壁纸 →"。

### S0-3 · 16 个朝代页 0 邮箱捕获

- **问题**：16 个朝代页全部**无 email 表单**（`name="fields[email]"` 仅存在于 `/collection/` 一个页面）。每页约 4,473–7,357 汉字（合计实测 **92,793 汉字**），均以"← 上一朝 / 下一朝 →"和"藏品 · 把五千年带在身边 →"结尾。 **【实测】**
- **影响**：**变现**。这是站点最核心的流量承接资产，却完全不产名单。搜索引擎带来的读者读完一页即离开，无法沉淀。
- **严重度**：**S0**
- **改法**：把同一段 MailerLite 嵌入码追加到朝代页正文末尾（"读到这里，要不要把十六朝带在手边"），诱饵与 /collection/ 一致。**这是本次评估中改动最小、影响最大的一条。**

### S0-4 · 免费诱饵与"留邮箱"价值完全重叠，留邮箱动机为 0

- **问题**：免费 zip 是**直接下载链接，无需邮箱**（页面原文："不用留邮箱，点下面的按钮就存到你的设备"）。而表单承诺的回报是"顺手也把 32 张手机壁纸发你一份"——**同一批文件**。表单位置在下载链接**之后**。 **【实测】**
- **影响**：**变现**。用户已拿到东西才看到表单，且表单给的是他已有的东西。名单 0 人符合这个结构，而非偶然。
- **严重度**：**S0**
- **改法**：给邮件独有物。免费 zip 保持可直下，表单改为给"桌面横版首发价 + 抢先预览 + 单朝试发一张"。让留邮箱**换来拿不到的东西**。

### S0-5 · 首屏 5 秒测试失败：无价值主张

- **问题**：首屏 `<h1>` = **「道境」**，副标 = "天道酬勤 / 道法自然"，然后"七境之印""展卷"。全站首屏**没有一句话**说明这是中国历史、有免费壁纸、有商品。`meta description` 也只说抽象"原创 IP"。 **【实测】**
- **影响**：**流量 + 变现**。新访客与搜索引擎都无法在 5 秒内判断"这是什么、对我有什么用"，跳出率上升、品牌词以外无从记忆。 **[推断：跳出率影响依据 NN/g "5 秒测试"与首屏价值主张通例]**
- **严重度**：**S0**
- **改法**：h1 下加一行说人话的副标，例如"十六朝中国历史长卷 · 32 张免费手机壁纸"；再加**一个**主 CTA 按钮指向 `/collection/`，文案"免费领 32 张手机壁纸"。保留"道境"作 h1 但让它被副标解释。

### S1-1 · 主导航 13 项中 5 项是死链（404）

- **问题**：实测 `<ul class="nav-root">` 直系 13 个 `<li>`：道境 / 上下五千年 / 传说与三代 / 秦汉魏晋 / 隋唐两宋 / 元明清·近代 / 藏品 / 关于我们 / **周边 / 小说 / 动漫 / 电影 / 游戏**。后 5 项（`/merch` `/novel` `/anime` `/film` `/game`）实测**全部 HTTP 404**。代码里已用 `class="todo"` 且 CSS 会渲染"未启"角标——说明已知未上线，但仍是 `<a href="/merch">` 真链接。首页"七境之门"4 张卡片同样指向 404。 **【实测】**
- **影响**：**流量 + 变现**。13 个一级导航里 5 个（38%）把用户送进 404，且它们排在导航末段、与"藏品"相邻；用户误点概率高，直接摧毁可信度。
- **严重度**：**S1**
- **改法**：`<a class="todo" href="/merch">` → `<span class="todo">`（CSS 样式已现成，无需改设计）。首页 4 张"未启"卡片同样去链接化。收益立刻、改动 5 分钟。

### S1-2 · 404 页不套用子主题，暴露默认模板与死链页脚

- **问题**：404 页**不含** `nav-root`（无自定义主导航）、**不含**自定义页脚；加载父主题 `navigation/style.min.css`；页面标题显示 **"（无标题）"**；页脚链接实测为 8 个 `href="#"` + `cn.wordpress.org`；正文列出"博客 / 关于 / 常见问题 / 作者 / 事件 / 商店"。 **【实测】**
- **影响**：**变现 + 流量**。从导航/首页 5 个死链进来的用户，落在一个看起来不像本站、页脚全是死链的页面，且**没有回到 `/collection/` 的路径**。
- **严重度**：**S1**
- **改法**：在子主题加 `404.php`，直接复用现有 header/导航/页脚，正文给"免费领 32 张壁纸"主 CTA + "上下五千年"入口。

### S1-3 · 字体 `@import` 造成第三方串行阻塞（实测 2.5–4.7 秒）

- **问题**：`qijing.css` 第 5 行 `@import url('https://fonts.loli.net/css2?family=Ma+Shan+Zheng&family=Noto+Serif+SC...')`。实测该字体 CSS 返回 **294 条 `@font-face`、327,389 字节（gzip 后 29,433 字节）**，多次请求耗时 **2.48 s / 3.88 s / 4.66 s**。加载顺序为 HTML → qijing.css → 字体 CSS → 294 个 `gstatic.loli.net` 子集。 **【实测】**
- **影响**：**流量**。`@import` 使请求串行化，浏览器需等该表返回才能完成 CSSOM，首屏渲染被推迟；且整站排版依赖一个**第三方非官方镜像**，其不可用时全站回退字体，直接影响"5 秒内明白这是什么网站"。 **[推断：@import 阻塞渲染为浏览器标准行为]**
- **严重度**：**S1**
- **改法**：删掉 CSS 里的 `@import`。字体栈里已有 `'Songti SC','STSong','KaiTi'` 系统字体，**零成本方案**是直接不引外部字体；若要保留，改为 `<head>` 内 `<link rel="preconnect">` + 非阻塞加载，并给字体 URL 加 `&text=` 仅子集化首页用字。

### S1-4 · 对比度大面积不达标（实测 1.71:1 – 2.89:1）

- **问题**：正文与导航大量使用半透明墨色。实测（白底 alpha 合成）：`rgba(26,26,24,.45)` = **2.89:1**，`.42` = 2.65，`.38` = 2.38（导航 `.todo` 项），`.35` = **2.20**，`.3` = 1.94，`.25` = **1.71**。使用处包括 `.trigram`、`footer .f-links .sep`、副标题、`.sub-g` 分组标签。 **【实测】**（WCAG AA 正文要求 4.5:1）
- **影响**：**流量 + 变现**。中老年与移动端强光下阅读困难，P3 教育型（家长/教师）首当其冲；这些低对比元素多为导航辅助文字，直接影响路径发现。
- **严重度**：**S1**
- **改法**：把作正文使用的 alpha 提到 `.55` 以上（≈4.5:1），或统一改用已达标的 `--ink2:#6b675f`（实测 **5.63:1**）。`--cinnabar:#b03826` 实测 6.11:1 可放心用。

### S1-5 · 全站 0 结构化数据、0 面包屑

- **问题**：抓取全部页面，`application/ld+json` 出现 **0 次**——无 `Article`、无 `FAQPage`、无 `BreadcrumbList`。全站也无任何面包屑（HTML 与 CSS 均无 `breadcrumb`）。`/faq/` 有 5 个 h2 的问答结构但未标记 FAQPage。 **【实测】**
- **影响**：**流量**。一个以自然搜索为唯一获客渠道的站，放弃富摘要（FAQ 折叠、面包屑路径）等于主动降低 SERP 面积与点击率；16 个朝代页属典型 Article，白白让出机会。 **[推断：富摘要提升 CTR 为搜索行业通例]**
- **严重度**：**S1**
- **改法**：FAQ 页加 `FAQPage`，朝代页加 `Article` + `datePublished/modified`，全站加 `BreadcrumbList` 并配可见面包屑（上下五千年 › 唐）。纯代码，零成本。

### S1-6 · `/collection/` 的搜索摘要写着"付费品还在准备中"

- **问题**：`/collection/` 的 `<meta name="description">` 是**从正文自动截取**的，实测内容为"藏品 第七境 · 五千年，做成可以放在手边的东西 手机壁纸现在就能免费领…**桌面横版还在准备中** —— 想第一…"。 **【实测】**
- **影响**：**变现**。这是变现页在 Google/百度上的展示文案，等于在搜索结果里宣布"没得买"。同时它是关键词堆叠式摘要，点击率受损。
- **严重度**：**S1**
- **改法**：手写 `meta description`，突出"32 张免费手机壁纸 · 即下即用"与已有商品的价格，不提"准备中"。

### S2 级（重要，但排在首笔收入之后）

**S2-1 · 16 朝页模板一致性：同构良好，但 0 张配图**  **【实测】**
- 16 页结构高度同构（每页 33 个链接、h1 唯一、h2 数 5–12 个、正文 4.5k–7.4k 字），**无模板缺陷、无内容空洞**，这点做得很好。
- 但 **16/16 页零配图**，`/5000years/` 索引页同样零配图。卖的是壁纸（视觉产品），目标客群 P1 是 20–35 岁审美型女性，内容页却**纯文字无任何视觉证据**。
- **影响**：**变现**。P1 无法在购买前看到产品长什么样；内容页停留与分享动机弱化。
- **改法**：每朝页首图用该朝已有的金句壁纸缩略图（现成素材），顺带成为产品展示位；alt 填朝代 + 壁纸名。

**S2-2 · 移动端只有 1 个断点（640px），无平板区间**  **【实测】**
- CSS 内 `@media` 实测仅 `max-width:640px` 一种。641–1024px（iPad 竖屏、小平板）走**完整桌面导航**：13 个一级项 + 5 个下拉 + `letter-spacing:5px` + `font-size:clamp(16px,2.2vw,19px)`。
- 附带问题：移动端面板用 `nth-child(-n+2)` / `nth-child(n+7)` 硬编码控制布局，13 个子项里 **11 个变成通栏独占一行**（含 5 个死链），高度远超 CSS 注释自称的"约 300px 一屏放下"。 **【实测 + 推断】**
- `body{overflow-x:hidden}` + 注释自承"导航用 100vw 硬撑而多出约 8px 横向溢出"——**溢出被隐藏而非被修复**。
- **影响**：**流量**。平板用户是历史内容的高价值阅读设备，导航拥挤与横向截断损伤浏览。
- **改法**：加 `@media(max-width:1024px)` 断点，把导航切到汉堡方案（CSS 已现成，只需改断点值）。顺带移除 `overflow-x:hidden` 验证是否仍溢出。

**S2-3 · 触控目标小于 44×44px**  **【实测】**
- 汉堡按钮 `.nav-burger` = **38×28px**；移动端子菜单箭头 `.ns-btn` = **26×34px**；一级导航项 `padding:7px 5px`（实测高约 30px）；子菜单项 `padding:8px 6px`（约 31px）。
- **影响**：**流量**。移动端误触率高，尤其"点箭头展开子菜单"与"点链接跳转"紧邻。 **[推断：44×44px 为 WCAG 2.5.5 / Apple HIG 通例]**
- **改法**：`.ns-btn` 提到 `44×44`，汉堡提到 `44×44`；导航项 padding 加到 `12px 8px`。

**S2-4 · 字号偏小且衬线 + 大字距**  **【实测】**
- CSS 实测存在 `font-size:9px`（页脚分隔符）、`9.5px`（"待建"角标）、`10px`（"未启"角标）、`11.5px`（`.sub-g` 分组标签）、`12px`（`.sanshi .en`、若干正文性文字）。正文字体为 `'Noto Serif SC'` 衬线，并大量 `letter-spacing:2px–6px`、`.trigram{letter-spacing:15px}`。
- **影响**：**流量**。9–12px 的衬线中文已接近不可读；大字距在中文里割裂词形，降低扫读效率。
- **改法**：作正文用的字号下限提到 14px，9–10px 只留纯装饰符号；正文 `letter-spacing` 收到 0–1px。

**S2-5 · 无语义地标、标题层级跳级、图片无尺寸**  **【实测】**
- 除 404 页外，**全站无 `<main>` 元素**。`/5000years/` 索引页层级为 `h1 → h3`（16 个朝代是 h3，跳过 h2——因为卡片标题在用 h3）。
- 全站图片 **0 个 `width`/`height` 属性、0 个 `loading="lazy"`**。logo 为 1920×260 / **234,780 字节**且 `.logo-img{width:100%;height:auto}`，无尺寸预留。
- **影响**：**流量**。缺 landmark 影响读屏与 SEO 结构理解；logo 无尺寸预留造成 CLS，直接扣 Core Web Vitals 分数。 **[推断：CLS 影响排名为 Google 已公开的评估项]**
- **改法**：内容区包 `<main>`；索引页朝代标题改 h2（或整体下移一级）；logo 加 `width/height` 与 `fetchpriority="high"`；`/collection/` 的 3 张商品图加 `loading="lazy"` + 尺寸。

**S2-6 · `/contact/` 无表单；全站最高标价 ¥19**  **【实测】**
- `/contact/` 只有 Cloudflare 混淆的 mailto 链接，无表单。全站出现的价格仅 ¥12 / ¥19。**没有任何 ¥129–499 价位的商品或询价入口**。
- **影响**：**变现**。P2 考据型（25–40 男性，¥129–499）在整站**无对应供给**，也无低摩擦的沟通入口；P3 教育型同样无产品。
- **改法**：`/contact/` 加一个 3 字段表单（免注册可用静态表单服务或直接 mailto 预填 `subject/body`）；并在 `/collection/` 增加"定制/授权/教育用途"入口承接 P2/P3 询价。

**S2-7 · 无 hreflang，且中英页对 AI 的表述互相矛盾**  **【实测】**
- `/` 与 `/en/` 之间**无 `hreflang`** 标注。
- 更值得注意的是内容冲突：`/en/` 写 **"Nothing here is generated by AI"**，而 `/about/` 写"一个人的审美与判断，**加一套 AI 工具链**"。`/about/` 同时署名笔名"第七思维"。
- **影响**：**变现**。P2 考据型对来源与生成方式高度敏感；两页表述不一致会被读成回避。hreflang 缺失影响英文页收录。
- **改法**：统一口径（建议保留 `/about/` 的坦率表述，把 `/en/` 的绝对句改成具体说明"哪些环节由 AI 辅助、哪些是人工考据"）；两页互加 `hreflang` + `x-default`。

**S2-8 · 页脚 ICP 备案号是占位符**  **【实测】**
- 全站页脚显示 **"X ICP备00000000号"**，链接指向 `beian.miit.gov.cn`。**这是占位符，不是真实备案号。**
- **影响**：**变现**。中文站访客与任何付款方看到明显假号会立刻降低信任；对一个即将收款的站，这是负面信任信号。（另：在"不能注册主体"的约束下，**该号无法补齐**。）
- **改法**：**删除该行**，不要保留占位。信任感由"一个人创作者 + 明确联系邮箱 + 退款条款"承担，这些页面已有，写得也好。

**S2-9 · MailerLite 表单 `target="_blank"`，站内成功态可能不显示**  **【实测 + 推断】**
- 表单 `action="https://assets.mailerlite.com/jsonp/2674672/forms/.../subscribe"` 且 **`target="_blank"`**。页面内有"已发送 / 32 张壁纸的下载链接已经发到你邮箱"成功文案。
- **影响**：**变现**。若 `universal.js` 未接管，原生提交会在**新标签页**打开 JSON 响应，用户看到白屏/JSON 而非"已发送"，会以为失败并重复提交或离开。 **[推断：取决于该 JS 是否成功加载并接管]**

## 2. Top 5 优先动作（按"改动小 × 影响大"排）

### ① 把 `/collection/` 的邮箱表单复制到首页 + 16 个朝代页
同一段 MailerLite 嵌入码直接粘贴即可，无需新开发。这是唯一一条"内容 → 名单"的通路，目前 17 个页面里 0 个有捕获点。**改动最小、影响最大。**

### ② 给"留邮箱"一个拿不到别处的理由
现在免费 zip 无需邮箱即可下载，表单却承诺同一批文件，留邮箱的增量价值为 0。改为邮件独有物：桌面横版**首发价 + 抢先预览 + 单朝试发一张**。免费 zip 保持裸链。

### ④ 首页首屏加一句人话 + 一个主 CTA
h1「道境」下加副标"十六朝中国历史长卷 · 32 张免费手机壁纸"，并加**唯一一个**主按钮指向 `/collection/`："免费领 32 张手机壁纸"。同时把"七境之门"提到"三释"长文之前。

## 3. 最严重的一个问题

> **变现链路在页面上根本不存在——但这不是"优化不够"，而是"结构没接上"。**

具体是三层叠加：**（a）** 全站没有任何购买入口，唯一的付费品"桌面横版"仍标注"还在准备中"，所以首笔收入目前**没有商品可卖**；**（b）** 承载 92,793 汉字内容的首页与 16 个朝代页**零个邮箱捕获点**，唯一表单藏在 `/collection/` 一页里；**（c）** 即便用户走到那个表单，免费 zip 无需邮箱即可直接下载，而表单承诺的正是同一批文件——**留邮箱的动机被设计成了 0**。

三层里 **(c) 最容易被误判为"流量不够"**：名单 0 人会看起来像获客问题，但从 HTML 看，这是一个**结构性归零**——就算明天来一万个访客，按现有页面结构，名单仍会接近 0。修复顺序应是 **① 铺开捕获点 → ② 给邮件独有物 → ③ 让商品可买**，其中前两步加起来不到一小时，且不需要任何预算或注册主体。
