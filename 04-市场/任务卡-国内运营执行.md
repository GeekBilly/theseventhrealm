## 一、注销旧号：照着点（共 5 分钟，人工）

> **为什么这一步不自动化**：注销是**不可逆**操作，中途有短信验证码与人脸/身份校验，
> 且 iPhone Mirroring 是视频流，脚本无法确认当前页面状态——点错的代价无法挽回。见 §六。

### 1.1 小红书（已确认实名 → 必须注销）

```
我 → 右上齿轮（设置）→ 账号与安全 → 划到最底 → 注销账号
→ 读完风险提示 → 按提示完成验证 → 提交
```

### 1.2 抖音（未实名，一并注销）

```
我 → 右上三横 → 设置 → 账号与安全 → 注销账号 → 按提示提交
```

### 1.3 提交**前**的四个检查（别漏）

- [ ] 无未提现余额 / 薯币 / 创作激励
- [ ] 会员不在有效期内（在的话先取消续费并等当期结束）
- [ ] 无未完结订单、未结案的品牌合作
- [ ] **想留的内容已备份**（注销后永久清除，**无任何恢复渠道**）

### 1.4 提交**后**的唯一纪律

> ⚠️ **冷静期内一次都不要登录。**
> 扫码、密码、短信任一种成功登录都会**立即中止注销，前功尽弃**，要重新等 10 天。
>
> ⚠️ **尤其别为了「看看注销完没」去登录** —— 想验证的这个动作本身，就是中止条件。
> 这是本流程最容易踩的坑：人总想确认进度，而确认的方式恰好会毁掉进度。
> 正确做法：**什么都别做，等 2026-10-10 的那条提醒**。
>
> 时长：审核 1–3 工作日 + 冷静期（各方口径 7/15/30 天不一，**以 App 内提示为准**），合计约 10 天。
> 冷静期内主页仍可被访问，但点赞/评论/私信/收藏全部锁定——看到也别慌，属正常。
