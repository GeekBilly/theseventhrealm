# 客户库（订阅者）· 04-市场/05-客户库

**一句话**：所有攒到的邮箱都落在同一个 CSV 里、分好组；开售那天导出一个名单，直接导进 MailerLite 按组群发。
数据在自己硬盘上，零月费，不依赖任何平台的存续。

---

## 一、文件清单

| 文件 | 作用 |
|---|---|
| `客户库.csv` | **唯一数据源**。Excel / WPS / Numbers 都能直接打开看 |
| `粘贴邮件到这里.txt` | 入库缓冲。把邮箱里复制出来的邮件信息粘进去 |
| `留痕归档/` | 每次粘贴的原文自动留痕（＝「他当初确实主动来信订阅」的证据，别删） |
| `11-运营/scripts/manage-contacts.py` | 入库 / 分组 / 查询 / 导出 / 退订 / 删除，全在这一条命令里 |

---

## 二、分组口径（唯一权威，改这里要同步 MailerLite）

| 分组名 | 谁进来 | 开售时发什么 |
|---|---|---|
| `桌面横版开售` | 在藏品页点「留邮箱，收开售通知」的人（主题含「桌面/横版/开售」） | **字形线主利润品（¥129–499）的开售通知** —— 这是最值钱的一个组 |
| `壁纸领取` | 领免费手机壁纸的人（主题含「壁纸/领取/金句」） | 免费品交付信 + 后续新品通知 |
| `众筹意向` | 明确问过众筹/实体书/出版的人 | 众筹开机时的第一波种子用户 |
| `一般订阅` | 主题没匹配上任何关键词的兜底 | 只发大节点（开售、众筹） |

三条铁律：

1. **组名必须与 MailerLite 里的组名一字不差**。同一个组名打错一个字，导入后会裂成两个组，群发就会漏人。
2. 一个人可以同时属于多个组（CSV 里用 `;` 分隔），例如既是壁纸用户又是开售意向 —— 导出时按组取，不会重复发。
3. 分组默认**由邮件主题自动判定**（脚本里的关键词规则）；判错了用 `--group` 强制指定，或直接在 Excel 里改那一格。

## 三、字段口径

| 列 | 说明 |
|---|---|
| `邮箱` | **唯一键**（大小写不敏感）。重复导入只合并，不会产生两行 |
| `称呼` | 从「发件人: 张三 \<a@b.com\>」里自动提取；没有就留空 |
| `分组` | 多组用 `;` 分隔 |
| `来源` | `藏品页-mailto` / `藏品页-表单` / `手工` / 其他渠道 |
| `同意时间` | **合规证据**：他什么时候主动来信订阅的。不要留空 |
| `状态` | `已订阅` / `已退订` |
| `退订时间` | 退订时自动填 |
| `备注` | 脚本会把原邮件主题记在这里，方便回溯这人当初是从哪进来的 |
| `更新时间` | 最后一次改动的时刻 |

> **退订的人不删行**，只改 `状态`。发信时自动排除，但记录留着 —— 证明「他退订过、我们没再发」，这是被投诉时最有用的一行。

## 四、日常入库（三条路线）

### 路线 A · 现在就能用（半自动，零成本）★ 当前主路径

1. 打开 sina 邮箱，逐封点开订阅邮件，把「**发件人 / 主题 / 时间**」三行整段复制
2. 粘进 `04-市场/05-客户库/粘贴邮件到这里.txt`（说明行之下）
3. 跑一次命令：

```bash
python3 11-运营/scripts/manage-contacts.py import-mail          # 看完就入库
python3 11-运营/scripts/manage-contacts.py import-mail --dry    # 只想先看一眼
```

4. 脚本自动：抽邮箱 → 按主题分组 → 去重 → 写库 → **清空缓冲 + 原文留痕**。

粘贴格式很宽松，认下面任意一种，混着贴也行：

```
发件人: 侯炳利 <houbingli@example.com>
主题: 订阅桌面版开售通知
时间: 2026年9月30日 15:15
```

```
zhang@163.com 我想问众筹实体书什么时候开始
```

```
lisi@qq.com
wang@126.com
```

自己的地址（`hello@theseventhrealm.com`、sina 个人邮箱）与 `noreply@` 类地址会被自动跳过，不会污染库。

### 路线 B · 全自动（需一次性配置邮箱账号）——**暂未启用**

原理：sina 邮箱支持 IMAP，让脚本定时去收件箱把主题匹配的订阅信拉出来自动入库。

需要你做的（一次性，约 5 分钟）：在 sina 邮箱网页版的设置里**开启 IMAP/客户端服务并生成客户端授权码**，把授权码交给我存进钥匙串。

**为什么现在不做**：这要动你的个人邮箱账号设置，影响面比入库本身大；且 sina 免费邮箱对 IMAP 有频率限制。等你哪天觉得「每周手动粘一次」烦了，说一声我就配 —— 脚本会做成「只读拉取、失败即停、不重试」。

本库现在的角色是两件事：**自有备份**（平台限制或涨价时随时能搬走）+ **分组基准**（组名以本库为准）。

#### ⚠️ MailerLite 五条硬规矩（踩过的坑，改配置前先读）

| # | 规矩 | 后果 |
|---|---|---|
| 1 | ⭐ **表单里的 reCAPTCHA 绝不能勾** | 大陆网络加载不出 reCAPTCHA → 提交**静默失败**（页面无报错，访客以为成功了） |
| 2 | ⭐ **双重确认（Double opt-in）保持开启** | **订阅者必须点确认信才进组、才触发自动化** —— 所以"填了没收到交付邮件"多半是没点确认信 |
| 3 | 域名认证已完成（SPF 合并进现有记录 + DKIM 走 CNAME **灰云** + 验证用 TXT） | 域名记录被动过就要重跑验证 |
| 4 | 后台「Privacy policy」**显示文字与链接地址是两个字段** | 只填一个，页面上就会缺一块 |
| 5 | ⭐ **现行＝静态嵌入**（HTML 结构与样式写死在页面里）→ **后台改表单不会同步到站点，必须重贴嵌入码**；动态版（`universal.js` + `div.ml-embedded`）才实时同步 | 改完后台以为生效了，其实线上还是旧的 |

> 附：三个 MailerLite 静态域（`assets.mailerlite.com` / `groot.mailerlite.com` / `assets.mlcdn.com`）本机实测均 200、~0.9s。

### 明确不做：把订阅信转发到 AI 邮箱自动读

技术上可行，但客户邮箱是个人信息，转给第三方处理者要先写进隐私政策并取得同意 —— 为省一步操作引入合规敞口，不划算。

## 五、开售当天怎么发（SOP）

```bash
# 1. 导出「桌面横版开售」这一组（已退订的自动排除）
python3 11-运营/scripts/manage-contacts.py export \
  --group 桌面横版开售 \
  --out "04-市场/05-客户库/导出-桌面横版开售-$(date +%F).csv"
```

2. MailerLite → **Subscribers → Groups** → 新建组 `桌面横版开售` → **Import** → 上传这个 CSV（字段映射 `email` / `name`）
3. **Campaigns → Create campaign** → 收件人选 `桌面横版开售` 组 → 填主题与正文（模板见 `11-运营/REQ-2026-09-30-06-手机壁纸自动交付-执行申请单.md` 第 3 步配套）→ 发送
4. 免费版限制记牢：**订阅者 250 人 / 月发 2500 封 / 邮件底部强制带 MailerLite logo**

**退路（平台不可用时）**：用自己邮箱密送分批发 ——

```bash
python3 11-运营/scripts/manage-contacts.py bcc --group 桌面横版开售 --batch 50
```

会按 50 人一批打印密送名单。缺点是容易被判垃圾邮件、没有自动退订链接，**只在没有平台可用时才用**。

## 六、退订、删除与合规

| 情况 | 命令 |
|---|---|
| 有人回信说「退订」 | `manage-contacts.py unsub --email a@b.com --reason "回信退订"` |
| 有人要求删除其个人信息 | `manage-contacts.py purge --email a@b.com`（先加 `--yes` 前会提示一次） |

- 每次群发都**必须带退订方式**（MailerLite 会自动加，密送方案要手动在正文写「回『退订』即可」）。
- 不把邮箱用于交付与开售通知之外的用途，**不出售、不转交第三方**。
- 第三方数据处理条款见 `11-运营/REQ-2026-09-30-06-手机壁纸自动交付-执行申请单.md`「隐私政策增补」，等表单上线时一并发布到 id=88。
