## 〇、一句话结论

**积分：0 分。** 这个功能全程不碰 ImageGen / VideoGen，全是本地文本、代码与脚本。

**人民币：0 元。** 16 朝讲解约 6,500 字，腾讯云 TTS 新用户免费额度（精品 800 万字符／
大模型 10 万字符／超自然 2 万字符）**绰绰有余**；即便自己贴钱，精品音色也只有 **0.2 元**。

**所以这不是一个钱／积分问题，是一个「工作量 + 合规」问题。** 真正的成本是：
① 16 朝讲解文案要新写（约 6,500 字）；② 三条合规红线必须先过（见 §四）；
③ 国内浏览器 GPS 定位成功率不高，方案要留兜底（见 §五）。

## 二、人民币账

### 2.1 语音合成：三种音色都在免费额度内

腾讯云语音合成（2026-10 现行价，来源：cloud.tencent.com/document/buy-guide/1073/34112）

| 音色档 | 后付费单价 | 新用户免费额度 | 本项目用量 | 是否收费 |
|---|---|---|---|---|
| 精品音色 | 0.3 元/万字符 | **800 万字符**（3 个月） | ~6,500 字符 | **0 元** |
| 大模型音色 | 1.2 元/万字符 | **10 万字符**（3 个月） | ~6,500 字符 | **0 元** ✅ 推荐 |
| 超自然大模型音色 | 6.5 元/万字符 | **2 万字符**（3 个月） | ~6,500 字符 | **0 元** |
| 标准音色 | 0.2 元/万字符 | 同上 800 万 | ~6,500 字符 | **0 元** |

> 免费资源包自领取起 3 个月有效，**一个账号只能领一次**。

**三个月后再补做的边际成本**：精品 0.3 元/万字符 → 6,500 字符 = **0.2 元**。可忽略。

### 2.2 🔴 必须避开的做法：**实时调用 TTS API**

若改成「每次访问实时合成」，按日 100 人 × 平均 400 字 = 4 万字符/日：

| 音色 | 日成本 | 月成本 |
|---|---|---|
| 精品 | 1.2 元 | **≈36 元** |
| 大模型 | 4.8 元 | **≈144 元** |

⇒ **必须预生成静态音频文件，绝不做实时合成。** 这也是唯一符合本项目「能本地就不上线」原则的做法。

### 2.3 存储与带宽

| 项 | 估算 |
|---|---|
| 16 个 m4a（64 kbps AAC，每朝 90–120 秒） | **约 15–27 MB** |
| 月 1,000 次播放的流量 | 约 1.7 GB（CF 缓存后可大幅下降） |

GoDaddy 空间无压力。⚠️ 国内直连 GoDaddy 取大文件偏慢 —— 若要上，建议配一条 CF Cache Rule
缓存 `/wp-content/uploads/*.mp3|m4a`（属 CF 配置改动＝C 档，需另开申请单）。

## 三、技术方案（三档）

### A 档 · MVP（0 积分 / 0 元 / 改动最小）

- 独立静态页（走 `/collection/` 同款做法，**绕开 WP 编辑器与插件权限**，见 MEMORY §C27）
- 定位：`navigator.geolocation` 取经纬度 → **前端本地**用内置古都坐标表算最近城市
  （Haversine，不调任何地图 API ⇒ 0 成本、0 测绘合规风险）
- 语音：**Web Speech API 实时朗读**（浏览器原生，0 存储 0 上传）
- 兜底：定位失败/拒绝 → 弹出古都列表手动选

**优点**：一天能出，零外部依赖。**缺点**：音色取决于用户设备（iOS Safari 长期有 bug），
与「第七境」水墨调性不完全匹配。

### B 档 · 成品（0 积分 / 0 元 / 推荐）

- A 档的全部，但语音换成**预生成的 16 个 m4a**，上传媒体库
- 播放器支持进度、暂停、语速；**无音频时自动降级到 A 档的浏览器朗读**（双轨）
- 文案每朝 350–450 字（约 90–120 秒），16 朝共约 6,500 字

### C 档 · 增强（会动到合规与积分，暂不建议）

- 加地图展示：🔴 只能用**腾讯地图 / 高德 / 百度 / 天地图**（国内合规白名单），
  坐标必须 **GCJ-02**；Google / OSM / Mapbox 一律不可
- AI 实时生成个性化讲解：会持续消耗大模型调用，且内容不可控（引用溯源铁律 MEMORY §F33 难守）
- 多语种讲解

## 四、🔴 合规红线（先过这三条再谈开工）

1. **地图资质**：本项目**不展示任何地图**即可完全规避。
   一旦要显示底图/打点，就必须用合规白名单服务、用 GCJ-02 坐标、且不得标注涉密与敏感区域。
   ⇒ **本调研推荐方案全程不出现地图。**
2. **个人信息保护法（PIPL）**：精确定位属**敏感个人信息**，必须：
   ① 用户主动授权（Geolocation 自带弹窗）；② **坐标只在浏览器本地计算，不上传、不落日志**；
   ③ 隐私政策（`03-页面/pv-privacy.html`，现 1,460 字）补一段「位置信息」说明。
   ⇒ 改隐私政策＝改线上内容，属 C 档，需另开申请单。
3. **Apple 语音的商用授权**：本机实测 `say -v Tingting` 可出中文（样张见
   `10-规划/定位语音-调研-20261005/Tingting-样张-商.m4a`，22 秒 / 180 KB / 64 kbps）。
   但 macOS 系统语音用于**对外商业分发**存在授权灰区。
   ⇒ **站内正式上线建议走云 TTS（免费额度内），本地 `say` 只用于试听与内部校样。**

> 另注：整个功能属「发布上线」类改动，按 MEMORY §A2 需先出执行申请单
> （`状态：待批/已执行/已验收/已否决`），本调研不等于开工。

## 五、国内定位的现实坑（决定了兜底设计）

| 环境 | HTML5 定位表现 |
|---|---|
| iOS Safari / 微信 iOS | 正常 |
| **国内 Android Chrome** | 🔴 **常失败或超时**（缺少 Google 定位服务） |
| 微信内置浏览器 | 需 JS-SDK `wx.getLocation`，**要求认证服务号**（当前不具备） |
| 桌面浏览器 | 多半要靠 IP/Wi-Fi 定位，精度到城市级 |

⇒ **方案必须以「定位失败」为常态来设计**：
- 主路径：Geolocation → 最近古都
- 兜底：手动选城市（按省份分组 + 热门古都一键点）+ localStorage 记住上次选择
- 未来增强：`request.cf.city`（Cloudflare Workers 免费版即提供城市级 IP 推断）做「猜你在…」，
  ⚠️ 需要动 CF 配置＝C 档
