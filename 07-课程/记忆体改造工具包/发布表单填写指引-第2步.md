## 二、分类怎么选（已根据平台实际选项定稿）

### 市场展示分类（可多选）→ 选「**开发工具**」＋「**效率工具**」

平台实际选项：OPC·一人公司 / 办公协同 / 二十一 / **开发工具** / 投资理财 / 效率工具 / 内容创作 / 信息资讯 / 教育学习 / …

**选两个：开发工具 ＋ 效率工具。** 一个精准（开发者），一个宽（泛效率人群），双覆盖。
**不要选「办公协同」** —— 那是团队协作场景（会议、审批、多人文档），
而本技能是**单人**使用的工具；分类错配会带来「装完发现不是我想的那样」的差评，
对个人开发者的信誉伤害比少一个分区大得多。

选「开发工具」的理由：

1. 技能本体是脚本化静态分析（扫目录、算体量、查失效引用），本质是工程辅助工具
2. 调研里付费意愿最强的人群＝重度 AI 长项目用户，他们逛的就是这个分区
3. 「内容创作」不对口 —— 尽管做内容的人会买，但这个产品不是创作工具
4. 「教育学习」不选 —— 会引出课程资质审核的联想，且产品是工具不是课
5. 🔴 **「投资理财」绝对不选**（R-19 红线）
6. 「OPC·一人公司」不选 —— 那是企业向／Buddy 应用的分区，个人技能挂进去不对口

> 免费版与付费版的这组分类**必须完全一致**，否则用户从免费版点进去找不到付费版。

### 服务类目（多选，至多 5 个）→ 选「**办公**」＋「**计算器**」＋「**信息查询**」

平台实际结构：一级（物流服务 / 教育服务 / 交通服务 / 生活服务 / 餐饮服务 / 旅游服务 / **工具** / 商业服务）
→ 「工具」下的二级：**记账 / 日历 / 天气 / 办公 / 图片处理 / 计算器 / 报价·比价 / 信息查询**

选这三个，对应技能实际做的三件事：

| 选它 | 因为技能实际在做 |
|---|---|
| **办公** | 产出体检报告与改造稿文档（Markdown 交付物） |
| **计算器** | 统计字符数、token 估算、改造前后降幅测算 |
| **信息查询** | 读取项目文件、检出孤儿文件与失效引用 |

**不选**：图片处理（无图像处理）、报价·比价（不涉交易）、记账/日历/天气（无关）、
以及一级里的**教育服务**（会引出资质审核联想）。

> 免费版与付费版的这三个类目**也要完全一致**。

## 三、能力介绍 · 增强版（可直接替换自动填入的内容）

### 免费版（增强版 A）

```
只读体检你的长项目记忆文件：算出体量、多少是真用得上的、剩下多少在每轮白付，
并给出逐节处置表、孤儿文件清单与失效引用清单。

不修改、不删除、不移动任何文件；不联网、不上传。
结论是建议，不是判决——哪条该留哪条该沉，由你拍板。
```

### 付费版（增强版 B）

```
体检并改造你的长项目记忆文件：算出三个数字，分清「每次都用得上」与「以防万一」，
生成「保留／下沉／归档」三段式改造稿，并给出改前改后的 token 对照与三个模板。

全程只读，绝不碰你的原文件。
不替你报「每月省 X 元」——除非你提供每天对话轮数与每千 token 单价，
否则只给百分比与 token 绝对值。
```

## 六、顺序建议

**先传免费版 → 提交审核 → 再传付费版 → 提交审核。**
理由：开通收款账户的硬条件是「**至少 1 个通过审核的技能或专家**」，
免费版先过审就能把收款通道打开，付费版随后就能直接定价发布。
