```
【适合谁】
同一个项目已经做了好几周甚至几个月的人；以及反馈「AI 老是忘事、每次都要重新交代背景、
越用越慢、额度掉得莫名其妙」的人。

【交什么材料】
不需要任何材料。只要你的项目里有记忆／规则文件（如 MEMORY.md、CLAUDE.md、AGENTS.md，

【拿到什么结果】
1. 三个数字：记忆文件现在多大、其中多少是「每次都用得上」的、剩下多少在白付
2. 逐节处置表：哪些该留在上层、哪些该下沉成一行摘要、哪些该归档
3. 孤儿文件清单（主文件从未引用的下沉文件）与失效引用清单
4. 一份改造稿文件：按「保留 / 下沉 / 归档」三段式给出建议文件名、存放位置与摘要填空位
5. 改前改后对照报告：字符数、token 数、降幅

· 不替你报「每月省 X 元」——除非你提供每天对话轮数与每千 token 单价，
```

## 四、🔴 定价这一步为什么现在就要选好

社区实测：**免费资产不能转成付费** —— 想变现，必须在**发布时就选好付费模式**。

所以付费版必须在提交时就设为「一次性买断 ¥39」，没有回头路。

**但这里有个安全阀**：发布为付费状态 ≠ 立刻产生收入。

| 阶段 | 有没有收入 |
|---|---|
| 提交审核（付费模式） | 没有 |
| 审核通过并发布 | 没有 |
| **开通收款账户 ＋ 微信签约** | ← 从这一步开始，才是「可提现的经营性收入」 |

⇒ 建议：**付费版现在就按 ¥39 买断提交审核**（因为不能后改），
但**收款账户和微信签约等 R-19 口径确认后再开**。
在那之前，技能挂在那里也没有人能付钱给你。
