## 二、付费技能《谁动了我的Token》· 商品介绍

### 简短版（一句话，用于卡片/列表）

```
体检你的项目记忆文件，算清额度被谁吃掉了，并给出可对照的改造稿。
```

### 完整版（平台建议说清四件事：适合谁 / 交什么材料 / 拿到什么结果 / 有哪些限制）

```
【适合谁】
同一个项目已经做了好几周甚至几个月的人；以及反馈「AI 老是忘事、
每次都要重新交代背景、越用越慢、额度掉得莫名其妙」的人。

【交什么材料】
不需要任何材料。只要你的项目里有记忆／规则文件（如 MEMORY.md、
CLAUDE.md、AGENTS.md，或你自己写的长期记忆文档）即可。
不联网、不上传、不读取项目目录以外的文件。

【拿到什么结果】
1. 三个数字：记忆文件现在多大、其中多少是「每次都用得上」的、剩下多少在白付
2. 逐节处置表：哪些该留在上层、哪些该下沉成一行摘要、哪些该归档
3. 孤儿文件清单（主文件从未引用的下沉文件）与失效引用清单
4. 一份改造稿文件：按「保留 / 下沉 / 归档」三段式给出建议文件名、
   存放位置与摘要填空位
5. 改前改后对照报告：字符数、token 数、降幅
6. 三个模板：索引层模板、单主题档案模板、每日待办模板

【有哪些限制】
· 只读：体检绝不修改、删除、移动你的任何原文件；改造稿只新建文件
· 分类是启发式判断，输出是「建议」不是「判决」，最终由你拍板
· 不替你报「每月省 X 元」——除非你提供每天对话轮数与每千 token 单价，
  否则只给百分比与 token 绝对值
· 需要你的项目已存在记忆文件；若从未建立过，本工具不适用
· 不承诺任何收益

【真实数据】
体验版 0 元、22 天实测：记忆文件 15,682 字符 → 3,398 字符（降 78%），
期间真实消耗 4,014 积分。工具在我自己的项目上跑出过「冗余 0%」的结果，
说明它对已经做对的人也说对。
```

## 三、免费技能《记忆体检（免费版）》· 商品介绍

### 简短版

```
只读体检：算出你的记忆文件有多大、多少真用得上、剩多少在白付。不改任何文件。
```

### 完整版

```
【适合谁】
想先量一量自己的记忆文件、但还没打算改造的人；或者只是想确认
「额度到底被什么吃掉了」。

【交什么材料】
不需要材料。脚本会自动在你的项目目录里寻找记忆文件与下沉目录。

【拿到什么结果】
1. 三个数字：体量 / 有效部分 / 冗余占比
2. 逐节处置表（哪些该留、该沉、该归档）
3. 孤儿文件清单与失效引用清单
4. 三条下一步建议（手动做法 / 完整版能多做哪一步 / 什么情况下不用改）

【有哪些限制】
· 完全只读，不修改任何文件
· 不联网、不上传
· 不编造成本数字：没有你自己的轮次与单价，就只给百分比与 token 绝对值
· 结论是建议，不是判决
· 想要改造稿、改前改后对照和模板，请使用完整版技能
```
