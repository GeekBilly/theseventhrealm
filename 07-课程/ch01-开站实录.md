# 第 01 章 · 开站第一课：从"网站打不开"到全球可访问（草稿）

> 实录时间：2026-09-25 ~ 09-26 · 本章为真实事件整理，细节可回溯当日工作日志

## 场景还原（课程开场用）

买了域名（US Domain Center/GoDaddy 生态）+ 主机（cPanel），一切配置"看起来都好了"，但浏览器打开 theseventhrealm.com 永远是 GoDaddy 停放页。这一章就讲：我怎么在十分钟内定位到根因——**DNS 的 A 记录还指着域名商的停放服务器**。

## 核心知识点（可复现步骤）

1. **诊断顺序**：`ping 域名` → 看解析到的 IP 是谁的 → `curl -I` 看返回头 → 判断是 DNS 问题还是主机问题
2. **A 记录修改**：在域名商 DNS 管理里把 A 记录指向主机 IP（cPanel 右侧可查），TTL 先调小方便快速生效
3. **生效验证**：不要干等，用 `nslookup`/在线多地解析工具确认全球生效
4. **HTTPS 教训**（预告 ch03）：**先确认证书签发成功，再改 WordPress 的站点 URL**，顺序反了会把自己锁在后台外面；自救办法是 wp-config.php 里临时定义 WP_HOME

## 踩坑清单（本章卖点：真实）

- 找不到 cPanel 的 NS 配置入口——不同面板层级藏得深，录屏演示在哪点
- 改完 A 记录以为立刻生效——TTL 缓存，十分钟 ≠ 马上
- 证书自动签发有等待期，心急切 https → 后台被锁
