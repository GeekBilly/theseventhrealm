# ch14｜一人公司的风险管控：把"怕出事"变成一张能执行的表

> 素材日期：2026-09-28 ｜ 对应《一人公司建站实录》第 14 章（新增）
> 配套档案：`11-运营/风险管控/第七境-风险管控手册-第1年.md`、`11-运营/风险管控/风险健康体检盘.html`
> 本章真账本：AI 投入约 1 次对话完成全套交付（手册 + 自检工具），金钱成本 ¥0。

## 目标

一个人做公司，最贵的成本不是主机和 AI 积分，是**一次没防住的雷**——商标被抢注、域名到期被抢走、素材侵权被投诉、跨境收入没申报。

本章解决的不是"懂多少法条"，而是一个更朴素的问题：**把"我可能会死在哪"变成一张有编号、有复核周期、有升级触发线的清单，并且每季度真的跑一遍。**

## 操作步骤（可复现）

### 第一步：先定原则，别一上来背法条

我给自己定的风险偏好只有一句话：**不追求消除风险，追求任何单点风险都不会终止这条业务线。**

配套四条取舍规则：

| 规则 | 为什么 |
|---|---|
| 不可逆风险优先 | 商标被抢、域名丢失、账号永封、数据全丢——这类事防御优先级永远高于省钱 |
| 低频高损 > 高频低损 | 日均 10 个访问没人管；一次地图违规可能整站被处置 |
| 证据优于争辩 | 版权、税务、合同纠纷里，赢的永远是证据完整的一方 |
| 合规增量嵌入工作流 | 不设"合规日"，只把 5 个动作写进日常：素材入库登记 / 发布前红线自检 / 每周备份 / 每月记账 / 每季打分 |

### 第二步：建一张风险登记册（这是全套体系的核心）

我按 **L（可能性 1–3）× I（影响 1–3）** 打分，≥6 红、3–4 黄、≤2 绿，共 18 条。打完第一遍，红色三项自己跳了出来：

1. **R-01 商标**：中文"第七境"还没申请——国内是申请在先原则，谁先申请归谁，域名也救不回来。
2. **R-02 备份**：备份目录有了，但**从没做过恢复演练**。没验证过的备份等于没有备份。
3. **R-05 地图**：五千年长卷必然要用疆域图。这类图只能取自自然资源部标准地图服务（`bzdt.ch.mnr.gov.cn`），**图面必须带审图号**，禁止手绘描改比例——这是典型"事后删也来不及"的风险。

这三条的共同线索值得记住：**红色项几乎都不是"违法风险"，而是"不可逆风险"。一人公司最该防的是忘记，不是恶意。**

### 第三步：做一个能自己打分的工具

手册写完了没人看怎么办？我把它压成了一个 HTML 自检盘（8 个模块 36 题），每题三档：达标 / 部分 / 未达标，带权重，自动出总分、分项分和"优先行动清单"。结果存在浏览器本地，能一键导出 Markdown 归档到 `11-运营/reports/`。

> **这是本章最值得抄的做法**：不要交付"一份文档"，要交付"一个能跑分的工具"。文档会被忘，工具会被打开。

### 第四步：给会计动作排时间表

| 何时 | 做什么 |
|---|---|
| 本月内 | 商标检索+申请准备、素材台账、隐私页条款页、备份自动化+首次恢复演练 |
| 首次跨境收入前 | 决定结汇路径；欧盟/英国/澳洲要么走平台（平台代扣代缴 VAT），要么评估自注册 OSS |
| 月流水连续两月破万 | 办理个体工商户（≈¥0） |
| 首次签对外合同 | 主体升级评估 + 外包合同四件套落地 |
| 年底 | 年度大体检 + 境外所得汇算 |

## 踩坑与修复（本章的真实认知修正）

- **坑：以为"没注册公司就不用管合规"。** 实际上《电子商务法》对"零星小额"有豁免，但豁免保护的是偶尔卖一点，不保护持续经营一个品牌。修复：给自己设触发线（月流水、签合同、平台资质要求），达到就办，不观望。
- **坑：以为自站直卖最省（0 抽成）。** 忽略了跨境数字商品的 VAT/GST：欧盟 B2C 数字服务按消费者所在国税率征收，自站直卖要自己走 OSS 申报；而 Gumroad/Etsy 这类平台作为"视同供应方"替我们代扣代缴。**省 10% 抽成 vs 承担一张自己都不会填的申报表**——别为了前者去冒后者的险。
- **坑：AI 音乐的版权想当然。** 付费层才可能含商用许可，条款还会变。修复：保留 prompt/参数/时间与平台账单，并**截图留存当时的许可条款页面**；对 AI 成品做人工实质性编排（配器/词/结构/混音）后再登记。
- **坑：个人便利化额度当成经营性收汇通道。** 那个额度是为非经营性收付设计的，持续大额经营性收入应通过已登记主体办理——这不是守不守的问题，是被标记后追溯期比赚钱时间长得多。

## 可直接套用的模板

**① 素材台账字段（一条 30 秒）**
```
素材名 | 类型 | 来源URL | 授权类型(OFL/CC0/付费/自有AI/外包) | 可否商用 | 是否需署名 | 下载日期 | 凭证位置
```

**② 外包合同四件套**
```
著作权转让（财产权利全部转我，署名权写明）
原创保证与侵权赔偿（若侵权由乙方承担）
保密条款
付款节点与验收标准（留 20–30% 尾款在验收后）
```

**③ 发布前红线自检（每次上新内容走一遍）**
```
[ ] 所有中国疆域图来自标准地图服务 + 审图号在图面
[ ] 文案无绝对化用语、无收益/通过率承诺
[ ] 新入库素材已登记进台账
[ ] 字体为可商用（不确定就当不可商用）
[ ] 页面/商品描述写清"买的是什么、怎么交付、不提供什么"
```

**④ 应急第一动作**（详见手册 §9）
```
收到侵权投诉：先截图保全 → 立即下线 → 查台账溯源（先止损，别先争辩）
支付通道冻结：整理交付证据 → 按要求提交（切勿注册新账户绕过）
正式函件/执法联系：不自行答复 → 先找律师 → 别删聊天记录（那叫毁灭证据）
```

## 补充实录：注册商标时才发现的第一堵墙（2026-09-28 下午）

红色 R-01 一查到就先动手，结果第一步就撞墙：

> **内地自然人申请商标，必须提交"证明其从事生产经营活动的主体资格证明文件"——个体工商户营业执照或农村土地承包经营合同。没有它，商标局不受理，找代理机构也一样。**

也就是说，"先注册个体户"不是可选项，而是商标申请的**第 0 步**。这堵墙有个连带的好处和两个免费陷阱：

**连带好处**：个体户本来就在我们的触发线上（月流水破万要办），既然商标绕不开，那就现在一起办掉，成本≈0。

**免费陷阱一：经营范围写窄了。** 自然人申请商标的类别受营业执照经营范围限制。如果只写"文化艺术交流"，那么日后第 25 类（POD 服装）、第 9 类（软件/电子出版物）就可能申请受阻。→ **办执照时经营范围一次写全**（完整措辞见 `11-运营/风险管控/商标注册-执行申请单.md` §二）。

**免费陷阱二：用艺术字申请文字商标。** 以普通印刷体申请的纯文字商标，别人用任何字体写同样三个字通常仍构成近似；而以毛笔艺术字申请的，保护范围可能被窄化到那个特定字形。→ 主力用**标准宋体/黑体**，艺术体只当补充案。

顺带记下三条成本口径（官方线上自助）：**270 元/类（含 10 个小项），超出每项 +27 元**；续展 450 元/类，宽展期 +225 元；正常全程 **8–12 个月**。

以及一个最容易被忘掉的义务：**注册成功后连续三年不使用，可能被别人申请撤销**。所以从上线那天起，每季度截一次带商标的页面图归档——这不是形式主义，是保住商标的必要动作。
