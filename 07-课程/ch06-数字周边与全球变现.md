# 第 6 章 · 数字周边与全球变现（草稿）

> 状态：构思阶段，未上线。本篇回答用户三个问题：数字品是什么 / 主题能不能卖 / 美元定价与全球市场怎么做。

## 一、什么是数字周边

数字周边 = **没有实体、一次制作、无限复制**的商品。零库存、零物流、零边际成本，卖 100 份和卖 1 份的交付成本一样——这是「一人公司 + AI 生产」组合的最优变现形态。

常见形态：

| 形态 | 单价区间 | 制作成本 | 备注 |
|---|---|---|---|
| 壁纸/屏保（4K 桌面 + 手机竖屏） | $3.9–9.9 / 套 | 低（半天一套） | 最快起步，测试市场反应 |
| WordPress 主题/模版 | $29–59 | 中 | 我们手上已有 80% 成品 |
| 电子书 / 长卷 PDF（如上下五千年画册） | $9.9–19.9 | 中 | 内容即资产 |
| 字体 / 印章素材包 | $9.9–29.9 | 高 | 需注意字体版权 |
| 在线课程 | $49–199 | 高 | 规划中的课程本身 |

## 二、我们的主题模版能卖么？

**能，而且第七境的建站过程已经做出了 80% 的产品。** 但要跨过三道门：

### 1. 品牌剥离（最重要）
现子主题里嵌着第七境的品牌资产：印章 logo、logo-banner.png、《道境》诗文。**卖模版 = 送出自己的 IP 核心资产**。商业版必须全部换成通用占位（「你的印章」/「你的标题」），第七境自己那套继续自用。
→ 做法：fork 一份 `ink-wash-theme`（商业名待定），资产位参数化。

### 2. GPL 许可证（WordPress 的规矩）
WordPress 主题必须遵循 GPL：**买家拿到后有权自由分发**。所以卖的从来不是「代码所有权」，而是：开箱即用的成品 + 文档 + 更新 + 支持。这是 ThemeForest 十年的成熟模式，不用担心，但要理解游戏规则：
- 定价逻辑 = 服务价（省去买家自己折腾的时间），不是软件授权价
- 护城河靠持续更新与支持，不靠代码保密

### 3. 补齐模版
现版本只有 `page.html`。商业产品需补：单篇文章页、404、搜索、归档、theme.json 完整排版变量、安装文档。约 2–3 天工作量。

**结论：主题值得做，但不是第一发。先拿壁纸试水——反馈快、无 GPL 问题、不需要补开发。**

## 三、壁纸产品线（第一发）

现成弹药：毛笔字体（Ma Shan Zheng / Noto Serif SC）、朱砂色 token、印章 SVG、远山横幅、纯白水墨设计语言——全部已在 skill 里沉淀。

产品建议：
- 系列 1「上下五千年」：16 朝代各一张，配一句该时代气质的文（如商·青铜纹样 + 「天命玄鸟」）
- 尺寸：4K 横版 3840×2160 + 手机竖版 1290×2796 + iPad 2048×2732，一套打包
- 交付：PNG 无水印 + 附赠同款纯色版
- 定价：**$4.99 / 套，全系列 16 张 $29.9**（数字品定价锚点：一杯咖啡 vs 一整年审美）

### 排版法 A：单字 + 玄鸟底纹（v2–v4）
纯白底 + 玄鸟水墨底纹（opacity .34、径向 mask）+ 中央主字 470px + 竖排金句 + 印章 + 英文年代 + 品牌角标。
主字字体经实测选**思源宋体 Black**（碑刻厚重），金句用**马善政毛笔**小字。

### 排版法 B：字形演变三联（v5，2026-09-28）
把「一个字的三千年」做成三联：**左甲骨文拓片 → 中今文毛笔（马善政）→ 右今文碑刻宋（思源宋体）**，中间夹极细竖断线暗示时间推进，每字下方两行小标注（书体 + 出处/年代）。三联整体**左移 100px 居中**（为右侧金句让位），字号 270px、列宽 300px、间距 50px。

三个坑与解法（都是实拍出来的）：
1. **三联别居中** —— 右侧有金句与印章时，居中会撞在一起；整体左移后视觉反而更平衡。
2. **标题会被底纹吞掉** —— 玄鸟墨色上的灰字不可读，给标题/标注加多层白色 text-shadow（`0 0 10px #fff` 叠 2–3 层）即可"浮"在墨迹上。
3. **竖排金句会被静默换列断词** —— 绝对定位 + vertical-rl 且不设高度时，元素高度会被限制（实测拿到 540px），9 字长句换列后可能断在"玄"字后，把「玄鸟」拆开。解法：**放弃 writing-mode，改逐字竖排**（flex 列 + 每字一个 span），位置完全可控。

### 中文竖排的两条硬规矩（用户指正后固化）
- **书名号必须旋转**：「《》」在竖排里要 `transform:rotate(90deg)`，开口朝下/上，直接用横排字形是错的。
- **列顺序要反着写**：竖排是从右往左读，而 HTML/flex 是左→右排列 —— 所以**代码里最左边的元素，是整句的最后一段**。写对了读者才是「天命玄鸟 → 降而生商 → 出处」。

### 落款行：品牌信息一次说清（v5）

左下角一行：`第七境 · THE SEVENTH REALM  theseventhrealm.com  [印章]` —— 品牌名、英文名、网址、印章全在一行，印章充当"文 + 印"的传统落款。这样壁纸在任何平台流转都自带品牌入口，等于每张图都是一个免费广告位。（代价：年代要上移让位，右下角留白变多。）

### 排版法 C：手卷章法（v9，现行标准）

用户提了一个把壁纸从"设计稿"变成"作品"的想法：**按一幅字画来排，想象从右到左展开画卷**。于是整张图重排成一条时间轴，并最终形成"右上起笔、中收画心、左下收笔"的构图：

```
[右上] 天命玄鸟 → 降而生商 → 《诗经·商颂》      —— 题跋（先看到，贴顶；出处沉到末尾左下角）
[中]   甲骨文「商」 → 毛笔「商」 → 碑刻宋「商」   —— 画心（从古到今，画面正中）
       SHANG DYNASTY / c. 1600 – 1046 BC         —— 画心的"英文对照"，紧贴三联下方
[左下] 第七境 ● 钤印                             —— 中文款识
[下中] THE SEVENTH REALM / theseventhrealm.com   —— 品牌落款，底部居中
```

**为什么中文款识在左下角，而不是底部正中或右下角**（这是用户直接问的问题，答案值得写进课程）：

| 位置 | 问题 |
|---|---|
| 底部正中 | 正对 macOS Dock，**最危险**（Dock 展开必被压）——所以底部正中只放英文品牌名这种"小字"，且全部压在 Dock 安全线上方 |
| 右下角 | 安全，但**动线断裂** —— 视线被从右往左引导，终点在左下，落款却在右下，读完"落空" |
| **左下角（采用）** | **章法正确**（卷轴读完即落款）、实测安全（贴在 Dock 安全线上方）、动线顺畅 |

**六个实现要点**：
1. **代码顺序与阅读顺序相反**：HTML 从左往右写，展卷从右往左读 —— 所以**甲骨文要写在 HTML 最后**（屏幕最右），碑刻宋写在最前（屏幕最左）。
2. **画心（三联）必须真居中**：它是整幅画的基准，中心要落在画布正中心（实测三联中心 960,541 / 画布中心 960,540）；题头在它正上方。用户原话："让三个商字在整个画面的正中间，所有的布局根据他们三个字的位置来调整。"
3. **不做白色让渡，字直接压在墨上**：玄鸟浓墨上一律不加白色底衬（题签、留白底衬、白描边全去掉）。解法是**把字色加深到接近墨色**（标题 `#24221d`、副题 `#4a463f`、标注 `#3d3931`）。这条是用户看到 v6 的白色底衬后否决的："玄鸟的水墨不要紧，不要做白色的让度，把字放在上面显示就好。" —— 反过来说，**白底衬只是"灰浅字"的补救手段**，字够深就完全不需要它，而且它会让画面显脏。
4. **三种锚定方式各司其职（v9）**：金句固定 `top` 贴顶（`top:62px`，16:9 与 Mac 通用）；画心与英文对照用算好的固定 `top` 居中；底部两块用 `bottom` 锚定（中文款识左下、品牌居中）。**不同内容用不同锚点，比"全部垂直居中"稳定得多** —— 换画布比例时只需改四五个数值。
5. **英文对照紧贴画心（v9）**：`SHANG DYNASTY / c. 1600 – 1046 BC` 从画面底部上移到**三联下方 36px**，作用等同"画心的英文翻译对照"。用户原话："作为类似英文的比对翻译的间距，只需上移就可以了。" —— 这条其实是**信息层级**的修正：年代属于"商"这个字，不属于画面底部。
6. **出处沉到金句末尾左下角（v9）**：`《诗经·商颂》` 用 `align-self:flex-end` 落到金句组的左下角，并**拉开 54px 间距（≈正文列距 1.8 倍）+ 垂于正文底缘 12px**。三个要素缺一不可 —— 只做底对齐不拉开间距时，实测会被误读成最后一列正文的续行（Mac 版尤其明显）。

**落款 = 免费广告位（商业价值）**：品牌名 + 域名 + 印章集中在落款区，别人拿这张图做视频背景、发社交平台，品牌入口跟着走。

**排版小账（值得记住的成本认知）**：整张壁纸从 v1 到 v9 的九轮迭代，**ImageGen 只花过一次钱**（生成玄鸟底纹那张）；剩下全部是本地 HTML + 浏览器截图，零积分。真正贵的不是"画"，是"排"—— 所以底图一次做好、反复精修排版，是最省钱的路径。

## 四、美元定价与全球市场（用户核心诉求）

**完全可以，且应该。** 中国文化内容在海外有稳定长尾需求（东方美学、禅意、zen、aesthetic wallpaper 是常年在 Pinterest 搜索的词）。

### 渠道选型（零月费优先）

| 平台 | 抽成 | 门槛 | 适合 |
|---|---|---|---|
| **Gumroad**（推荐首发） | 10% | 无月费，注册即卖 | 发现页有自然流量，支持美元收款 |
| **Lemon Squeezy** | 5%+ | 无月费 | 更像正规商店，可做订阅 |
| **Etsy**（数字品） | ~9% + 上架费 | 需店铺运营 | 平台自带西方买家，但内卷 |
| 自建站（将来） | 0%（支付通道 3%） | 需引流 | 等品牌站流量起来后导流过来 |

### 收款路径
Gumroad/Lemon Squeezy → 支持提现到 **PayPal / Payoneer / Wise / 美国银行账户**。国内个人常见做法：Payoneer 或 Wise 收美元 → 结汇人民币。税务上属跨境个人收入，需按规定申报（课程里要写清楚，这是负责任的卖点）。

### 全球市场注意项
- 文案双语：英文标题 + 一句中文意境词（中文本身是卖点，别全翻译掉）
- 图内文字：毛笔字内容选经典古文（公有领域），**不用自己小说的原创诗文**（版权资产隔离）
- 时差：海外买家高峰在他们的白天 = 我们的深夜，自动发货平台天然解决

### 第二款怎么"复制"第一款（周款的套路，全程零积分）
1. 古文字形去**汉典**取：`img.zdic.net/zy/jiaguwen/*.svg`（金文是 `/zy/jinwen/`，小篆 `/zy/xiaozhuan/`），**直连 403，必须带 `-e "https://www.zdic.net/hans/<字>"` 的 Referer**
2. 字形有多版，不知道挑哪个 → **"典型度"算法**：把候选字形各栅格化成 48×48 位图，两两算像素差异，取**平均差异最小**的那一版（最像"大家的共识写法"），避免挑到异体字

## 从内容站到商品：先名录，再承接页（2026-09-29）

### 一、顺序不能反

很多人做周边一上来就"做个商品页"。正确的顺序是：**先把「卖什么」盘成一张表，再决定页面长什么样**。因为页面是名录的投影——SKU 定了，页面结构自动就出来了（一个 SKU 一屏：主视觉 → 三句话说清是什么 → 样张 → 规格 → 价格按钮 → FAQ → 法务）。

名录第一步是**盘点原料**（本地脚本扫一遍就够，零成本）：本站扫出 16 条朝代金句 + 29 处典籍引用 + 48 条「字·物·事」三卡 + 6888 字正文 + 42 张壁纸 + 6 段音频。**一看就知道：薄本（金句帖、字帖）素材已经够了，厚本（通史）还差 7 万字。**

### 二、「先众筹、后开机」是一人公司的最优解

用户提出的思路很值得写进课程：**先把数字版做出来卖，攒够人，再决定要不要印成实体书**。

- 传统做法：自己掏钱印 1000 本 → 压库存、压现金流、判断错了就是废纸。
- 众筹做法：**达标才开机**（300–500 起订），不达标全额退或转成数字版（买家自选）。**永远不压库存、不垫货款。**
- 阶梯解锁让传播自带动力：300 册加藏书票 / 500 册加函套 / 800 册加编号钤印——每上一个台阶都值得发一条动态。

### 三、三个必须提前知道的合规红线

1. **中国大陆的"出版物"是有门槛的**。书号 + 网络出版服务许可，个人拿不到。所以：
   - 数字品走**海外平台**（Gumroad / Etsy），美元定价；
   - 国内上架**避开「出版物/电子书」类目**，用「字帖素材包 / 电子摹本 / 设计素材」；
   - 众筹走**文创 / 装帧册**类目，不以"图书"名义。**真要出书，走出版社合作，单独立项。**
2. **古籍原文是公有领域**（《论语》《史记》《周易》谁都能印）。能卖钱的不是原文，是**你这一版的选篇、注释、译文、版式、装帧**——这才是护城河，也是宣传时要强调的东西。
3. **开源字体（OFL 1.1）可以做出售物，但不能单卖字体文件**。壁纸、封面、书、包装随便卖，连署名都不强制；唯独不能把 `.ttf` 包起来当商品。产品里附一份 `OFL-*.txt` 就合规。

### 四、渠道：展示页归自己，收款归平台

个人站最常见的执念是"我要在自己站上卖"。现实是：**编辑角色装不了 WooCommerce，支付、发票、退款、纠纷自己扛也不划算。**

定案双轨：
- **站内 `/collection/`**：纯静态展示页，负责讲故事、放样张、讲清楚为什么值这个价；
- **第三方平台**：负责收款与履约。

这样流量、SEO、邮件名单是自己的，麻烦事是平台的。**唯一不能外包的是名单**——免费品（色卡、试听音频）的唯一 KPI 就是留下邮箱。

## 底纹是一种定价杠杆（2026-09-29 用户定案）

同一个版式家族里放两款产品，怎么让它们**价格差出 10 倍**，还能让人心服口服？答案不是"分辨率"（那是廉价理由），而是**约定一种"少一笔"的差异**。

本案：壁纸商品分两条线。

| | 手机竖版（金句线） | 桌面横版（字形线） |
|---|---|---|
| 内容 | 主字 + 竖排金句 | 字形演变三联 + 右起题跋 |
| 底纹 | 无（干净白底 + 底部远山） | **具象底纹**（商 = 玄鸟水墨） |
| 素材缺口 | 零，16 朝一次出齐 | 大，仅商周有古文字 |
| 定价 | ~~¥19~~ → **¥0 免费**（换邮箱，2026-09-30 改） | ¥12 / 1 朝（溢价） |

一句话心法：**便宜的那款，便宜在"少一笔点睛之笔"。** 用户不会因为分辨率提升而多付钱，但会为"这张图更有味道"付钱。

三个可以直接抄走的推论：

1. **差异必须是"看得见的一眼"**，不能是参数表里的数字。玄鸟与纯白底，一眼就分得出来。
2. **底纹不能每张都缺**。一旦要做成系列，就要问"这套底纹素材够撑几朝"？本案只有商有玄鸟，其余 15 朝没有——所以**手机线统一不用具象底纹**，反而成了"系列一致性"的解药：既保住了零缺口，又给桌面线留出溢价空间。
3. **稀缺性本身就是溢价来源**。桌面字形线要一个个从字形库取字、逐字核授权；手机金句线改一行数据就能出 16 张。**贵的那款，贵在"做它更难"。**

> ⚠️ **2026-09-30 修正（重要，建议连同上文一起讲）**：手机线上线后实测发现一个**课程里没写的坑**——**数字品防不住复制**。展示图只要能看清，就等于成品：当时页面嵌的手机图 1181×2560 已**大于 iPhone 15 Pro 屏幕**（1179×2556），服务器上还留着一张 1400×3035 的原图可直接下载。**这一档等于白送。**
>
> 处置不是加水印（难看且伤转化），而是改产品定义：**手机线改为免费换邮箱**，收费重心移到「截图替代不了」的那一档。
>
> **由此得到本课最终的一条定价铁律**：
> **免费看到的，必须在真实使用场景下不够用。**
> 桌面线成立（展示 1400×788 只覆盖 4K 屏的 37%，300dpi 印刷仅 11.8cm 宽）；手机壁纸品类天然不成立（「能看清」＝「能用」）。
> **所以「免费 vs 付费」的差别，不是分辨率高低，而是「够不够用」。**

## 批量出图的工程化：别让长句毁掉整批

批量生成最典型的翻车场景：16 张里有 1 张的文案特别长，字号是固定的，于是它溢出了、压住了落款，而**肉眼在缩略图上根本看不出来**。

本案的三道保险（都可复用到任何"数据 → 固定版式 → 批量出图"的活）：

1. **字号自适应，而不是固定**。`qfs = min(基准, 可用高度 / (最长列字数 × 行高))` —— 长句自动缩一档，短句保持基准。
2. **列数自适应**。竖排金句按标点切小句；某句超过 7 字就再均分成两列。横渠四句（为天地立心／为生民立命／为往圣继绝学／为万世开太平）原本会撑爆画面，改成 4 列后反而成了最漂亮的一张。
3. **用 DOM 矩形做批量校验，不看图**。取每个关键块的 `getBoundingClientRect`，检查两条：① 有没有超出画布；② 关键块两两有没有重叠。跑一次几秒钟，比人眼看 32 张图可靠得多。
   - 本案实测：金句底边到落款顶边**余量 56–85px**，全部合格。这只是数字，但它比"我觉得还行"值钱。

另外一个排版惯例值得记下：**题款（出处）字号必须明显小于正文**。书法里正文与题款是两个视觉层级；等大就会出现"出处喧宾夺主"。本案把题款统一压到屏宽的 2.0%，画面立刻安静了。

## 给一个 IP 造"两端叙事"：玄鸟生商 → 凤凰鸣岐（2026-09-29）

做系列商品最怕两张图各美各的、放在一起不成套。本案给了一个便宜又好用的解法：**不追求"风格统一"，追求"故事闭环"**。

商朝底纹用玄鸟（《诗经·商颂》"天命玄鸟，降而生商"），周朝底纹用凤凰（《诗经·大雅·卷阿》"凤凰鸣矣，于彼高冈"）。两张图挂在一起，读者自己就会读出"商 → 周"的递进。**系列感来自叙事，不来自视觉模板**——而且叙事是免费的，只要你选素材时多问一句"这两张之间有话可说吗"。

配套的工程做法：**生成新素材时，拿旧素材当风格参考图**（image-to-image），而不是重新写一段文字描述风格。这样笔触、浓淡、留白比例天然同源，省掉大量"再调一版"的往返。本案周朝凤凰只生成了 1 张就直接可用。

## 背景压主角：底纹的三次构图迭代

字形壁纸的第一次尝试是把水墨底纹`object-fit:cover`铺满全屏——结果**底纹压在比它更重要的三联字上**，画面又灰又乱。三次迭代后的结论：

| 迭代 | 做法 | 结果 |
|---|---|---|
| v1 | 满屏 cover，opacity .32 | 压字，画面脏 |
| v2 | 缩到 60% 宽、贴右上，opacity .22 | 干净了，但太淡、没气势 |
| **v3（定稿）** | 右上方定位（width 56–62%、top -1.5~-2.5%）+ 径向遮罩中心偏右上，opacity .25 | 有气势、不压字 |

三条可以直接抄走的经验：

1. **背景元素不要用 `cover` 铺满**。铺满 = 它默认要和主角抢注意力。用绝对定位把它"按"到一个角上，画面立刻分层。
2. **`opacity` 不是越低越好**。太低就白做了（底纹是溢价点，看不见等于没有）。.25 左右是"看得见但不抢戏"的甜点。
3. **题跋压图不是 bug，是传统**。中国画的题款本来就写在画上。深黑字压淡墨图，可读性反而比压在纯白上更"稳"。所以不必为了躲开文字把底纹挤到看不见。
