# 《一人公司建站实录：用 AI 把文化 IP 做成生意》课程大纲与制作规范

> 定位：非程序员的真人实录课——一个人 + AI，从买域名到文化 IP 变现的完整路径。
> 差异化：不是"教你用 AI"，而是**带着全部踩坑记录的真实项目**，边建站边成课。
> 平台规划：国内优先（知乎知学堂/腾讯课堂类/网易云课堂/小红书私信课/公众号付费专栏），二期出海（Udemy/Gumroad）。

## 制作规范（每次建站工作后自动追加）

1. **素材来源**：本工作区每次实际操作都是素材——用户提问、报错截图、修复过程、前后对比，全部按章归档
2. **每章结构**：目标 → 操作步骤（可复现）→ 踩坑与修复 → 成本记录（积分/时间/费用）→ 可直接套用的模板/代码
3. **成本透明**：这是卖点。如实记录"这一步花了多少 AI 积分、多少时间"，观众最想知道的就是真账本
4. **版权红线**：课程中引用的诗文、图片、字体必须自有版权或可商用，与本站法律声明一致
5. **双产出**：每章 = 课程素材 + 公众号/小红书引流文（一鱼两吃，课程和引流共用素材）
