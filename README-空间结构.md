### 2026-09-30 · 手机线转免费换邮箱 + 清除可下载大图

用户发现藏品页展示图可直接截图替代付费件。核查属实且更严重：手机竖版展示图 **1181×2560 已大于 iPhone 15 Pro 屏幕**（1179×2556），且服务器上另有 **1400×3035 原图可公开下载**（WP `-scaled` 只生成缩放版、**不删原图**）。

| 项 | 处置 |
|---|---|
| 手机竖版（金句线）¥19 | **改为免费领取**，只换邮箱；收费重心移到桌面 4K 与后续实体 |
| 展示图 1181×2560 | 降级为 `collection-jinju-free.jpg` **640×1388**（覆盖屏幕 54%），页面显示上限 320px |
| 服务器原图 / -scaled / 各变体 | 删除媒体 id=117（连带全部文件）；**带参数复验 404** ✅ |
| 桌面横版 1400×788 | **不动** —— 只覆盖 4K 屏 37%，做 4K 壁纸或 300dpi 印刷明显不够，是有意设计的安全档 |
| 交付件 | 新建 `02-商品/04-金句线/交付包/`：全套 32 张 zip（6.9 MB）+ README |

**新立规矩**：数字商品定价的唯一支点是「**免费看到的，在真实使用场景下不够用**」——不是水印，不是技术防御。故凡「缩图展示」策略，**必须同时删服务器原图**，否则策略完全失效。

**踩坑与修**：

- WordPress `-scaled` 机制只缩显示、**不删原图** → 缩图展示必须同步清理原图
- Cloudflare 会缓存**已删除**的静态资源 → 删除验证必须**加查询参数绕缓存**，否则误判「没删掉」
- REST 调用必须显式带 `-u "$WP_USER:$WP_APP_PASS"`：`source wp-auth.sh` 只导出变量，curl 不会自动认证 <!-- lint-ignore -->
- `site-health-lite.sh` 的 000 假警报（2 条实为 200，耗时 1.4–2.0s）→ 加 `--connect-timeout` 与 000 重试一次

详见 `11-运营/REQ-2026-09-30-04-手机线转免费与清理大图-执行申请单.md`。

## 本机脚本环境的三个坑（2026-09-29 实测）

1. **`sed` 是 toybox 版**，`sed -i '' …` 会把空串当文件名报错 → 用 `sed -i.bak …` 再清理 `.bak`。
2. **`grep` 的 BRE 不支持 `\|`**（交替）→ 一律用 `grep -E "a|b"`。
3. **系统 Chrome 无头截图会被沙箱拦截**（`Trace/BPT trap: 5`）→ 需以绕过沙箱方式执行，或改用允许文件访问的调用方式。
