## 二、税务详解（有官方依据）

### 2.1 增值税 —— 月销 ≤ 10 万全免 ✅

**依据**：财政部 税务总局公告 2025 年第 31 号（执行期 2026-01-01 至 2027-12-31）

```
适用主体：增值税小规模纳税人（含个体工商户、小微企业、自然人）

⭐ 月销售额 ≤ 10 万元（按季 ≤ 30 万元）⇒ 【全额免征增值税】
   超过标准的：原 3% 征收率 ⇒ 减按 1%
```

**⇒ 你现在的营收（月几千到几万）远低于阈值 ⇒ 增值税为 0** ✅

### 2.2 个人所得税（经营所得）—— 减半征收 ✅

```
政策：2023-01-01 至 2027-12-31
     年应纳税所得额 ≤ 200 万元的部分 ⇒ 【减半征收】
     （不区分查账征收还是核定征收）

经营所得税率：5% – 35% 五级超额累进（按利润，不是按收入）
```

**⇒ 举例**：
```
假设月营收 5,000 元，年 6 万，成本费用假设 2 万
⇒ 年应纳税所得额 4 万
⇒ 按 5%–10% 档，税额约 1,500–4,000 元
⇒ 再减半 ⇒ 约 750–2,000 元/年
```

**⚠️ 但各地有【核定征收】的不同做法**：
```
· 有些地方：核定月销售额（如 8 万），按定额交
· 有些税收园区：年营业额 < 120 万 ⇒ 增值税 + 个税可能都免
⇒ ⇒ 差异很大，一定要问当地税务局 ✅
```

### 2.3 六税两费减半 ✅

```
城建税、教育费附加、地方教育附加等 ⇒ 减半征收
（可与上述优惠叠加）
```

### 2.4 ⚠️ 但有一条硬性义务：**必须按期申报**

```
即使一分钱税都不用交，也要【按期做纳税申报】（可以零申报）⚠️

不申报的后果：
  · 税务异常 ⇒ 影响个人征信 ⚠️
  · 可能被罚款
  · 严重的会被列入异常名录
```

**⇒ 这是办执照后最需要坚持的一件事** ✅

## 三、风险详解

### 3.1 🟡 风险一：个体工商户信息**公开可查**

```
· 营业执照信息在【国家企业信用信息公示系统】可查
· 包括：经营者姓名、经营场所、经营范围
⇒ ⇒ 如果你在单位上班，同事/领导可能查到 ⚠️
⇒ 有些单位的劳动合同或规章禁止员工经商

⇒ ⇒ 【这一条你自己判断】—— 我不知道你的职业情况
```

### 3.2 🟡 风险二：**无限责任**

```
个体工商户【不是】有限责任
⇒ 经营产生的债务，要以【个人财产】承担 ⚠️

法院判例（2026 年）：
  · 「个体工商户变更经营者，旧债岂能一笔勾销？」
  · 「超市注销就能免责？法律说"不"！」
  · 「个体户注销不等于责任清零，原经营者被判连带担责！」
```

**⇒ 但对你这个生意，实际风险有多大？**：
```
【你的生意特征】
· 无进货 ⇒ 无货款负债 ✅
· 无库存 ⇒ 无仓储风险 ✅
· 无员工 ⇒ 无劳动纠纷 ✅
· 无实体店 ⇒ 无房租水电欠款 ✅

【唯一可能的负债来源】
· 版权纠纷赔偿（如果有人投诉你的壁纸侵权）⚠️
  ⇒ 但你是原创设计 ✅
  ⇒ 字体用思源宋体（SIL OFL，明确允许商用）✅
  ⇒ 古文属公有领域 ✅
  ⇒ ⇒ 版权风险【很低】✅

⇒ ⇒ 结论：无限责任这条【理论存在，实际风险低】✅
```

## 九、⚠️ 补一节：平台会按季度把你的收入报给税务局（2025 新规）

**用户 2026-10-11 追问**：「只要我的淘宝店开始卖货了，不管有没有成交，都需要报税是吧」

### 9.1 关键新规：国务院令第 810 号

```
《互联网平台企业涉税信息报送规定》
发文机关：国务院 ｜ 发文字号：国令第 810 号
成文日期：2025-06-20 ｜ 公布即施行

第二条  平台企业应当报送平台内经营者和从业人员的【身份信息、收入信息】等涉税信息
第四条  平台应当于【季度终了的次月内】报送上季度的身份信息与收入信息
        例外：配送、运输、家政等便民劳务人员，依法免税或不需要纳税的，不报送
第十二条 本规定施行前的涉税信息，不需要报送
```

**⇒ 含义**：
```
⭐ 淘宝 / 抖音 / 小红书等平台，会按季度把你的身份 + 收入报给税务机关
⇒ ⇒ 【你的销售额是透明的】⚠️（这是 2025 年 6 月才开始的新规）
```

### 9.2 回答：分两种情况

**情况 A · 个人身份证开店（无营业执照）—— 你现在这样**

```
⚠️「不管有没有成交都要报税」这句话【对你不太适用】

· 法律上是【自然人】，不是个体工商户
  ⇒ 没有"按期申报"的强制义务
  ⇒ 没成交 = 没收入 ⇒ 不用交税 ✅

⚠️ 但两点要注意：
  ① 有成交就有【经营所得】⇒ 应在年度汇算时申报个税
  ② 平台已按季度把收入报给税务局 ⇒ 收入透明 ⚠️
```

**情况 B · 办了营业执照（个体工商户）—— 以后**

```
✅「不管有没有成交都要报税」—— 这句话【正确】

· 办执照 ⇒ 必须税务登记
· 必须按期申报 ⚠️
  · 没收入 ⇒ 【零申报】（也要报）
  · 不申报 ⇒ 税务异常 ⇒ 影响征信 ⚠️
```

### 9.3 对照表

| 你的状态 | 有没有成交 | 要不要报 |
|---|---|---|
| **个人店**（现在） | 没成交 | 不用交税，暂时也不用报 ✅ |
| **个人店**（现在） | 有成交 | ⚠️ 有收入要申报个税（平台已报送数据） |

| **个体户**（以后） | 有成交 | 必须申报（月销 ≤ 10 万增值税免） |
