4. 结尾留互动问题，评论区活跃度也是参考

## 二、发帖方法（入口已核实）

1. 浏览器打开 **https://cloud.tencent.com/developer** → 右上角「**写文章**」。⚠️ 不是客户端内的社区入口。
2. **用与 WorkBuddy 同一个微信 / 手机号 / QQ 登录**。两端登录方式不同 = 两个账号 = 奖励到不了账。
3. 发布配置（缺一项都可能不过审）：标签必带 **`#WorkBuddy`**（另加 AI 办公、效率工具）；来源选**原创**；专栏选 **AI 与大数据 / 云+社区**；正文 **≥800 字**；配 **3–6 张真实截图**。
4. 正文直接复制发表，markdown 通用；建议**一天发一篇**，不要一天刷三篇。
5. 发完等 **1–3 个工作日**审核，积分自动到账。

**处置**：这类"用 AI 做出的成果"必须改写成"**用 WorkBuddy 怎么做出来**"才有资格拿奖励（post3 的 v2 就是这个改法）。已发的这篇不必删，留着当作品集；要拿分就按新写法另投。

## 五之三、发文前的泄密体检（2026-10-01 建立，每篇投稿前必过）

**法律上「商业机密」四要件**：不为公众所知悉 + 能带来经济利益 + 有实用性 + **权利人采取了保密措施**。
我们真正值钱的东西都满足第四条（母版 / 脚本 / 素材从不对外），所以**发文章本身不等于泄密**——关键是守住下面这张表。

| 类别 | 实例 | 能不能写进文章 |
|---|---|---|
| 母版 HTML / 生成器 / 打包脚本 | `wallpaper-*-v9.html`、`gen-wallpaper-*.py` | ❌ **永不公开** |
| 古文字 SVG 素材库 / 字体文件本体 | `02-商品/02-素材/` | ❌ **永不公开**（只讲方法与字体名，不给文件） |
| 印章抠图参数、版式精确数值 | 色相范围、`metrics()` 字号表 | ❌ 只讲"有这一步"，**不给参数** |
| 定价 / 销量 / 收入 / 客户数 | — | ❌ 永不公开（同时是 R-19 红线） |
| **未做的计划 / 路线图 / 下一步** | 「往后还能出挂历、电子书、课件配图」 | ❌ **永不公开**（2026-10-01 用户拍板）→ 只写**已经做完的怎么做的**，不写打算做什么 |
| 真实姓名 / 手机 / 公司 / 工位信息 | — | ❌ 永不公开 |
| 设计变量（色值 / 字号） | `--ink:#1a1a1a` 等 5 个 | ✅ 可公开（取色即得，无秘密性） |
| 通用技术（curl / sips / 字体加载断言） | — | ✅ 可公开（通用知识，不构成秘密） |
| 提示词 | ink wash 句式 | ✅ 可公开（不受著作权保护，且他人可独立发现） |
| 成品图（**压缩版 ≤1200px**） | 投稿配图 | ✅ 可公开，但**必须低于网站预览图**，**绝不用 4K 原图**（见下方清晰度梯度） |
| 域名 | theseventhrealm.com | ✅ **2026-10-01 用户已拍板：保留**（引流价值优先；whois 隐私保护已确认开启；同时是商标在先使用证据）。**此项已定，后续投稿不再征询** |

**真正的门槛从来不是方法**：母版、素材库、字体授权、排版审美、4K 导出链路——五道关一道都没公开。会做的人本来就能做，不会做的人看完教程也做不出来（这正是"开源方法、卖成品"成立的原因）。

**⭐ 配图清晰度梯度（2026-10-01 建立，投稿前必查）**：**文章配图 < 网站预览图 < 交付商品**。

| 环节 | 桌面线（字形线） | 手机线（金句线） |
|---|---|---|
| 文章配图 | **1200×675** | **553×1200** |
| 网站预览图 | 1400×788 | 640×1388 |
| **交付商品** | **3840×2160** | 1179×2556 |

**为什么必须卡这个梯度**：读者从文章保存的图如果**比在网站上看到的还清**，"上网站能看到更好的"这个预期就塌了。
我们卖的是**"能用"，不是"能看"**——文章给"看"，网站给"更好的看"，付款才给"用"（4K 原文件）。梯度一旦反过来，付费理由就少一条。
（2026-10-01 实测：原配图压到 1600×900，**反而大于网站预览的 1400×788**，已改回 1200×675。）

> 做法：配图一律从成品用 `sips -Z 1200 <4K原图> --out <配图>` 压出，**从 4K 直接采样，不要二次压缩**；平台还会再压一次，实际只会更小。

**⚠️ 只写已完成的，不写计划（2026-10-01 用户拍板）**：文章里**不出现任何未做的计划、路线图、下一步打算**。
公开计划＝告诉别人你要去哪，而且说过没做到会砸口碑；更重要的是它把「未来的产品线」提前暴露，对未注册商标的品牌尤其不利。
→ 判据很简单：**写"我做了什么、怎么做的"，不写"我打算做什么"**。描述已验证的能力可以（如"换一组数据就是一套新图"），描绘未做的 roadmap 不行。
→ post3 原第六节「同一套资产还能怎么用」（挂历 / 电子书 / 课件配图）已改写为回顾视角「**做完这条线，手上留下了什么**」，只讲已沉淀的四样资产。

**⚠️ 合规红线（2026-10-01 新增，post3 已据此修改）**：
**绝不公开"教人绕过访问控制"的做法**——伪造 Referer 绕过防盗链、破解付费内容、批量抓取他人站点，一律不写。
古文字本体是公有领域，但**别人站点的服务条款不是**；公开这类做法等于给自己留一条可搜索的违规记录，且与 R-19「在职金融从业、忌讳留痕」的敏感度直接冲突。
→ post3 原稿里 `curl -e` 伪造 Referer 抓字形站点的命令**已删除**，改为讲「矢量 vs 位图」的判断标准 + 一句授权提醒。
