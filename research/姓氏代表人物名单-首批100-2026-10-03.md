### 0.3 置信度定义

- **high**：正史（A 级）有明确记载，人物归属该姓无争议，历史地位公认
- **medium**：① 出处为志人小说／笔记／权威辞书而非正史；② 人物归属该姓有可讨论的余地；③ 人物地位较低但记载明确
- **low**：**仅**见于《中国人名大辞典》一类辞书、正史无传，或姓氏归属存在争讼 → **印前需人工复核**，已在 §B 逐条列出

## §C 必须避开的错误

> 下面是**网上流传最广、做姓氏卡片最容易被抓错**的若干条。每条给出「❌ 错误表述」与「✅ 正确表述」。

### C.1 把寓言／传说／小说人物当史实

| ❌ 错误表述 | ✅ 正确表述 |
|---|---|
| 「鲁班，姓鲁名班，鲁国人」 | 鲁班即**公输般**，《墨子·公输》作「公输盘」，是**公输氏**；「鲁班」是后世俗称。鲁姓人物**不要**选他 |
| 「卞和，楚国人，献和氏璧被砍双脚」 | 卞和事见《韩非子·和氏》，是**诸子寓言中的人物**，先秦史籍无载；**不要**作为卞姓主形象（本表用《晋书》有传的卞壸） |
| 「俞伯牙，春秋琴师，与钟子期高山流水」 | 伯牙事见《列子·汤问》《吕氏春秋·本味》，属**寓言传说**，无史传。俞姓用**《明史》有传的俞大猷** |
| 「花木兰，北魏女英雄，代父从军」 | 木兰最早见于《木兰诗》（北朝乐府），姓氏「花」出自晚出的《述异记》等**传说系统**，正史无载。花姓用**《明史·花云传》的花云** |
| 「史佚／史籀，西周史官，史姓始祖名人」 | 二人皆属**传说性或记载极简的上古史官**，其中史籀（作《史籀篇》）真伪与年代学界有争议；**不要**作为可画的人物形象。史姓用**史可法** |
| 「罗成，唐初名将，罗艺之子」 | 罗成是**《说唐》《隋唐演义》等小说的虚构人物**，两《唐书》无此人。罗姓可用**唐末诗人罗隐**或清代罗聘 |
| 「时迁，北宋好汉」 | **《水浒传》虚构人物**。时姓可用明代紫砂名家**时大彬** |
| 「穆桂英，北宋女将，杨门女将」 | **《杨家将演义》虚构人物**。穆姓可用《魏书》有传的**穆崇** |
| 「凤纲，汉代仙人」 | 凤纲见《神仙传》系统，是**方术传说人物**；本表把他列为副选并标注，主形象改用明代凤翕如 |

### C.2 把「名号／国名／封号／谥号」当姓氏

| ❌ 错误表述 | ✅ 正确表述 |
|---|---|
| 「汤姓名人首推商汤，商朝开国君主」 | 商汤名履，「汤」是**名号**，商王室为**子姓**；把开国君主列为姓氏人物属于常识性错误。汤姓用《明史》有传的**汤显祖、汤和** |
| 「殷姓名人商纣王（帝辛）」 | 「殷」是**朝代名**，商王为子姓、名受（帝辛）；不是殷姓人物。殷姓用《晋书》有传的**殷仲堪**，或凌烟阁功臣**殷开山** |
| 「齐姓名人齐桓公」 | 齐桓公**姜姓**、名小白，「齐」是国名。齐姓用唐末僧诗人**齐己** |
| 「齐姓名人姜子牙」 | 姜子牙（吕尚）是**齐国始祖**，但他是**姜姓吕氏**，本表归「吕」姓（见 §B.4）。「齐」是国名，不是他的姓 |
| 「孟姓名人孟尝君」 | 孟尝君**田姓**、名文，「孟尝君」是封号。孟姓用**孟子、孟浩然** |
| 「穆姓名人周穆王（穆天子）」 | 周穆王**姬姓**，「穆」是谥号。穆姓用**穆崇、穆修** |
| 「张姓名人张良，封留侯」 | 这条**没错**（张良确实姓张），但常有人把**「留侯」当成留姓人物**——「留」是封地。若做「留」姓需另行考据 |
| 「倪姓名人倪宽，西汉御史大夫」 | 《汉书》本传作**兒宽**（「兒」为姓），与后世「倪」不同字。倪姓主形象宜用**倪瓒**；如要提兒宽，必须注明这一字之差 |
| 「柳姓名人柳下惠」 | 柳下惠本名**展获**，「柳下」是食邑，「柳」为其氏的说法有学术分歧；可以列，但**必须标注争议**。柳姓主形象用**柳宗元** |

### C.3 生卒年与身份容易搞错的

| ❌ 错误表述 | ✅ 正确表述 |
|---|---|
| 「老子李耳，生于公元前 571 年」 | **生卒年无确证**，《史记》本传已言「莫知其所终」；生年诸说相差数十年。本表**不写年份**，且因真伪有争，李姓主形象改用**李广** |
| 「李白是西汉李广的后代，家世清楚」 | 《新唐书·李白传》所述世系为**后人追溯**，学界有争议；**不要**在卡片上写死家世 |
| 「章邯是秦朝名将，封雍王」 | 章邯本职是**少府**（九卿之一），秦末临时率骊山刑徒御敌，**降项羽后**才被封雍王；写「秦朝名将」不准确 |
| 「钱镠建立了吴越国，称帝」 | 钱镠先受后梁封为**吴越王**；其孙钱俶纳土归宋。「吴越国王」的称号有一个受封过程，卡片写「吴越国王」即可，不要写「开国皇帝」 |
| 「周瑜心胸狭窄，被诸葛亮气死」 | 正史《三国志·吴书·周瑜传》称其「**性度恢廓**」，且赤壁之战时诸葛亮并未参与指挥。**不要**沿用《三国演义》印象 |
| 「曹操是三国时期魏国皇帝」 | 曹操生前**未称帝**，是魏王；「魏武帝」是曹丕追尊。写「汉末政治家，魏国奠基者」 |
| 「吴道子是唐代画家，称画圣」 | 正确。但其**生平细节多出自《历代名画记》等画史**，正史无传；作为主形象需要接受「非正史级」这一点（本表因此把吴起列为主形象） |
| 「毕昇发明了活字印刷，见《宋史》」 | 毕昇**正史无传**，事见**沈括《梦溪笔谈·技艺》**；不要写出处为《宋史》。同时注意「发明活字」指**胶泥活字**，不是金属活字 |
| 「张仲景是东汉名医，曾任长沙太守」 | 《后汉书》《三国志》**均无张仲景传**；「长沙太守」之说晚出且学界存疑。作为副选可以，**不要在卡片上写官职** |
| 「马钧是三国时期发明家，见《三国志》」 | 马钧事见**《三国志·魏书·杜夔传》裴松之注**引傅玄所述，**不是《三国志》正文**。卡片提及时必须写「裴注引」 |
| 「孟浩然一生隐居，没做过官」 | 《旧唐书·孟浩然传》载其曾**入张九龄幕**；「终身布衣」是简化说法 |
| 「商鞅姓商」 | 商鞅是**卫国公族之后**，称卫鞅、公孙鞅，因封于商而称商君。「商」是封邑名 |
| 「范蠡姓陶，号陶朱公」 | 范蠡**姓范**（氏范），「陶朱公」的「陶」是**定陶**这一地名 |

### C.4 姓氏源流里的高危说法（做卡片文案时会用到）

| ❌ 错误表述 | ✅ 正确表述 |
|---|---|
| 「柏姓出自柏皇氏，是黄帝的臣子」 | 「柏皇氏」是**上古传说帝王**，属传说系统。做源流文案必须写「传说」二字，且**不能当作可考人物** |
| 「水姓出自大禹治水，禹的后人掌管水利以水为氏」 | 这是**族谱世系式的说法**，先秦文献无征。上图档的表述更稳：「水氏为历史上**晚出**的姓氏」 |
| 「酆姓出自周文王之子酆侯」 | 「酆」作为封国见于文献，但**酆姓人物在正史中极罕见**；上图档明言《中国人名大辞典》仅收 2 例。文案不要说「酆姓名人辈出」 |
| 「云姓与雲姓本来是同一个姓」 | 上图档明确：「**古代云氏与雲氏为不同的两个姓，现混而为一**」。简化字合并后容易被误当成一姓 |
| 「余姓就是馀姓」 | 上图档另立「馀／餘」条目，收 4 例，与「余」非一姓。卡片若做简化字处理，**不要把两姓的人物互串** |
| 「柳姓出自柳下惠」 | 柳下惠本名展获，其「柳」是否为氏有争议；说「柳姓出自柳下惠」属于**未定论当定论** |

## 2. 交付清单与后续建议

1. **本文件**：100 姓 × 2–3 位代表人物 + 100 位主形象 + 生图描述。
2. **可直接进入生图流程的**：`high` 置信度的 **77 位**主形象（正史有传且无争议），照 §A 文案即可。
3. **建议先人工复核再用的**：`medium` / `low` 的 **23 位**（medium 20 位 + low 3 位），集中在 §B.1、§B.3 两张表——它们不是「查不到」，而是「只有辞书级来源」或「形象缺标志物」。
4. **建议改走非人物方案（用图腾／纹样）的**：`水`（水纹）、`凤`（凤凰纹）、`昌`（无可画人物）。这三姓若强行配人，出图效果与可信度都会拖累整批卡片。
5. **下一步可以做的**：为第 101–200 姓（`姚 邵 湛 汪 祁 毛 禹 狄 米 贝 明 臧 计 伏 成 戴 谈 宋 茅 庞 …`）做同规格名单，**沿用本文件的出处代码与置信度体系**；其中 `茅`（茅焦，见《史记·秦始皇本纪》）、`禹`（大禹为传说，须标注）两姓已在 §C 的同一逻辑下预判为高风险。
