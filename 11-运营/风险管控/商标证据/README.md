## 一、证据强度分层（不是所有证据都一样有用）

| 强度 | 证据 | 为什么强 |
|---|---|---|
| ★★★ | **第三方时间戳**：域名 whois、网站存档（Wayback）、搜索引擎索引时间、平台交易记录 | 由第三方机构生成，不可单方篡改 |
| ★★ | **可验证的创作痕迹**：带创建时间的源文件、社媒首次发布日期、页面发布日期 | 可篡改，但配合哈希与时间戳后很硬 |
| ★ | **自述材料**：自制的说明文档、未公开的草稿 | 证明力弱，只作补充 |

**策略**：优先积 ★★★，用哈希 + 批量时间戳把 ★★ 升级。

### 3.1 「网页上线时间」证据的三条路（Wayback 打不开时的替代）

`https://web.archive.org/save/...` 在中国大陆网络下经常**无法打开或提交失败**（archive.org 直连不稳定，本次本机 curl 也已失败）。不用卡在这一条上，下面三条任选其一即可拿到等效证据：

| 方案 | 操作 | 效力 | 成本 |
|---|---|---|---|
| **① Wayback（首选，若网络可达）** | 浏览器打开 `https://web.archive.org/` → 输入框粘贴 `https://theseventhrealm.com` → 回车 → 等待抓取完成 → 复制生成的存档 URL | ★★★ 国际通用 | ¥0 |
| **② archive.today** | 打开 `https://archive.ph/` → 粘贴网址 → Save；生成的永久链接即为存档凭证（该站通常在国内可达性更好） | ★★★ | ¥0 |
| **③ 国内网页取证 / 可信时间戳（最稳）** | 用提供「网页取证」的存证平台（如保全网、易保全等）输入 URL，由平台自动抓取并固化、出具存证证明；或自行把首页**打印为 PDF + 录屏**，再对文件申请**可信时间戳**（联合信任时间戳服务中心等）。国内司法认可度较高，且不依赖境外服务 | ★★★ | 几十～几百元/次 |

**建议组合**：先试 ①，打不开就试 ②；等哪天要正式维权或做商标异议时，再用 ③ 对关键页面（首页 + 长卷页 + 商店页）做一次正式取证，一次性把证据链做硬。

## 四、升级路径：把 ★★ 变成 ★★★

本地文件的时间戳本质上可以被伪造（改系统时间重存即可），所以**光有清单不够**。升级方式两种，都很便宜：

1. **可信时间戳**（联合信任时间戳服务中心等）：把一批文件打包成一个 zip，申请一个时间戳证书，几十元/批。证书证明"这个 zip 在该时刻已存在且内容为此哈希"。
2. **区块链存证**：同理，部分平台提供按次存证。

**打包规范**（建议每季度一次）：
```
11-运营/风险管控/商标证据/打包/2026-Q4.zip  <!-- deadlinks-ignore -->
   ├─ 本季度新增的源文件（PSD/SVG/工程文件）
   ├─ 成品图/音频
   ├─ manifest.md（本批文件清单 + 哈希）
   └─ 时间戳证书（申请后放入）
```
打包脚本与 manifest 生成已具备：复用 `02-本地资产时间清单` 的生成方式（本地 Python，零积分）。

## 六、万一真被抢注了，怎么用这套东西

1. **公告期内（3 个月）** → 提**异议**。理由组合：著作权在先（已登记的作品）+ 在先使用并有一定影响（本目录证据链）+ 对方明知或应知（如能证明对方接触过你的内容）。
2. **已核准注册** → 自其注册之日起 **5 年内**提**无效宣告**（恶意注册的，驰名商标不受 5 年限制）。
3. **同时** → 依据《反不正当竞争法》第六条，主张其为"有一定影响的商品名称/装潢"，要求停止使用。

> 前提始终是：**证据的时间早于对方的申请日**。所以补证要勤，不能等出事再补——事后补的证据不叫证据，叫辩解。
