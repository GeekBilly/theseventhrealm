# 商标注册 · 路径调整说明（在职金融从业者的约束）

> 日期：2026-09-28 ｜ 触发：用户披露"目前在一家金融公司任职"
> 结论：**暂停办个体工商户**，先做单位合规确认；同时立刻启动不依赖主体资格的替代防御方案。

---

## 〇、条款已确认（2026-09-28 更新）

用户查到的原文：

> 利益冲突活动包括但不限于：**未经公司同意，直接或间接以任何身份从事其他盈利性贸易、业务或职业**，无论是否使用了公司资源或系统。

### 判定：这条写得非常宽，三处措辞决定了它几乎覆盖所有可能

| 措辞 | 含义 |
|---|---|
| **"未经公司同意"** | 唯一的钥匙是**书面同意**；不申报 = 默认违规 |
| **"直接或间接、以任何身份"** | 不止自己名下开店——用亲属执照、担任顾问、代持、幕后运营，都算 |
| **"无论是否使用了公司资源或系统"** | 不用公司的电脑、不上班时间做，也**不构成免责** |

### ⚠️ 因此必须纠正一个容易自我安慰的误解

**"我不办个体户，就不算经商" —— 不成立。** 该条款约束的是**从事盈利性业务这个行为本身**，不是"有没有执照"。只要你在卖壁纸、卖课、收美元，无论以什么名义、有没有登记，都在条款射程内。

这意味着：**办照与否，改变的是"被发现的概率"，不改变"违规的性质"。** 所以真正的决策不是"要不要办照"，而是下面这个三选一。

### 决策树（修订版）

```
                 你还想继续做第七境吗？
                          │
        ┌─────────────────┼─────────────────┐
        ▼                 ▼                 ▼
   ① 申报获批        ② 不做登记、低可发现性   ③ 离职后全力做
   （最干净）         （多数人走，但有代价）     （最彻底）
        │                 │                 │
   需向公司披露        不办照、不申报        办照 + 商标全能做
   品牌/网站/计划      不露脸、不向同事透露   风险归零
   被拒则被迫停止      规模化前必须再决策
```

**我的建议排序**：
1. **短期（第 1 年）走 ②**：收入规模小、可发现性可控，先把内容与 IP 资产做起来（这不产生新的职业风险）。
2. **设置一个决策触发线**：当出现以下任一情况时，必须做一次正式抉择（见 §六）——月收入稳定过万 / 课程需实名上架 / 需要签对外合同开公司 / 被要求投入明显时间。
3. **不要为了商标去申报**：申报意味着把品牌、网站、商业计划一次性暴露给雇主；若被拒，你在人才盘点里会被贴上"有离心倾向"的标签。**除非你已准备好离职，否则不要走这条路。**

### 走 ② 期间的五条自律纪律（这是真正的风险管理）

1. **工作设备上不留任何第七境文件**（电脑、手机、邮箱、云盘）。这既是纪律，也是万一被核查时最重要的事实基础——"未使用公司资源"要有证据支撑。
2. **不占用工作时间**，不在公司网络处理相关事务。
3. **不向同事、客户、供应商透露**，不在单位相关社交圈发布。
4. **不使用公司的任何渠道、名义、客户资源**推广。
5. **保留时间线证据**：证明经营活动发生在业余时间、使用个人设备（源文件的创建时间、个人设备的操作记录本身即是证据）。

## 一、为什么这条路对金融从业者不一样

办个体户对普通人几乎零成本，但对金融从业者有三重额外风险：

### 1. 登记信息是公开可查的（最现实的一条）

个体工商户登记后会进入**国家企业信用信息公示系统**（以及企查查、天眼查等聚合平台），公示内容包括：名称、经营者姓名、经营范围、登记机关、成立日期。**用姓名即可关联检索** —— 金融机构的合规/内审部门做员工关联排查时，这是常规动作，成本极低。

### 2. 在职期间的"第二职业 / 兼职"约束

- 《劳动合同法》第 39 条：劳动者严重违反用人单位规章制度的，用人单位可以解除劳动合同；第 90 条：违反竞业限制约定给单位造成损失的，应负赔偿责任。
- 金融机构通常在《劳动合同》《员工手册》《廉洁从业承诺书》中写明：未经公司书面同意不得在其他经济组织兼职、不得从事第二职业、不得经商办企业；并要求**主动申报**本人及配偶、利害关系人的对外投资与任职情况。
- 证券、基金、期货、银行等持牌机构的从业人员，还受行业自律规则约束（廉洁从业、利益冲突管理、重大事项报告等），具体要求以所在机构制度与执业登记口径为准。

> 换句话说：**即使你的业务（文化 IP、课程、数字周边）与金融毫无利益冲突，"经商"这件事本身可能就在禁止清单里。**

### 3. 利益冲突与声誉风险

一旦被认定"未申报从事经营活动"，可能的后果不是罚款，而是**劳动合同层面的处分**——从提醒、降级到解除，且可能记入行业诚信档案。这个代价与"省下的商标风险"完全不成比例。

## 二、先做的三件事（30 分钟，零成本）

| # | 动作 | 看什么 |
|---|---|---|
| 1 | 翻《劳动合同》《员工手册》《廉洁从业/合规承诺书》 | 搜关键词：**兼职、第二职业、经商、对外投资、任职、申报、利益冲突** |
| 2 | 看是否要求"重大事项/兼职申报" | 若只是**申报即可**，这条路是通的——走申报，拿书面同意，然后照常办照 |
| 3 | 判断业务是否构成利益冲突 | 你的业务是文化 IP/课程/数字周边，与金融业务**通常无实质冲突**；真正的风险点在于"经商"本身是否被禁止 |

**判断树**：
```
单位明确禁止经商/兼职 ────────────▶ 走 方案 B（防御包）+ 方案 A（亲属名义兜底）
单位要求申报、批准后可 ───────────▶ 走 方案 C（申报获批后办照）
单位无相关规定 ─────────────────▶ 走 方案 C，但保留书面确认（邮件/聊天记录）
不想让单位知道 ─────────────────▶ 走 方案 B（不办照，纯防御）
```

## 三、四套方案对比

| 方案 | 做法 | 优点 | 缺点 | 适用 |
|---|---|---|---|---|
| **C 申报后办照** | 按单位流程申报，获批后办个体户 → 正常申请商标 | 权属干净，一步到位 | 需单位知情；可能被拒 | 单位允许或需申报 |
| **A 亲属名义申请** | 以配偶/父母的个体户执照申请商标，签《商标使用许可合同》并办理许可备案 | 取得商标专用权，不与本职冲突 | **权属在他人名下**；需信任成本与关系风险；将来转回自己需办转让登记（数百元/件） | 单位明确禁止经商 |
| **B 防御包（不办照）** | 著作权登记 + 可信时间戳 + 在先使用证据 + 商标公告监测 | **零主体门槛，立刻能做**；成本几百元 | 拿不到商标专用权；只能对抗"恶意抢注"，不能对抗善意第三人 | 所有情况下都应同时做 |
| **D 离职后/收入达标后办** | 暂缓，等时机 | 无职业风险 | 敞口期最长（8–12 个月甚至更久） | 短期内有离职计划 |

### 推荐组合：**B 立刻做 + 按确认结果选 A 或 C**

理由：**B 是唯一不依赖任何前置条件、今天就能推进的防御动作**，而且它恰好把 R-01 从"不可逆风险"降级为"可监测、可异议的风险"。单位合规确认可以和 B 并行推进。

## 四、方案 B：现在就能做的四件防御动作（都不需要主体资格）

### 4.1 著作权登记（美术作品 / 文字作品）

- **不需要营业执照**，自然人凭身份证即可申请。
- 优先登记：① 玉玺印章 LOGO（美术作品）② 五千年长卷图文（汇编/美术）③ 小说《第七境》正文（文字，逐卷）④ 朝代壁纸成套（美术）
- 价值：著作权是**商标异议和无效宣告中最好用的在先权利筹码**，也能单独用于维权。
- 成本：作品自愿登记约数百元/件（以中国版权保护中心公布为准）。

### 4.2 可信时间戳 / 区块链存证（批量、便宜）

- 把每次重要产出打包 → 申请时间戳（联合信任时间戳服务中心等），几十元/批。
- 内容：设计源文件（PSD/SVG）、成品图、文章、音频工程文件、AI 生成的 prompt 与参数、平台付费凭证截图。
- 目录约定：`11-运营/风险管控/商标证据/打包/YYYY-MM/`，压缩包 + 时间戳证书一起归档。

### 4.3 在先使用证据包（这是对抗抢注的核心弹药）

《商标法》第 32 条：**不得以不正当手段抢先注册他人已经使用并有一定影响的商标。**
要主张这一条，你需要的是"早于对方申请日、且持续、有一定影响"的证据链：

| 证据 | 怎么取得 | 强度 |
|---|---|---|
| 域名注册时间 | whois 记录截图（theseventhrealm.com 已注册） | ★★★ |
| 网站上线与内容发布时间 | Wayback Machine（archive.org）主动存档 + Google/Bing 索引时间截图 | ★★★ |
| WordPress 页面发布日期 | 后台/前台显示日期截图 | ★★ |
| 社交媒体首次发布 | 公众号/小红书/知乎/X 首篇内容的时间戳 | ★★ |
| 带日期的设计源文件 | PSD/SVG 文件的创建时间属性 + 时间戳 | ★★ |
| 交易记录 | 首笔订单、Stripe/PayPal 结算单 | ★★★（最强的使用证据） |
| 媒体报道/他人转载 | 截图存档 | ★★ |

**归档位置**：`11-运营/风险管控/商标证据/`（新建），每季度补一次，附一份索引 README。

> 顺带一提：即使拿不到商标，持续使用并积累知名度的标识，还会受到《反不正当竞争法》第六条关于"有一定影响的商品名称、装潢等标识"的补充保护。这不是主力防线，但聊胜于无。

### 4.4 商标公告监测机制（把"不可逆"变成"可监测"）

- **频率**：每月 1 次快速自查（10 分钟），每季度结合风险体检盘一起做。
- **⚠️ 前置条件（2026-10-01 核实，**必须先做**）**：商标网上查询系统已于 **2025-12-19** 起全面对接
  「**国家知识产权公共服务平台统一身份认证系统**」，**原系统注册账号已停止使用** → **不注册新账号就查不了**。
  - 注册入口：https://sso.cnipa.gov.cn/am/#/login →「立即注册」→ 选「**个人用户**」
  - **⏰ 挑时间注册能省事**：自 2026-07-01 起，**每日 8:00–18:00** 用**居民身份证**可在注册页直接填信息完成注册；
    **其他时段或其他证件类型**还需下载「**国家网络身份认证**」APP 做人脸核验 → **想免装 APP 就挑工作日白天注册**。
  - **⚠️ R-19 边界（重要）**：这个账号**只用于查询与监测**，**绝不用来提交商标注册申请**——
    申请需经营主体资格（个体户/公司），且提交即产生公示记录，正是 §〇 要规避的留痕。
    查询行为**不对公众公开**、不产生经营主体，属于**自我保护性质**，不构成 §〇 所指的"经营"。
  - **注册环境**：用**个人设备 + 个人网络**，不要在工作设备或公司网络上注册与查询（§〇 纪律 1、2）。
- **做法**：登录后 → **商标** → 商标查询 → **近似查询**，检索式固定为：`第七境`、`七境`、`第七境界`、`柒境`、`SEVENTH REALM`、`7TH REALM`；图形侧查印章类要素。
  - 查到疑似抢注 → 记录**商标名称 / 申请人 / 申请号 / 类别 / 状态 / 公告日期**，存 `11-运营/风险管控/商标证据/`。
- **发现被抢注怎么办**：
  - **公告期内**（初步审定公告 3 个月内）→ 提**异议**，在先权利 + 在先使用证据是主要理由（官费数百元/件）。
  - **已注册** → 自其注册之日起 **5 年内**提**无效宣告**（恶意注册的情形，对驰名商标不受 5 年限制）。
- **关键**：异议只有 3 个月窗口，所以**监测频率决定成败**——这也是为什么"注册与否"之外，监测才是真正的安全网。

## 五、若最终走方案 A（亲属名义），必须补的三件事

1. **《商标使用许可合同》**：明确许可你使用（独占许可为佳），约定许可期限、地域、品类；
2. **商标使用许可备案**：向商标局备案（官费数百元/件），未备案不得对抗善意第三人；
3. **未来转回条款**：合同中写明"在你具备主体资格时，无条件配合办理转让登记"，以及转让费用与税费承担。

风险提示：权属在他人名下意味着——若关系变化、或对方主张权利，你的品牌可能瞬间失去法律基础。所以 **A 只是兜底，不是最优解**；一旦职业状态变化，应尽早把商标转回自己名下。

## 六、调整后的执行顺序

```
现在 ─ 立刻 ─▶ 防御包（不产生任何"经营"动作，纯自保）
        │      4.1 著作权登记（LOGO + 长卷 + 小说卷一）
        │      4.2 时间戳批量存证
        │      4.3 建「在先使用证据」目录并归档首批证据
        │      4.4 启动每月商标公告监测（写进月度清单）
        │
        ├─ 同时 ─▶ 执行五条自律纪律（§〇），工作设备不留痕
        │
        ├─ 到达决策触发线 ─▶ 申报获批 → 办个体户 → 提交 41/9/16（¥1,620）
        │                  → 或离职后全力做
        │                  → 或完全隔离（亲属主体，本人不露面）
        │
        └─ 商标主案暂不提交 ─▶ 靠"著作权 + 在先使用 + 公告监测"撑过敞口期
```

> **说明**：防御包四项都不需要主体资格、不构成新的经营动作，因此在合规确认期间做是安全的。真正需要克制的是"为了拿商标去申报"——那一步要把你的品牌和计划一次性交给雇主看，代价不对等。

## 六之二、决策触发线（到了就必须做抉择，不能继续拖）

| 触发条件 | 说明 | 到期动作 |
|---|---|---|
| 月收入稳定 > ¥10,000 | 规模化的开始，可发现性显著上升 | 申报 / 离职 / 完全隔离，三选一 |
| 课程需实名上架国内平台 | 姓名与面孔公开，与"在职"身份直接碰撞 | 同上 |
| 需要签对外合同、开公司、招外包 | 主体资格躲不过去了 | 同上 |
| 业务开始占用明显时间、影响本职 | 也是最容易被察觉的时点 | 同上 |
| 单位启动合规排查 / 要求员工申报 | 被动触发 | 如实申报，不要隐瞒（隐瞒的后果远大于申报被拒） |

> 一句话：**第 1 年用时间换空间，但必须在规模化前把这件事解决掉。** 越晚处理，可选择的余地越小。
