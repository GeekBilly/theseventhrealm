## 一、先把三件事分开：它们互不相干

你的疑问来自把三件不同的事叠在了一起。它们的主管机关、适用规则、管辖依据全都不同：

| | 管什么 | 触发条件 | 你的现状 |
|---|---|---|---|
| **工商登记**（办个体户执照） | 你在境内从事经营活动的**主体资格** | 在中国境内有住所/身份 + 想以经营主体身份取得权利、签合同、开票 | ❗ 还没办 → 这是当前卡点 |
| **ICP 备案** | 网站使用的**境内服务器** | 用境内主机/境内 CDN 才需要 | ✅ 境外主机 + Cloudflare → 不需要，也不违规 |
| **商标注册** | 你对某个标志的**专用权** | 向国家知识产权局商标局申请，**管辖依据是申请人身份** | ❗ 需要有主体资格证明 |

**结论**：服务器在国外、域名在国外、没做过 ICP 备案 —— 这些与商标注册**毫无关系**。一个人在中国境内有身份证，就可以在境内办个体工商户，也就可以作为商标申请人。反过来，境外托管并不能给你换来商标的主体资格。

> 一句话：**ICP 备案是"给服务器备案"，个体户执照是"给人/主体发身份证"。你缺的是后者，而它跟你服务器在哪无关。**

### 那有没有"完全绕过境内主体"的路？

有，但都更贵：

| 路径 | 说明 | 成本对比 |
|---|---|---|
| 境内个体工商户 | 商标申请的第 0 步 | **≈¥0**（在线办理，免费） |
| 境外主体（如香港公司/美国 LLC）申请中国商标 | 境外申请人必须**委托中国代理机构**，并提交主体资格证明的**公证认证**文件 | 公司注册+年审+公证认证+代理费，一年数千元起 |
| 不注册，只靠域名 + 著作权 + 使用证据 | 防御力最弱：被抢注后你几乎无法阻止对方使用，也难主张在先权利 | ¥0，但风险敞口最大 |

所以：**如果你的目标是"拿到商标"，办个体户仍然是成本最低的必经之路。** 唯一需要考虑的，是它带来的后续义务（见 §三）。

## 二、怎么办（轻量路径）

### 2.1 办理渠道

- 各省「政务服务网 / 一网通办」→ 搜索"个体工商户设立登记"
- 或微信/支付宝小程序：「电子营业执照」小程序、当地市场监管局公众号
- 咨询电话：当地 **12315** 或 12345 转市场监管

### 2.2 关键难点是「经营场所」，不是别的

你没有线下商铺，所以先解决地址。三条路，按优先级打当地 12315 问清楚（**下面这段话直接照着念**）：

> "我要从事互联网数字内容创作与销售（文化创意、设计、网络技术服务），没有线下经营场所，想登记个体工商户，可以用自有住所登记吗？需要住改商承诺书吗？还是要用集群注册/托管地址？"

| 方案 | 说明 | 常见费用 |
|---|---|---|
| **自有住所登记** | 最常见。多数地区允许"住改商"，提交房产证明 + 一份住改商承诺书即可 | ¥0 |
| **集群注册 / 托管地址** | 部分地区提供园区托管地址 | ¥0–数百元/年 |
| **网络经营场所登记** | 政策上为"仅通过互联网开展经营活动"的电商经营者设计，通常需平台出具网络经营场所证明；**自建站能否适用需问当地窗口** | ¥0 |

### 2.3 办照时经营范围照抄（重要，宁多勿少）

自然人申请商标的类别受营业执照**经营范围**限制，写窄了以后第 25 类（POD 服装）、第 9 类（软件）可能被卡：

```
文艺创作；组织文化艺术交流活动；专业设计服务；平面设计；
数字内容制作服务；网络技术服务；软件开发；信息技术咨询服务；
教育咨询服务（不含涉许可审批的教育培训活动）；
广告设计、制作、代理、发布；互联网销售（除销售需要许可的商品）；
服装销售；针纺织品销售；文具用品销售；工艺美术品销售；玩具销售；
图书、报刊零售（凭许可证经营）；音像制品及电子出版物零售（凭许可证经营）
```

> 带"凭许可证经营"的两项可以登记但暂不实际经营（等真要卖电子书/出版物时再补办许可）。

### 2.4 拿到手的东西

- **电子营业执照**（PDF/图片）+ 统一社会信用代码
- 这两个就是商标申请要上传的主体资格证明
- 名称不必与商标一致（如"××区第七境文化创意工作室"），法律上没有要求，但**名称里带"第七境"能给日后的在先使用证据加分**，建议带上

## 三、⚠️ 办照之后新增的义务（这部分没人提醒你，但会出事）

办个体户不是"拿了执照就结束"，它意味着你进入了一套持续义务体系：

| 义务 | 时限 | 不做的后果 |
|---|---|---|
| **税务信息确认 / 登记** | 领照后 30 日内 | 税务异常、无法开票 |
| **按期申报纳税** | 按税务局核定周期（月/季） | **即使零收入也要零申报**；逾期会罚款、进异常名录，影响法人/经营者个人信用 |
| **工商年报** | 每年 1 月 1 日–6 月 30 日 | 列入经营异常名录，长期不报可能被吊销 |
| **记账与凭证留存** | 持续 | 收入无法自证；注销时出不来清税证明 |

**降负建议**：
- 办照时向税务窗口说明"业务尚未开始，收入极低"，申请 **定期定额** 或简化的零申报路径；
- 把"月度记账 + 季度申报"直接并进你已有的《积分账本与产能测算》表，形成一张"经营+AI成本"的总账（顺便就是课程素材）；
- 现行小规模纳税人月销售额 10 万元以下免征增值税等优惠**以主管税务机关最新口径为准**，别照抄网络旧文。

> 说句顺耳的：这套义务听起来麻烦，但它同时是**未来所有合规动作的前提**——商标、开票、签合同、入驻平台、结汇走对公渠道，全都建立在"你有主体"这件事上。反而是不办照，一直以自然人身份收着经营性收入，才是风险里最被动的那种状态。

## 四、提交商标申请的逐栏填报指南

- [ ] 支付方式（在线缴费）

### 4.2 操作路径

1. 打开 `https://sbj.cnipa.gov.cn` → 商标网上服务系统 → 注册账号
2. 账号类型选**简易用户**，完成**实名认证**（身份证+手机号）
3. 「商标注册申请」→ 新建，按下方逐栏要求填
4. 提交后等《缴费通知书》→ **按期缴费**（逾期视为放弃）

### 4.3 逐栏要点（这里错一栏就白交）

| 栏目 | 怎么填 |
|---|---|
| **申请人类型** | 选 **「自然人」**（个体户经营者属自然人申请）——**不要选"法人或其他组织"** |
| 申请人名称 | 个体户经营者**本人姓名**（与身份证一致） |
| **主体资格证明** | 上传**个体工商户营业执照**（这是强制项）+ 身份证 |
| 证件号码 | 身份证号 |
| 地址 / 送达地址 | 填实际能收信地址；电子送达为主，但仍需准确 |
| 商标说明 | 文字商标：写"商标由中文'第七境'构成"；图形商标：写"商标由玉玺印章图形构成，印章内为中文'七境'" |
| 是否指定颜色 | 选**「不指定颜色」**（即提交黑白稿，日后用色自由） |
| **商品/服务项目** | 按 §4.4 填报，**每类不超过 10 项**（超出每项 +27 元） |
| 类别 | 第 41、9、16 类，分别建 3 件申请（1 类 1 件） |
| 图样上传 | JPG，<200KB，400–1500px ✅ 已符合 |
