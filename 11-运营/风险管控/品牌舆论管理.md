> 建立：2026-09-30 ｜ 归属：`11-运营/风险管控/`（防御）+ `04-市场/`（资产）
> 一句话定位：**99% 的精力在"积累社会证明"，1% 在"守住不可逆底线"。别搞反了。**
> 成本：¥0（全部本地脚本 + 人工巡查）

## 一、先说清楚一件事：现在没有人谈论你，所以"舆论管理"不等于"防负面"

2026-09-30 实测扫描结果：**微信公众号全网，品牌真命中 0 条**。

这不是脚本坏了，这是 **Phase 0 的预期状态**——一个刚上线 5 天、零销售的站点，没有人讨论才是正常的。

由此得出本文件的核心判断：

> **当前阶段，把时间花在"监测负面"上是纯浪费。**
> 舆情管理真正的价值在另一头：**把每一次真实反馈沉淀成可以放在商品页、众筹页、 landing page 上的信任状。**
> 而 Y1 最短板恰好就是信任状（"新站 + 名单 0"）——这两件事正好互为解药。

所以这套体系的设计是**攻守倒过来的**：

| 传统舆情部门 90% 做的事 | 我们 Phase 0 应该做的比例 |
|---|---|
| 监测负面、控评、删帖 | **≤1%** |
| 收集用户原话、截图、推荐、二次传播 | **≥70%** |
| 主动制造可被谈论的内容（钩子、选题、事件） | ≈29% |
| **守住不可逆底线**（见 §四 P0） | 事件驱动 |

## 二、数据源实测结论（2026-09-30，改脚本前必读）

为了做这件事，实测了五个免费源。**结论比预想差很多，其中一个尤其危险**：

| 数据源 | 实测结果 | 判定 |
|---|---|---|
| Google News RSS | `http=000`（连不上） | ❌ 不可达 |
| DuckDuckGo HTML | `http=000` | ❌ 不可达 |
| **Bing `&format=rss`** | **返回 HTTP 200、合法 XML、状态码一切正常，但内容是跟着查询无关的兜底结果** | ❌ **伪可用，比不可用更危险** |
| 搜狗微信 `weixin.sogou.com` | HTTP 200，9 条**真实**结果 | ✅ **唯一可用** |
| Cloudflare Zone Analytics | `cf-analytics.py` 已跑通 | ✅ 自有流量哨兵 |

### ⚠️ Bing RSS 这个坑必须单独说（这是本次最大的发现）

三个**完全不同**的查询，返回的几乎是同一批结果：

| 查询词 | Bing RSS 实际返回 |
|---|---|
| `"第七境"`（加引号精确匹配） | 汉字「第」的百度百科、字典解释 |
| `theseventhrealm.com` | Excel 教程、百度经验 |
| `第七境 上下五千年` | 还是汉字「第」的字典解释 |

它忽略了引号，返回的是无头请求下的缓存兜底内容，**跟真实索引毫无关系**。

> **危险在哪**：它返回 200、返回合法 XML、`<item>` 数量正常（10 条）——所有"健康检查"都会通过。
> 如果拿它做监测，你每个月都会看到一份"格式完美、结论为『无提及』"的报告，
> 而真相是这个报告**从来没有真正查询过任何东西**。
> **一个假绿比一个真红危险得多。** 已弃用，禁止再用。

**通用教训**：对免费搜索接口，**必须验证"换一个明显不同的查询词，结果是否跟着变"**。结果不跟着变的 = 兜底/缓存 = 不能用。这个校验应该写进任何接入新数据源的流程里。

## 三、三层防线（对齐每周 310–470 分钟预算）

### L1 · 自有阵地哨兵（每周 1 次，10 分钟，工作日早段碎片）

**不看全网，只看自己的四个渠道。** 理由：一个新品牌 99% 的真实反馈发生在自己的评论区与私信里，不在公众号文章里。

动作（每个渠道 2 分钟，只做三件事）：

1. 清「消息红点」：评论 + 私信 + @
2. **凡有正向表达，立刻截图** → 存 `04-市场/03-推广获客/社会证明/`
3. 有需要回复的，当天回（24 小时内回复率本身就是平台权重）

记一行账到 `11-运营/data/brand-patrol.csv`：`日期,渠道,评论数,私信数,正向截图数,待办`

> 这 10 分钟的产出不是"安全感"，是**未来商品页上的那几行用户原话**。这是整件事 ROI 最高的部分。

### L2 · 全网提及扫描（每月 1 次，脚本自动，15 分钟）

脚本：`11-运营/scripts/brand-watch.sh`（已实测通过，运行约 10 秒）

- 源：搜狗微信 × 3 组关键词（`第七境` / `第七境 上下五千年` / `theseventhrealm`）
- **硬门槛过滤**：搜狗会把「第七境」分词成"第/七/境"，返回大量"第七章"这类噪声。
  脚本只把标题或摘要含**完整品牌词**的结果计为命中，其余标记 `噪声` 写入 CSV 但不报警。
- 退出码：`0`=无提及 / `2`=**有命中需人工判定** / `3`=抓取失败（降级为人工清单）
- 归档：`11-运营/data/brand-watch.csv` + `11-运营/reports/品牌舆论哨兵-<年-月>.md`

**⚠️ 搜狗有反爬频率限制，所以必须低频（月度一次）**。跑出 `3` 不要重试，直接转人工入口：
<https://weixin.sogou.com/weixin?type=2&query=%E7%AC%AC%E4%B8%83%E5%A2%83>

### L3 · 取证与沉淀（每月，10 分钟）

两件事：

1. **社会证明归档**：当月所有正向截图 → `04-市场/03-推广获客/社会证明/`，文件名带日期与渠道。
   这些将来直接用于商品页首屏、众筹页（Y1 短板就是"凭什么相信你"）。
2. **品牌搜索结果快照**：对品牌词做一次截图存证，进 `11-运营/风险管控/商标证据/`。
   这既是舆情，也是**对抗商标抢注的在先使用证据**（跟已有的域名 whois、资产时间清单同一包）。

> 这两步有一个隐藏收益：**同一次动作同时喂给营销和法律两条线**，边际成本接近零。

### 🔴 针对本项目的特有 P0：职业身份暴露（比其他所有舆情加起来都重要）

R-19 背景下（在职金融从业、未经同意不得从事盈利性业务），**最大的舆情风险不是差评，是被关联到你雇主。**

一条差评最多损失一个订单；一次身份关联可能损失的是工作。

所以监测词设计必须包含**组合式查询**（月度人工补做一次）：

- `第七境 + <雇主名称>`（你自己填，不写进文件里）
- `第七境 + <你所在行业关键词>`
- `theseventhrealm + <你的真实姓名>`（是否存在 whomatis/简历/社交账号外泄）

**自检项（每月）**：
- 站上是否**零**真实姓名 / 手机 / 通信地址（这条是底线，必须永远成立）
- 四个平台账号是否已按「国内账号策略」做成**品牌号**而非个人 IP（已定为新起账号）
- 是否从未在任何渠道提及雇主、岗位、行业身份

**如果发现被提及且暴露身份**：立即按 §五 P0-③ 剧本处理，**不要拖延、不要观望**——隐瞒的后果远大于主动说明。

## 五、响应剧本（Playbook）

### P0-② 仿冒站 / 仿冒账号

1. **先取证**，再动任何东西：全站截图 + whois + 发布时间（保全>/可信时间戳，同 `在先使用证据/` 的规范）
2. 平台侧投诉（各平台均有「冒充」举报入口，受理率高于版权投诉）
3. 若对方同时注册了近似商标 → 并入商标异议流程（**窗口 3 个月**）
4. 站上做一次「官方渠道声明」更新（关于页列明唯一官方域名与邮箱）
5. 记录到 `IP资产台账.md`

### P0-③ 身份关联暴露（最高优先级）

1. **不要急着删对方的帖子**——删除往往引发二次传播（史翠珊效应）
2. 先判断传播范围：单个帖子私聊沟通删除 vs 已被搬运/截图扩散
3. 若为后者：**准备好主动说明口径**（我这里一直强调的是"如实说明优于隐瞒"——按劳动合同争议的处理逻辑，主动申报的后果显著小于被动发现）
4. 同步暂停该渠道的经营动作，直到处置完成
5. 复盘 R-19 五条纪律哪一条被突破，写进风险手册更新记录

### P1-① 差评 / 负面反馈

**原则：对 UGC 时代的品牌，回复本身就是内容。**

- 有事实错误的 → 平静补充事实，附出处（我们的强项恰好是 191 种典籍的引用），不辩论
- 纯主观不喜欢 → 感谢 + 不辩解。**一条得体的回复，转化率常常高于十篇自夸文案**
- 涉及退款/履约问题 → 走第三方平台的正常流程，不在公开场合谈金额
- **绝不**：删评（除非涉人身攻击/广告）、拉黑、回怼、用统一话术群发

### P1-③ 搬运不署名

1. 私信沟通，附上原文链接与发布时间（证据在手，语气可以很平和）
2. 多数自媒体会配合加注；不配合再走平台投诉
3. **反向利用**：如果搬运账号量级大于你，那它本身就是一次曝光——加注即可，不必强删

### 什么时候该升级到付费工具（别提前）

当前这套是 ¥0 但**覆盖有限**（只看微信公众号 + 自有渠道）。满足任一条件时再考虑付费（新榜/清博一类，¥数千/年）：

| 触发线 | 动作 |
|---|---|
| 月流水 > ¥10,000 | 此时一次负面舆情的实际损失已经超过年费 |
| 任一渠道粉丝 > 5,000 | 自有渠道红点已看不过来，需要聚合 |
| 出现第 1 次 P1 事件且处理超时 | 说明人工流程已经跑不动了 |
| 进入 C 档众筹筹备期 | 众筹期是舆情放大期，事前要有监测 |

**在这些触发线之前花钱做全网监测，是典型的用高射炮打蚊子。**
