### 能力域（沿用 `11-运营/自动化全景与下一阶段路线-20261013.md` §三）

| 域 | 定义 | 默认处置 |
|---|---|---|
| **L0** | 只读采集／本地生成／备份，做错也无外部影响 | 可直接授权 |
| **L1** | 自动备料 → 人一键；生成草稿/工单/话术，**不对外发出** | 可直接授权 |
| **L2** | 涉及对外生效、身份、金钱承诺（发布上线／改线上内容／模板变更／涉合规金钱） | **只出执行申请单，人点**，绝不自动执行 |
| **L3** | 违规或失真（加油站签到、改价删评、代客操作账号、虚构主体、绕过平台规则、编造数据） | **永不授权** |
| **停** | 已废弃／已掉线／已合并 | 保留行不删（只移动不删除），不得复活 |

### 五条通用约束（对所有行生效，不逐行重复）

1. **失败一次即降级**：写「本次未取到」＋一句原因，**不重试、不排障、不开浏览器救数据**。
2. **数据缺失写「本次未能自动获取」**，绝不编造、绝不沿用昨天数值。
3. **凭据只在钥匙串**，绝不写进任何文件；本表只登记位置，不登记值。
4. **本地读写直接做**；四类改动先出执行申请单（状态：待批/已执行/已验收/已否决，执行完立刻回填）。
5. **不自动改线上站点／DNS／主题／Cloudflare**；改主题文件后先清 CF 缓存再验证。

### 永不授权清单（裁判层硬编码，任何 agent 不得申请）

- 修改 `README-总原则.md`、本表的「口径」段、`.workbuddy/memory/MEMORY.md` 的宪法段

- 加油站签到（P0：超额回收＋限号）
