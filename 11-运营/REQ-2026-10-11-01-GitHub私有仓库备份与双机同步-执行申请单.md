## 四、为什么不能「全量直接推」

- 全量 5.0GB 里 **3.6GB 是缓存垃圾**（帧 2.8GB + Chrome 766MB）
- Git 历史**不可逆**：推上去再删，文件仍在 `.git` 中，每个 clone 都要拉
- ⇒ 必须先写 `.gitignore` 分层，**再** `git init`
