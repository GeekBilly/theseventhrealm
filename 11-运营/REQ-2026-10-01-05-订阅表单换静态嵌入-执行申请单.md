# REQ-2026-10-01-05 · 订阅表单由 dynamic（universal.js）换为静态嵌入

## 背景
用户在 MailerLite 后台取到完整嵌入码（含 style + 表单结构 + groot JS）并交给我。
此前页面用的是动态版（`universal.js` + `<div class="ml-embedded" data-form="ky57RZ">`）：
表单完全依赖第三方 JS 渲染，JS 被拦截/超时/被 Cloudflare Rocket Loader 延后时，访客看到的是空白。

## 改动内容（`/collection/`，页面 id=134）
1. **换成静态嵌入**：表单结构与样式写死在页面里，JS 只负责校验与提交；JS 取不到时表单照常显示，且原生 `POST` 到 MailerLite 的 jsonp 端点仍然能订阅（`target="_blank"` 为标准降级路径）。
2. **样式精简**：MailerLite 生成的 ~800 行 CSS 压缩为 24 行，只保留本表单用到的规则（去掉单选/多选/下拉/弹窗/兴趣组等用不到的选择器），结构 id、class 全部原样保留，ML 的 `webforms.min.js` 与 `ml_webform_success_46577392()` 正常工作。
3. **去掉 `@import fonts.css`**（`assets.mlcdn.com`）：远程字体 `@import` 是渲染阻塞资源，大陆网络取不到会拖慢整页首屏；去掉后走 `font-family: inherit`，与页面宋体/Georgia 一致。
4. **隐私政策行**：链接显示文字由裸网址改为「隐私政策」（此前在后台改不动，静态嵌入后可直接改）。
5. **统一版式**：宽度 520px 居中、圆角 4px、输入框描边 `#d8d2c4`、按钮沿用站点印章红 `#9e2b25`、字号 14px、字体继承页面。
6. **删掉表单自带标题**：页面已有 `<h2>顺便留个邮箱</h2>` 及说明段，表单内的「开售时通知我 / 桌面版还在准备中…」是重复文案，删；成功态文案保留并补一句「确认信里点一下链接」（MailerLite 双重确认机制）。
7. **避开 wpautop 污染**（实测，已写进页面注释）：块级元素（`<style>`/`<div>`）内部换行安全；**行内元素（`<input>`、`<script>`）若直接落在块级标签之间，会被 wpautop 包一层 `<p>`**（多出约 1em 上下留白）。处理：表单结构压成一行；两个 hidden input 收进 `<div class="ml-form-hidden">`；3 个 script 收进 `<div class="ml-form-scripts">`。改完线上 `<br>` 污染 0、多余的 `<p>` 只剩 1 个（在 `display:none` 的 loading 按钮里，不影响）。
8. **成功回调去掉 jQuery 依赖**：ML 原版用 `ml_jQuery||jQuery`，本站是块主题不加载 jQuery，若 ML 自带 bundle 未加载完会 `ReferenceError` → 成功态不显示。改为原生 `querySelector` 实现。

## 风险与代价
- **低风险**。代价：静态嵌入后，后台再改表单设计/文案不会自动同步到页面，需要重新贴一次嵌入码（已在页面注释里写明）。
- 未改动：直接下载按钮（zip 直链）、页脚说明、隐私政策页。
