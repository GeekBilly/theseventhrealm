## 三、执行步骤（顺序有理由）

> **为什么是这个顺序**：先做资产（横幅图），否则改了模板会出现「页脚写探赜、横幅印着第七境」的不一致窗口。

1. **备份** → `bash 11-运营/scripts/backup-site.sh`
2. **第 3 层（资产）** → 出新横幅 / 新图标，上传媒体库，取得新 URL
3. **第 1 层（模板）** → 改子主题 5 个文件 → 打包上传（攒一批，勿频繁传）
4. **第 2 层（正文）** → 逐页走 `publish-page.sh`：
   ```bash
   DRY_RUN=1 bash 11-运营/scripts/publish-page.sh <slug> "<标题>" <源文件>   # 体检
   bash 11-运营/scripts/publish-page.sh <slug> "<标题>" <源文件>              # 发布
   ```
   建议批次：首页 + 藏品页 → FAQ + 关于 + 联系 → 隐私 + 条款 + 免责 → 英文页
5. **复检** → `bash 11-运营/scripts/site-health-lite.sh`；逐页抽查品牌名是否残留
6. **全站残留扫描** → 用现成脚本：`bash 11-运营/scripts/live-diff.py`（或直接抓页面 grep）

## 六、待决策项（本单执行前需拍板）

### ① 新横幅的中段水墨怎么办？

旧横幅的中段山峦**没有独立底图**（整张是 flatten 的 PNG）。三条路：

| 方案 | 做法 | 代价 |
|---|---|---|
| **A. 复用旧横幅中段** | 从旧图裁出无字的中间段，左右重新合成 | 裁出的宽度（约 1100px）不足以铺满 1920px，需镜像/拉伸，**可能看出痕迹** |
| **B. 换用现有底纹素材** | 改用 `02-商品/02-素材/底纹/` 的玄鸟 / 凤凰 | 视觉语言变了（从山水变成纹样） |
| **C. 重做一张极简横幅** | 去掉水墨，只留「印章 + 探赜 + TANTSE」于宣纸底 | **最干净、文件最小、最好维护**，但设计风格改变 |

> **我倾向 C。** 理由：横幅的作用是品牌识别，不是展示水墨；去掉山水后加载更快，而且**不依赖任何不可复现的底图**。

### ② 主站要不要迁到 `tantse.com`？

- **现状**：站点在 `theseventhrealm.com`，品牌名将变成「探赜」
- **支持迁**：域名与品牌一致；**当前收录为 0、权重为 0 → 迁移成本的历史最低点**
- **反对迁**：`theseventhrealm.com` 是在先使用证据 ★★★；迁移涉及 WP 站点地址、Cloudflare、媒体库 URL、sitemap、百度/IndexNow 全部重做
- **建议**：**本单先不迁**。等英文名定案 + 站点内容稳定后单独做一次迁移（那是一个独立的 REQ）

### ③ 英文名定案

- 当前 **TANTSE** 为占位
- `tantse.com` 已注册；语义英文域（recondite / dowser / diviner / ichnos …）**全部被占**
