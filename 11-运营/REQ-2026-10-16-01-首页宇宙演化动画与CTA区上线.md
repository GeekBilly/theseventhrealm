## 🔴 上线后事故与修复（2026-10-17 14:20，v2.3）

**现象**：上线后用户反馈「主页显示不出来动画」——整块空白（只留 h2 标题）。

**根因（实测定位，非猜测）**：WordPress 的 `wpautop()` 按 `\n\s*\n` 把正文切块、逐块包 `<p>`。
本片段 CSS 里有 **4 处空行**、SVG 里有 **8 处空行** ⇒ `<style>` 内部被插入 `</p><p>`。
`</p><p>` 是非法 CSS token，CSSOM 遇错会把后续规则整段吞掉
⇒ `@media (prefers-reduced-motion:no-preference)` 里的 animation 全部失效
⇒ 所有元素停在 `opacity:0` ⇒ **整块全白**。

**决定性证据**：同一页面上主题与 MailerLite 的 10 个 `<style>` 内嵌 `<p>` 数均为 **0**
（它们 CSS 里没有空行），**只有本片段被插** ⇒ 空行就是唯一变量。

| 检查 | 修复前 | 修复后 |
|---|---|---|
| 动画 `<style>` 内 `<p>` | **8** | **0** |
| SVG 内 `<p>` | **8** | **0** |
| `@keyframes` 数（CSSOM 可见） | 被吞 | **22** |
| CSS 花括号平衡 | — | 156 / 156 |

**修复**：`build-cosmos-v2.py` 新增 `wp_safe()` —— ① `<style>` 内容压成**单行**；② 全篇去掉空行。
仅作用于上线片段（本地预览页保持可读）。

**防复发三道**：

1. `check-cosmos-v2.py` 新增断言「片段内零空行」「CSS 压成单行」（34 项全过）；
2. `deploy-cosmos.py --verify` 抓线上 HTML 实测 `<style>`/`<svg>` 内 `<p>` 数（精确匹配 `</?p[ >]`，**别用 `<p` 会把 `<path>` 算进去**）；
3. 结论写进 MEMORY §9c。

**补充**：`cf-cache-status: DYNAMIC` ⇒ CF 不缓存首页 HTML，改完访客立刻拿到新版，无需清缓存。

## 四、技术风险与对策

| 风险 | 对策 |
|---|---|
| 动画拖慢首页 | 纯 SVG＋CSS，**零脚本、零外部图片、零滤镜**；播完即停、终态静止，CPU 归零 |
| 缩放掉帧 | **禁用 `filter`/`feGaussianBlur`**：银河核球、太阳、地球光晕全部改用 `radialGradient`（缩放时滤镜每帧重算会掉帧） |
| 天体形态失真 | 银河螺旋、行星轨道、地球大陆**全部由脚本按坐标算出后静态预渲染**，随机种子固定（20261016），可复现 |
| 地球不像地球 | 大陆用**正交投影**并裁掉背面；已单独光栅化核对（见 `地球形态校验.png`）；`clipPath` 防止曲线外凸溢出球外；v2.1 起用真实地球配色 |
| 幕间硬切 | 幕容器统一淡入淡出＋时间线刻意重叠 0.7–1.2s；自检脚本新增「交叉溶解重叠 ≥0.5s」断言 |
| 落点跳变 | 地球在轨道上**不做公转**（作静止锚点），确保缩放原点与实际位置严格一致；其余行星缓慢公转。地球入场起始 `scale .35` 以接住推进幕末态尺寸 |
| SMIL 兼容 | 行星公转用 `animateMotion`；同时预置静止兜底圆，并靠 `<set>` 在 0.1s 后隐去，避免重影 |
| 无障碍 | 支持 `prefers-reduced-motion`：系统开「减弱动态效果」的用户直接停在**地球终态**（宇宙过程元素全部隐藏） |
| 移动端 | `aspect-ratio` + SVG `preserveAspectRatio` 自适应，不固定像素 |
| 样式冲突 | 类名全部加 `qjcos-` 前缀，避免污染主题与既有页 |
| 字体 | 片段**不声明 `@font-face`**，直接沿用首页已有的 Ma Shan Zheng `@import`（少一处故障点）；加载失败时 fallback 行楷/楷体 |
| 脚本被剥 | WP 区块编辑器会剥脚本标签 ⇒ **整段零脚本**，全部静态预渲染 |
