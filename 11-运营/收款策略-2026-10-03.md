# 收款策略决策（2026-10-03）

> **用户决定：先攒流量，暂不接收款。**

---

## 一、决策

```
国内站  不接收款 —— 只做免费领（邮箱换壁纸）
国外站  暂不开收款（无自然流量）
⇒ 现阶段唯一目标：【攒名单 + 攒流量】
```

**理由**：
```
① 现在只有 3 个邮箱，需求未被验证
② 一旦接收款，就要处理税务 / 退款 / 客服 / 资质
③ 数品在国内涉【网络出版物】红线，个人几乎拿不到资质
```

---

## 二、合规结论（已核实项目既有红线）

**MEMORY 30 ①：国内网络出版物需书号 → 数字品走海外** —— 这条继续有效。

⚠️ **最容易被误解的一点**：
```
面包多Pay / 爱发电 是【代收代付工具】
它帮你收钱，但【不替你取得资质】
能收到钱 ≠ 卖数字出版物就合法
```

**⇒ 分的是「卖什么形态」，不是「卖给谁」**：

| | 数字内容（壁纸/电子典集） | 实体（装帧册/卡片/周边） |
|---|---|---|
| 国内 | ⚠️ 可能构成网络出版物，门槛高 | ✅ 普通商品，门槛低 |
| 国外 | ✅ Gumroad / Lemon Squeezy | ✅ 但物流贵 |

---

## 三、将来真要收款时的路径（分三步，别一次做完）

```
第一步（现在）    国内只收 0 元，免费领壁纸换邮箱。不收款，不涉资质
第二步（300+ 名单）国内上【实体】→ 面包多Pay；国外开【数字】→ Gumroad
第三步（跑通后）   国内数字品走【有资质平台代售】分成，不自己取资质
```

---

## 四、两件该花钱问人的事（等真要收款前）

```
① 代账会计 30 分钟：个人卖数字内容收入怎么报、要不要登记个体户、
   面包多Pay 的代收代付在法律上是什么关系
② 若做电子典集：单独问【出版资质】—— 这条最贵也最易踩
```

⚠️ 以上是基于项目既有红线 + 公开资料的判断，**不是法律意见**。

## 五、「攒流量」具体指什么（回到既定计划）

```
① 知乎内容流水线  每周 1 篇（我选题+写草稿，你改+发，你约 20 分钟/篇）
                  ⇒ 第 2 篇已写好，等用户审
② 网站内容        16 朝长篇已写完 9.5 万字，且已挂「相关藏品」入口
③ 名单            免费壁纸换邮箱，MailerLite 现 3 人
④ 判断标准        8 篇后算账：≥3 邮箱/篇 = 渠道成立；连续 8 篇 <1 = 换渠道
```

**⇒ 现在一切以「名单增长」为唯一 KPI，收款的事全部冻结。**
