## 四、已知的坑（B 线刚踩过，别再踩）

1. **参数字典漏 key 会导致 CSS 静默失效**
   → 我漏了 `qr`，结果竖排引文跑到左边。**生成后必做一次占位符自检**：
   ```python
   ph = set(re.findall(r'__([A-Z0-9_]+)__', HEAD))
   missing = ph - {k.upper() for k in V} - {...}   # 必须为空
   ```
2. **原句/位置要用「字符累计位置」算，不能用 `str.index()`** —— 有重复字会找错
3. **多字内容要单独设计**（复姓/多字朝代）—— 直接塞进单字版面会塌
4. **Chrome headless 会挂住**：`&` 启动 → 轮询输出文件 → 出现后 `kill`（脚本里已封装）
5. **多帧 zstd**：会话日志解压时 `zstdDecompressSync` 只解第一帧，要逐帧切
