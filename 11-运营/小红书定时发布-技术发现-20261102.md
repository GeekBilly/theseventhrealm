# 小红书发布页自动化 · 技术发现（2026-11-02 实测）

> 来源：为「定时发布每天 20:00」做的一次完整探测。发布页是 **Vue**（`data-v-*` scoped 标记），不是 React。
> 状态：**已攻克 5 项，未攻克 1 项**（提交按钮定位）。

## 一、🔴 推翻旧结论：三个开关其实都能点开

记忆里一直写着「原创声明 / 内容含 AI 合成 **点不动**（JS click／真实鼠标／键盘全试过无效，疑似账号权限未开放）」——**这个结论是错的，今天被推翻**。

真正原因是**点错了目标**：

| 组件 | 之前点的（无效） | 该点的（有效） |
|---|---|---|
| 原创声明 | `div.original-wrapper .custom-switch-card`（外层卡片） | `div.original-wrapper .d-switch-simulator` |
| 定时发布 | `div.post-time-wrapper .custom-switch-card` | `div.post-time-wrapper .d-switch-simulator` |

`custom-switch-card` 是整张卡片（308×44，含图标+文字+开关），不响应点击；`.d-switch-simulator` 才是开关本体。

**有效做法**：`scrollIntoView({block:'center'})` → 取中心坐标 → 真实鼠标事件三连
`mouseMoved → mousePressed(left) → mouseReleased(left)` → 等 2s

**判读状态**：读 `.d-switch-simulator` 的 class 是否含 `checked` / `unchecked`（**不是**读 `input` 的 value，checkbox 的 `value` 属性恒为 `"true"`，与开关状态无关——今天被这个坑骗过一次）。

实测：`unchecked → checked` 成功。

## 二、定时发布时间怎么设（唯一可行路径）

```
1. 开开关（见上）→ 出现 input.d-text 时间框（readonly:false，默认当前时间）
2. 点时间框 → 弹 .post-time-date-picker-popover 日历面板
3. 点日期格子（叶子文本 == "3"，排除 class 含 prev/next/other/disabled 的跨月格）
4. 时间列 = .d-timepicker-timebar（两个，overflow:auto）
     bar[0] = 小时列（left≈925，内容 00–23）
     bar[1] = 分钟列（left≈994，内容 00–59）
5. 组合拳生效：先 JS 设 bar.scrollTop 让目标数字居中
   → 再在列中心做「轻触」触发 snap：
     touchStart(x, cy) → touchMove(x, cy-2) → touchEnd()
```

**关键坑（逐个踩过）**：
- ❌ Vue 组件不认 JS setter 改 `input.value` + `dispatchEvent('input')`——DOM 值变了，组件状态不变
- ❌ 单纯设 `scrollTop` + `dispatchEvent('scroll')`——**不更新选中项**
- ❌ CDP `mouseWheel`（deltaY ±120~300）——完全无反应
- ❌ 纯 touch 大幅滑动——时灵时不灵（滑动阈值不可控）
- ✅ **只有「scrollTop 定位 + 轻触 snap」稳定生效**，已验证小时 07 → 20 成功
- ⚠️ 分钟列**没有首尾 padding**（scrollHeight 2530 ≈ 60×42），所以「00」永远无法居中，会 snap 到 03 —— **实际只能设到 20:03，凑不出整点 20:00**

## 三、AI 合成声明怎么选

```
1. 点 .d-select-main（"添加内容类型声明"）→ 弹下拉
2. 点文本 == "笔记含AI合成内容" 的选项
3. 回读 .d-select 文本确认
```
⚠️ 下拉会因焦点丢失自动关闭，**打开→选择必须在同一串连续动作里完成**，不能分两次调用。✅ 已验证成功。

## 六、其他踩坑

- ⚠️ **草稿存在浏览器本地**：平台明文提示「草稿存储于当前使用的浏览器本地，在清除浏览器数据时会被删除」⇒ 9226 常驻 Chrome 的 profile 不能清
- ⚠️ 探测元素时 `x.offsetParent` 会漏掉 fixed 元素；`children.length===0` 会漏掉有内联 span 的文本节点
- ⚠️ 坐标必须在视口内才点得中（今天有一次 y=1073 超出视口高度，点击静默失败）
- 笔记管理页不是 `<a>`，`/publish/note?source=official` 是 404，正确入口得从侧边栏点
