## 二、方案选择

| 方案                 | 做法                                     | 优点               | 缺点                          |
| ------------------ | -------------------------------------- | ---------------- | --------------------------- |
| **A · 新建英文表单**（推荐） | 后台复制表单 → 改英文文案 → 订阅者进独立 group「English」 | 中英文彻底分开，可发不同语言邮件 | 需后台操作较多                     |

**推荐 A。** 理由：中英文邮件内容差异大（说明、下载指引、退款政策都要翻译），分开最干净，后续也便于按语言做营销。

⚠️ 这段**只是加载器**——`ml('account', ...)` 只声明了账号，**没有指定要显示哪个表单**。还需再配一个表单标识，两种写法都行：

```html

<script>ml('show', '表单ID', {mode: 'inline', target: '.selector'});</script>
```

**第二份（同日提供）—— 表单容器，ID = `NRfwB6`** ✅

```html
<div class="ml-embedded" data-form="NRfwB6"></div>
```

⇒ **两段组合即可工作**：Universal 脚本声明账号 `2674672`，`ml-embedded` 容器按 `data-form` 拉取并渲染表单 `NRfwB6`。

**推荐直接用这两段**（表单文案在 MailerLite 后台改，代码不用动，最稳）。
