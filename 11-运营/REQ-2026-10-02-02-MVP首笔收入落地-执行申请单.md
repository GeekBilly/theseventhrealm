## 二、🔴 §四 形态修正：小程序不能做"壁纸浏览站"

**调研核实（2026-09）**：

> 微信「**工具-图片处理**」的官方释义是**图片/音视频本地制作、剪辑**，
> 且备案指引明确「**不适用于传播分享、公开访问**」。
> ⇒ **纯壁纸浏览/图片展示站不对口，会被判「类目与实际内容不符」——这是审核第一位驳回原因。**
> 另有官方口径：「个人主体不允许提供资讯内容」。

**正确形态：把产品做成「工具」，壁纸作为导出产物。**

对第七境最自然的工具形态（素材已全有）：

| 形态 | 说明 | 现有素材是否够 |
|---|---|---|
| ⭐ **朝代金句壁纸生成器** | 选朝代 → 看该朝金句 → 选配色/尺寸 → **本地导出壁纸** | ✅ 16 朝金句 + 版式全有 |
| 汉字字形演变查询 | 输入字 → 看甲骨/金文/篆/楷 | ❌ 古文字 SVG 仅商周 12 个，不够 |
| 纹样取色 / 宣纸配色 | 从玄鸟/凤凰底纹取色做配色卡 | ✅ 底纹有 |

> **C3 的验收标准不是"做完了"，而是回答一个问题**：
> **「壁纸作为导出产物的工具，能否按『工具-图片处理』过审」**
> ⚠️ 这一问**无 2025–2026 年可复核的官方结论**，只有个案。**不过就整条作废，转投主线。**

### ⚠️ C 层的三条红线（踩了会封号）

1. **审核期隐藏真实内容只给审核员看** = 「绕开、规避或对抗平台审核监管」（运营规范 5.19）→ **禁止**
2. 壁纸图片必须**自有或开放版权** —— 网络收集图侵权是官方明确拒绝情形
3. 「只有一个页面、一个按钮」/ 功能过于简单 → 会被拒

## 三、成本与风险账

| 项 | 金额 | 说明 |
|---|---|---|
| 面包多Pay | **2% + ¥0.1/笔** | 最低；**唯一能嵌进自己站的** |
| 面包多商品页 | 5.7% | 未开通闪电结算则 13% |
| 爱发电 | **6%** | 兜底；有公开创作者页（暴露略高） |
| 公众号赞赏 | **0 手续费** | T+7 到微信零钱 |
| 小程序个人认证 | **30 元/年**（实测口径，**官方未列个人主体 → 未核实**） | — |
| 小程序虚拟支付 | Android **1%** / iOS 12% | 月限额 10 万；Android T+3 / iOS 45–60 天 |

**R-19 判定**：全部通道**不需要营业执照**，但**全部要实名 + 绑卡**。
→ 属「**低风险，非零风险**」。压制手段见 `README-总原则.md` P1-1：低金额（年 ≤10 万免登记）+ 品牌号 + 不注册主体 + 不公开宣传经营身份。

**⚠️ 本次调研新确认的两条**：
1. **2025-10 起平台按季向税务报送个人经营者信息**（税总 2025 年第 15 号，无小额豁免）
   → 「收入不公开可查」**已失效**；准确说法：**公众不可查，税务必然可见**
2. **个人收款码收经营款违法**（《银发〔2021〕259 号》）→ **绝不贴个人码**

**已知负面样本**：有用户公开投诉面包多**提现前须过平台自设的「结算认证」**（要求有单量或把自媒体简介改成其站点），提交后数周无人处理、钱提不出。虽为个人投诉非官方口径，但**属可复现风险** → **B兜底必须并行**。

## 四、明确不做（调研已否决）

| ❌ | 原因 |
|---|---|
| 做 iOS App / 买 ¥688 开发者账号 | Apple 2026-06 审核指南 **4.3(b) 点名 wallpaper 不接受新提交**；个人账号**公开显示真名** |
| 上架国内安卓 | 需软著 + 营业执照 → 撞 R-19 |
| 开众筹 | 名单 0 时 = 公开永久留档的一次性失败；"78.55% 成功率"是 2021 年机构数据，**个人自主发起仅 8.52%** |
| 做实体周边 | R-19 下"贸易"最难辩解；且现有分辨率不够印 A2/A3 |
| 微信小店 | 只收企业/个体户 |
| 小红书个人店 | 需 1000 粉 + 月流水 6000 证明，**当前不可用** |
| 一切境外平台 | 撞 P1-2 跨境信道红线 |
| 贴个人收款码 | **违法** |

## 五、未核实项（决策前需实测，不要当成事实）

1. 🔴 **面包多Pay 2026 年是否仍接受个人新申请、通过率多少** ← 最大不确定项

7. 虚拟支付个人版与个人备案「不开展商业经营」承诺是否冲突
