## 一、改了什么

### 1. 四个大时期提到一级导航（用户要求：不再挤在「上下五千年」里）

一级从 3 项 → **7 项**（桌面一行）：

```
道境 │ 上下五千年 │ 传说与三代▾ │ 秦汉魏晋▾ │ 隋唐两宋▾ │ 元明清 · 近代▾ │ 关于我们▾
```

- 「上下五千年」改为**纯总览入口**（不带下拉），指向 `/5000years/`，承接「上下五千年」这个词。
- 四个时期各自下拉 4 个朝代（单列小微面板），**链接目标不变**（还是 `/5000years/<slug>/`）。
- 一级时期项点击 → 跳到时间线对应朝代的锚点（如「传说与三代」→ `/5000years#sanhuang`），保留"先看长卷"的路径。
- 「周边」仍在 HTML 注释里预埋（商标核准后再启用）。

### 2. 一级、二级统一毛笔字

二级菜单从正文黑体改为与一级相同的**毛笔字（Ma Shan Zheng）**，字号 16px、字距 3px、行高 1.45（比原来 14px 更大，因为书法字本身偏细，缩太小会糊）。

### 3. 高亮规则升级：朝代页高亮到「所属时期」

原来所有朝代页都高亮「上下五千年」；现在精确到时期：

| 访问 | 一级高亮 | 二级高亮 |
|---|---|---|
| `/5000years/` | 上下五千年 | — |
| `/5000years/shang/` | **传说与三代** | 商 |
| `/5000years/song/` | **隋唐两宋** | 宋 |
| `/5000years/juexing/` | **元明清 · 近代** | 觉醒年代 |
| `/privacy/` | 关于我们 | 隐私政策 |

### 4. 手机端：一级用简称，导航只占两行

桌面一行放得下 7 项；手机上全称会把导航挤成 **3 行 168px**。改为**手机显示简称**（桌面仍全称）：
`上古 / 秦汉 / 隋唐 / 元明清` → 导航 **2 行 114px**（旧版 3 项时 69px）。
二级面板在手机上满宽、2 列、点箭头展开且**五组互斥**。

**本轮修掉两个真 bug**：

1. 移动端 `.sub-list{display:grid}` 把 `.sub{display:none}` 覆盖了 → **四个时期面板全部默认展开、互相叠在一起**（截图里同时看到「元明清」和「商周」两套链接）。改为只在 `:checked` 时设 grid。
2. 手机端时期名太长 → 加「全称/简称」双 span 按视口切换。
