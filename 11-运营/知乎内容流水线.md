# 知乎内容流水线（每周 1 篇）

> **状态**：生效 ｜ **建立**：2026-10-03 ｜ **节奏**：每周 1 篇
> **分工**：🤖 我选题 + 写草稿 → 👤 你改 + 发（**你实际投入约 20 分钟/篇**）

---

## 一、为什么要固化流程

第一篇的教训（`REQ-2026-10-03-01`）：

```
内容    ✅ 立论硬、史实经得起查
位置    🔴 发在一个 415 个回答的问题下，0 赞 → 排 300 名开外 → 等于没发
结果    网站新增邮箱 0
```

**⇒ 内容不是瓶颈，"位置"才是。** 所以流程的第一步改成**先选问题，再写内容**。

---

## 二、选题标准（硬指标）

**只写满足以下条件的问题**：

| 指标 | 要求 | 为什么 |
|---|---|---|
| **关注者** | 100 – 2,000 | 太小没人看；太大轮不到我们 |
| **回答数** | **< 50** ⭐ | 这是最关键的。回答少的池子，排进前 3 就会被推 |
| **浏览量** | > 10,000 | 证明有人在搜/在看 |
| **最近活跃** | 近 30 天有新回答 | 死问题不给量 |
| **与我们相关** | 能自然连到汉字 / 姓氏 / 朝代 / 书法 | 不然链接放不进去 |

### 🔴 不碰的

```
· 回答数 > 200 的红海（第一篇就是这么栽的）
· 时事/热点问题（我们的内容不是快消品）
· 需要专业资质的问题（医学/法律）
· 容易吵架的（性别/地域/政治）
```

## 三、每周流程

### 周一 · 选题（🤖 我，约 30 分钟）
```
① 我按上面的硬指标捞 5 个候选问题
② 每个附：关注者 / 回答数 / 浏览量 / 为什么适合我们
③ 你花 2 分钟圈一个
```

### 周二–周三 · 写稿（🤖 我）
```
① 派一个 agent 做史实核查（不查清楚不动笔 —— 这是第一篇立了大功的一步）
   ⚠️ 核查必须包含一节「必须避开的错误说法」
② 我按 v3 的口吻写（短句、大白话、你的语气）
③ 按 `平台文章发布格式与偏好.md` 排版（跳读测试必须过）
```

###周四 · 你审（👤 你，约 15 分钟）
```
□ 内容有没有说错 / 说过头
□ 口吻像不像你
□ 结尾那句你自己念一遍顺不顺
□ 有没有写你没做过的事（不许吹身份）
```

### 周五 · 发布（👤 你，约 5 分钟）
```
① 我把全文填进编辑器 + 加粗 + 加链接（存草稿，不点发布）
② 你看一眼「发布设置」（创作声明如实、转载禁止、评论开放）
③ 你点「发布回答」
```

### 周日 · 记账（🤖 我）
```
回填到 11-运营/data/zhihu-answers.csv：
  日期 / 问题 / 链接 / 关注者 / 回答数 / 赞同 / 评论 / 网站新增邮箱
```

## 四、每篇必须遵守的（红线）

```
【P1-3 身份】
□ 只用「第七境」品牌号发
□ 全文不出现：真实姓名 / 单位 / 城市 / 收入 / 副业 /「卖」字
□ 署名口径：「个人创作者」
□ 外链 1 篇 ≤1 个，用纯文本域名让知乎自动识别

【不吹身份】
□ 不写自己没做过的事（没拿过竹简就别说翻简牍）
□ 查不到的量化数据 → 写「查不到」，不编
□ 引文照原文；改述的地方不加引号

【格式】
□ 跳读测试通过（只读加粗能看懂）
□ 一行一件事（不用表格、不用双栏对齐）
□ 手机预览过一遍
```

## 五、数据跟踪

台账：`11-运营/data/zhihu-answers.csv`

```
date,question,url,followers,answer_count,upvotes,comments,site_signups,notes
2026-10-03,嬴政灭六国的难度是不是被严重低估了,https://www.zhihu.com/answer/2089511882570871055,1389,415,0,1,0,首篇·红海·教训
```

**看什么**：
```
第 1 周  只记录，不下结论
第 4 周  看"每篇平均带来几个邮箱" —— 这个数是流水线是否跑通的标准
第 8 周  如果 8 篇平均 < 1 个邮箱/篇 → 停下来重新想
```

---

## 六、什么算跑通

```
每篇平均带来 ≥ 3 个邮箱        → 流水线成立，加大投入
每篇平均 1–3 个                → 成立，但选题还要再准
每篇平均 < 1 个（连续 8 篇）   → 说明知乎这条渠道对不上我们的产品，换渠道
```

**⇒ 用数字决策，不靠感觉。** 8 篇之后我们再判断知乎值不值得继续投。
