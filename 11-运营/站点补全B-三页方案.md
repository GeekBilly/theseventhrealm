## 三、第 2 页「隐私政策」我要写什么（中英双语）

跨境 SaaS/数字品站点必备，且**越简单越安全**。当前站点的真实数据处理情况：

| 环节 | 是否发生 | 政策里怎么写 |
|---|---|---|
| 注册 / 登录 | ❌ 无 | 声明不要求注册、不建用户账户 |
| 评论 / 表单 | ❌ 无 | 声明不收集访客提交的信息 |
| 分析 / 追踪 Cookie | ❌ 无（未装统计工具） | 声明不使用第三方追踪；仅 WordPress 必要 Cookie（登录时） |
| CDN | ✅ Cloudflare | 声明 Cloudflare 会处理 IP/UA 等技术日志用于安全与加速，链接其隐私政策 |
| 字体 | ✅ `fonts.loli.net` 镜像 | 声明第三方字体服务可能记录请求 |
| 邮件（将来） | 待定 | 若你公开邮箱，写明「来信仅用于回复」 |

另含：儿童（不面向 13 岁以下）、外链免责、政策变更通知方式、生效日期。

> **我需要你回 3 件事**：
> 1. **公开邮箱**用哪个？（建议专用 `hello@theseventhrealm.com`，个人邮箱别公开）
> 2. 是否要**加统计工具**？（不加最简单、合规成本最低；加的话要写进政策并做同意提示）
> 3. 署名方式：`第七境（个人创作者）` 还是用工主体名称？（商标/个体户下来后再更新）

## 四、第 3 页「联络」我要写什么

- 常见问题 3–5 条（可以用壁纸吗？能商用吗？字是哪里来的？）
- 一句品牌收尾
