## 一、硬约束（先读，不可绕过）

### R-19（最上位，README-总原则 P1-1）

- 用户金融机构任职，劳动合同禁止从事其他盈利性业务
- **禁止**：注册个体户 / 公司、商标申请、任何需营业执照的平台入驻
- **已证实**：R-19 **无法靠选收款通道规避**——几乎所有通道都要身份证实名 + 绑本人卡
- **能做的是压制暴露层级**：年金额 ≤10 万（属免登记「零星小额」）+ 品牌号 + 不注册主体 + 不公开宣传经营身份
- ⚠️ **这是「低风险」，不是「零风险」。不得说成合规无虞。**

### R-20（跨境信道红线，README-总原则 P1-2）

- **绝不为经营性活动使用非法定跨境信道**
- **所有境外平台默认排除**：Gumroad / Paddle / Lemon Squeezy / Etsy / Ko-fi / Redbubble / 海外 App Store
- 遇到「平台很好但需要稳定跨境网络」→ **直接判否，不讨论**

⇒ **本次选型因此只剩国内通道。**

### 为什么首推面包多

1. **数字商品原生平台**——壁纸 zip 就是它的主营类目，不是电商平台的边缘类目
2. **自动发货 + 文件托管**（<1G）+ **防盗版**（图片防下载、整页水印、PDF 授权戳）—— 壁纸最怕盗图，这条对我们要紧
3. **闪电结算**：平台不触碰用户付款，收入实时结算
4. **个人主页可自定义 CSS**——品牌调性（水墨风）能延续过去
5. 抽成 5.7% 低于爱发电 6%，且不用凑粉丝门槛

### 淘宝个人店的定位

- 凭**身份证即可开**，无需执照；年销 ≤10 万免登记
- 但**订单不返回买家邮箱** ⇒ **只能做成交渠道，不能做客户收集渠道**
- 定位：补充流量入口，不是主战场

## 三、关键架构决策：留资与成交解耦

这是本方案的核心，直接回应「客户信息在自己手里 + 借助平台力量成交」：

```
独立站（中/英）──留邮箱──▶ MailerLite ──▶ 免费 32 张（客户资产沉淀在我们手里）
                                              │
                                              ▼ 邮件序列推付费
                                     面包多 / 淘宝（成交 + 自动发货）
```

**原则**：

- **免费层换邮箱**：32 张手机竖版壁纸免费领 → 客户邮箱进我们自己的列表（已完成闭环）
- **付费层走平台**：桌面横版（含底纹）等付费品 → 面包多成交、自动发货
- **永不把付费成交当作留资手段**——淘宝买家我们拿不到邮箱，所以主链路必须走独立站

⇒ 客户资产（邮箱）与成交场所（平台）**彻底解耦**。平台换了、封了，客户还在。

## 三之二、自建收款平台可行性（2026-10-15 追加论证）

**结论：不可行。三条硬伤，任何一条都足以否决。**

### 硬伤 1 · 官方支付接口必须营业执照 → 触 R-19

微信支付、支付宝直连接口，**接入主体必须是企业或个体工商户**：

- 微信支付商户平台：提交**营业执照** + 法人身份证 + **对公银行账户**
- 支付宝「电脑网站支付 / 手机网站支付」：需用**企业或个体工商户账号**创建应用
- 公开资料明确：「个人主体无法申请官方自动化支付接口」

⇒ 自建站收款 = 要办营业执照 = **触 R-19 明令禁止的「注册个体户 / 公司」**。

### 硬伤 2 · 所谓「个人支付接口」是灰色通道

市面上有服务商（如 ZPAY、源支付等）宣称「无需营业执照、个人可开支付宝/微信接口」，本质是**挂靠在 ISV 商户号下的大商户模式**：

- **二清风险**：资金先入服务商账户再结算给个人，属监管灰色地带
- 成本不低：开户费 ¥50–500 + 平台手续费 0.8%–1% + 官方 0.6%
- **留痕更明显**：比走面包多/爱发电更像「经营性收款」，与 R-19「压制暴露层级」原则直接冲突
- 服务商跑路 / 稳定性风险无兜底

⇒ 违反 README P1-1 第七条（留退路）与 P1-3（暴露最小化），**不讨论**。

### 硬伤 3 · 我们没有 ICP 备案

支付平台审核要求「域名必须完成 ICP 备案，且**备案主体与支付入驻主体一致**」。本站无 ICP 备案（此前百度 sitemap 提交入口因无备案被 disabled，MEMORY 已有记录）。

⇒ 即便不考虑 R-19，技术上也无法通过审核。

### 备选方案：个人收款码 + 人工发货

不触 R-19（无需执照），但：

- ❌ **无法自动发货**——壁纸要人工核对付款截图再发链接
- ❌ 转化路径长（扫码 → 传截图 → 等人工），数字商品体验差
- ❌ 无订单管理、无防盗版
- 仅适合「熟人/社群小批量」，不适合作为主通道

⇒ **保留为兜底，不作主通道。**
