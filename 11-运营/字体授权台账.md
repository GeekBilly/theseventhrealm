# 第七境 · 字体授权台账（商用合规）

> 结论先行：**马善政（Ma Shan Zheng）可以商用**，它和思源宋体用的是同一个协议 —— SIL Open Font License 1.1（OFL 1.1），免费商用、可修改、可分发、可嵌入。之前换掉它不是因为版权，是因为"商"字字形有瑕疵（丷与冂肩连写、口部歪斜），那是**质量问题，不是法律问题**。

## 二、OFL 1.1 的三条红线（记住这三条就够）

1. **不能单独卖字体文件本身**。但——**用字体做出来的作品完全自由**：壁纸 PNG、海报、封面、书、视频、包装、APP 界面，想怎么卖怎么卖，OFL 对"产出物"不设任何限制，也**不强制署名**。
2. **不能改名后当自己的字体分发**。"Ma Shan Zheng"是保留字体名（RFN），改过的字体不能再叫这个名字，且必须继续用 OFL 授权。
3. **用了就要带许可**。把字体文件放在服务器/产品里（网站 @font-face 也算分发字体软件）时，要在字体同目录带上版权声明 + OFL 全文；最省事的做法就是像现在这样把 `OFL-*.txt` 留在同一目录。

## 三、对我们的三个具体场景

| 场景 | 判定 | 动作 |
|---|---|---|
| 卖朝代壁纸（4K PNG，$ 定价） | ✅ 完全没问题 | 无需署名（可选加一行 credits 更专业） |
| 网站 @font-face 加载马善政/思源宋体 | ✅ 可以 | 把 `OFL-MaShanZheng.txt` / `OFL-NotoSerifSC.txt` 一并上传到字体目录即可 |
| LOGO 用马善政字形，之后注册商标 | ✅ 可以 | 注意：商标保护的是整体标识，别人仍可用同一字体做别的 LOGO |

## 四、建议写进页脚的一行（非强制，但显得专业）

```
Typography: Ma Shan Zheng & Noto Serif SC by Google, SIL Open Font License 1.1
```

## 五、以后选字体的避坑规则

- 只从**官方源**取：Google Fonts、github.com/googlefonts、Adobe/思源官方仓库、SIL 官网。第三方"字体下载站"常把"个人免费"写成"免费商用"，是主要雷区。
- 国内常见"免费商用"但**非 OFL** 的（如站酷系列、阿里巴巴普惠体），授权条款各不相同，用前看一遍各自的授权书，别默认等同 OFL。
- 有疑虑的（方正、汉仪、华康、造字工房）默认按**不可商用**处理，商用需付费授权。
- 备选可商用毛笔字体（同为 OFL，可作为马善政替补）：Liu Jian Mao Cao（柳建毛草）、Long Cang（龙藏）、Zhi Mang Xing（挚芒行）。
