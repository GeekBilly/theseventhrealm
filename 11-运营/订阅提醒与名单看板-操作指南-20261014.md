## 一、⭐ 先做这个：5 分钟，零代码，立刻生效

MailerLite 官方帮助《How to manage email notifications》里明确写了订阅者通知：

| 通知类型 | 触发时机 |
|---|---|
| **Subscribe one by one** | 新订阅者加入时**立刻**发一封邮件给你 |
| Unsubscribe one by one | 有人退订时立刻通知 |
| Daily summary | 每天一封，汇总前一天的新增与退订 |

### 步骤

1. 登录 MailerLite → 左侧 **Account settings**（账户设置）
2. 点 **Email notifications**（邮件通知）
3. 选 **Subscriber notifications** 标签页
4. 在 **Subscribe one by one** 一栏填你的邮箱 → **Save**
5. （可选）同页有 *Send the notifications when the subscribers join: any group* →
   点 **Change** 可改成只在特定组来人时才通知（比如只盯「壁纸领取」组）

### 两个要注意的点

- **只对「新订阅者」生效**：已存在的人被加进某个组不会触发（官方原文写明）。
  所以我们关心的新增，它一定报。
- **双重确认的影响**：留邮箱的人要**点了确认信**才算进组。表单提交但没点确认的人，
  在后台是 `unconfirmed`——工作台「订阅」tab 会单列这个数字，别把它当成有效名单。

配合手机邮件推送，这就是目前最实时、也最省事的方案。**今天就能开。**

### 开完之后，建议自测一次（10 分钟）

> **没验证过的通知开关，只是"我以为它开了"。** 常见失败模式：邮件进了垃圾箱、
> 域名被自己的邮件服务静默丢弃、填错了收件邮箱。**第一次只在真人来的时候才发现没收到，代价最大。**

用你自己的另一个邮箱走一遍真实表单：

1. 用一个**不是后台账号**的邮箱（避免混淆），前台走一遍订阅表单
2. 应该在 **1–2 分钟内**收到 MailerLite 的通知邮件 → 确认时效和收件箱都正常
3. 收到后去后台 **Subscribers** 把这个测试者删掉，名单数量复原
4. 顺手看一眼工作台「订阅」tab 的今日新增有没有变成 +1（验证报表这条备份链路也通）

**代价**：临时多 1 个人，删掉即恢复；且这一步同时验证了主链路（邮件）和备份链路（报表）。
只有自然来人时才第一次验证，等于把风险留到真人身上。

### 你只需做两件事

**① 拿 token**（一次性的事）

MailerLite 后台 → **Integrations** → **Developer API**（新版入口）→ Generate new token。
免费版给**读**权限，本脚本只读，够用（发信类接口免费版本来就给不了，用不到）。

**② 存进钥匙串**（不落盘、不进 Git，与 Cloudflare token 同一套做法）

```bash
security add-generic-password -a theseventhrealm -s mailerlite -U -w "<你的 Token>"
```

然后自检一次：

```bash
# ⚠️ 先 cd 到项目根目录——终端默认在家目录，直接跑会报 No such file or directory
cd ~/WorkBuddy/2026-09-25-15-56-17

python3 11-运营/scripts/mailerlite-stats.py check    # 它会分别探测新版与 Classic 端点
python3 11-运营/scripts/mailerlite-stats.py collect   # 取一次并落盘
python3 11-运营/scripts/mailerlite-stats.py show      # 人读
```

> ⚠️ **踩过的坑（2026-10-14）**：在 `~` 下直接跑 `python3 11-运营/scripts/...`，
> 路径会被拼成 `/Users/billyhou/11-运营/...` ⇒ `No such file or directory`。
> 看着像 token 失败，其实是目录不对。

之后每轮刷新（30 分钟）自动带上。**中午来的人，中午那一轮就能看到**——

## 三、进阶：webhook（现在不必要，留个口子）

新版 API 支持注册 webhook，事件包括 `subscriber.created` / `subscriber.added_to_group`
/ `subscriber.unsubscribed` 等，**每分钟批量推送一次**，带 `X-MailerLite-Signature` 签名可校验。

要吃到它需要一个**公网可访问的接收端点**——那就得在站点上放东西，属「改线上内容」，
按纪律要先出申请单。**在第一节的邮件通知够用之前，不建议做。**
真要做的那天，目标不是"记下来"而是"推到手机上"，否则和邮件通知没区别。
