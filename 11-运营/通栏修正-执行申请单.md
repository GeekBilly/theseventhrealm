## 一、背景

内容重整已成功：首页与 `5000years` 页现在由子主题模版统一输出（横幅 ✅ 导航 ✅ 页脚 ✅，双页脚已消除）。真实浏览器复核后，发现**两处像素级偏差**，都由父主题的一个隐藏设置引起。

## 二、实测数据（真实浏览器测量，非推测）

| 元素 | 现状 | 应然 |
|---|---|---|
| 品牌横幅 | left = **50px**、width = 1165px（左右各内缩 50px） | left = 0、width = 视口宽 |
| 主导航 | width = **1280px** > 视口 1265px，left = −7px | 与视口等宽 |
| 文档横向溢出 | scrollWidth 1273 > clientWidth 1265（**会出横向滚动条**） | 两者相等 |

## 三、根因（已用 DOM 逐层确认）

逐层读取 `.brand` 的祖先计算样式，结果：

```
.brand           padding: 0px    width: 1165  left: 50
.wp-site-blocks  padding: 0px    width: 1165  left: 50
<body>           padding: 50px!  width: 1265  left: 0
```

结论：**Twenty Twenty-Five 给 `<body>` 加了左右各 50px 的「根内边距」**，横幅老老实实跟着内缩；导航为了通栏用 `width:100vw` + 负 margin 硬撑，而 `100vw` 包含滚动条宽度（约 15px），于是左右各多出 7.5px 形成横向溢出。

> 这不是我们写错，而是「独立页面」与「WordPress 模版输出」两种上下文的差异——独立页面没有 body 内边距，所以当初没问题。

## 四、修正内容（已在真实页面注入实测通过）

```css
body{padding-left:0!important;padding-right:0!important}
.brand,nav{margin-left:0!important;margin-right:0!important;width:auto!important;max-width:none!important}
```

同时把导航规则里的 `width:100vw;max-width:100vw;margin-left:calc(50% - 50vw)` 改回 `width:100%`（不再依赖 100vw）。

**实测修复效果**：

| 指标 | 修复前 | 修复后 |
|---|---|---|
| 横幅 left / width | 50 / 1165 | **0 / 1265** ✅ |
| 导航 left / width | −7 / 1280 | **0 / 1265** ✅ |
| 横向溢出 | 1273 vs 1265（有滚动） | **1265 = 1265（无滚动）** ✅ |
