### 2. 标题、描述与社交分享卡片

现状实测：所有页 `<title>` 都是「第七境」，**没有** description、**没有** og/twitter 标签 —— 微信、X、脸书转发时是一块没有标题没有图的白板。

`functions.php` 里补上：

| 输出 | 规则 |
|---|---|
| `<title>` | 首页：`第七境 THE SEVENTH REALM · 五千年文明的水墨叙事`；内页：`页面名 · 第七境 THE SEVENTH REALM` |
| `description` | 首页固定品牌句；内页自动摘正文前 110 字（已剔除 `<script>` 内容，不会把 JS 写进摘要） |
| Open Graph | type / site_name / title / description / url / image |
| Twitter Card | card=summary + title / description / image |

### 3. 商标未注册期的合规标记（呼应你说的经营风险）

- 页脚品牌行改为 `第七境™ · THE SEVENTH REALM™`（`.tm` 小字上标，6.5px，实测不破坏版式）
- 页脚法律行新增：**「第七境」「THE SEVENTH REALM」为商标申请中标识（™），未经许可不得用于商业用途**

> ™ 是**未注册/申请中**的正确用法，® 必须等核准后才能用（乱用 ® 反而有法律风险）。注册下来后，把 HTML 里这两个字符换成 ® 即可，样式不变。
