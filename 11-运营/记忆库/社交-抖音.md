## 路由与解析（实测，别猜）
- 🔴 **唯一有数据的页**：`https://creator.douyin.com/creator-micro/data-center/operation`。
  `/creator-micro/data-center/content-data` 是**空路由**（导航过去只有侧边栏文字），别浪费时间试别的路径。
- 一页三段，用「数据总览 / 作品数据 / 粉丝数据」切成三段再取值：
  - 数据总览（7 天）：播放量 / 互动率 / 完播率 / 作品数 / 粉丝净增，另有「您的视频播放量为 X，高于 Y% 的同类创作者」
  - 作品数据（默认 tab，周期可能是 7 天也可能是 30 天，**以页上 period 为准**）：
    投稿量 / 总播放量 / 总点赞量 / 总分享量 / 总评论量 / 5秒完播率 / 2秒跳出率 / 封面点击率 / 平均播放时长
  - 粉丝数据（7 天）：总粉丝量 / 粉丝净增 / 吸粉量 / 脱粉量 / 回访粉丝量
  - 播放量贡献 TOP3：锚点「7日新增播放量」→ 上一行标题、下一行数值
- ⚠️ **两种排版必须都兼容**：总览区是「播放量 307」**同行**，作品区是「投稿量 \n 16」**分两行**。
  只按「标签行 → 下一行」取值会把总览全读成 null（已踩过一次）。
- ⚠️ 同类标签名在多个区重复出现（如「粉丝净增」总览区和粉丝区都有）⇒ 必须先切段。

## 判读口径
- 🔕 冷启动期：数据满 2 周前不下趋势结论，**不因「涨粉 0」报警**。
- **2 秒跳出率 ≥60% ⇒ 问题在开头两秒**，不在后面内容。这是抖音最该盯的一项。
- 播放高而完播低 = 推荐给错了人；两个一起低 = 内容本身没立住。
- 🔴 抖音的「完播率 / 2 秒跳出 / 5 秒完播 / 平均播放时长」小红书那边**没有对应物**，
  别拿同一套口径套两个平台。
- 封面点击率为 0 = 未进入推荐流样本，不是「封面差」。
