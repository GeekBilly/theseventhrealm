## 三、日常怎么用

### 3.1 客户从哪来

```
小红书 / B站 / 知乎（陌生人平台）
    ↓ 简介或私信里给二维码
企业微信（客户扫码）
    ↓ 自动通过 + 自动发欢迎语（含壁纸链接）
你收到消息 → 回复 / 成交
```

### 3.2 每天要做的

```
① 打开企业微信 App（手机 / 电脑）
② 看有没有新客户（会自动通过好友、自动发欢迎语）
③ 回复咨询
④ 给客户打标签（如「小红书」「问过桌面版」）
```

### 3.3 三件事绝对不要做

```
❌ 不要主动加熟人（会暴露你在做这个生意）
❌ 不要在个人微信上发商业内容
❌ 不要群发广告（会被举报，也会掉信任）
```

## 四、与小红书 / B站的衔接

### ⚠️ 平台的导流限制

```
小红书：留网址/微信号会被限流 ⚠️
B站：简介里放相对宽松 ✅
知乎：简介里可放
```

### 可行的做法（按平台）

**小红书**
```
· 简介写：「资料在置顶」或「看置顶评论」
· 置顶评论里给引导（不要直接写"微信"两个字）
· 或引导私信，私信里再给
· 有粉丝群的话，群里发
```

**B站**
```
· 简介里可以直接放（限制较松）
· 视频结尾口播引导
· 评论区置顶
```

**通用技巧**
```
· 不要写"加微信"，写"领取"/"资料"
· 二维码图片比文字安全
· 分渠道建多个二维码，便于统计（后台建"批量单人"码）
```

⇒ 结论：微信生态里，【企业微信】是个人做生意的唯一干净入口
