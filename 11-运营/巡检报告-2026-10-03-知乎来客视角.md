## 二、🔴 发现并修复的真问题

### 问题 1：MailerLite 表单旁的代码注释泄漏 —— **21 个页面全中**

**现象**：首页往下滚，MoneyLite 表单附近会出现这两行**正文**：

```
、并被
包裹 → 按钮下方多出空行。
```

**根因**（这是个我们早该记住的坑）：

```html
<p><!-- MailerLite 嵌入式表单 · 账号 … 
     多行会被插 <br />、并被 <p> 包裹 → 按钮下方多出空行。
     <style> 属块级，可多行。 … --></p>
```

注释里**嵌了 `<p>` 和 `<style>` 标签** → **区块主题会剥掉 HTML 注释** →
注释里的 `<p>` 把外层 `<p>` 提前闭合 → **剩下的注释内容全部漏成可见正文** ✅

**修复**：注释**整段删除**（不是"注释掉"）→ 21 页全部清理 ✅

```
首页 10239→9764 · 藏品页 10217→9742 · 索引 11080→10605 · FAQ 14222→13747 · 关于 9699→9224
16 个朝代页同步清理（各减 475 字符）
线上复核：泄漏文字 0 处 · 注释残留 0 处 ✅
```

### 问题 2：关于页残留 5 个未启分支 —— **同一类坑，之前漏改**

**现象**：关于页「七境之门」区块里，「小说 / 动漫 / 电影 / 游戏」四个未启分支**显示在页面上**

## 五、本次学到的（已考虑写入总原则）

> ### 区块主题里「注释」≠「隐藏」
>
> **HTML 注释在区块主题中会被剥离，注释里的内容会漏成正文。**
> **要隐藏内容，只能删除 —— 不能注释掉。**
>
> 而且：**注释里只要嵌了块级标签（`<p>` `<style>` `<div>`），就一定会造成标签失衡**，
> 失衡之后漏出来的不只是注释，还可能连带后面的正文。

**⇒ 建议加一条执行纪律**：
```
改线上内容前，先查该页有没有 HTML 注释；
凡注释里含标签的，一律删除（先备份），不得保留。
```
