## 三、方案与权限边界

使用 WordPress 原生「应用密码」+ REST API，配合**专用编辑账号**，权限严格受限：

| 能力 | 编辑角色（推荐） | 说明 |
|---|---|---|
| 编辑 / 发布页面内容 | ✅ 可以 | 我们的核心需求 |
| 上传图片到媒体库 | ✅ 可以 | Logo、横幅、插图 |
| 新建页面 | ✅ 可以 | |
| 改主题 / 上传主题 | ❌ 不能 | 子主题安装**仍需你手动上传 zip** |
| 装插件、改用户、改站点设置 | ❌ 不能 | 即使密码泄露也伤不到根基 |

> 也就是说：权限接入只覆盖「内容层」，碰不到「架构层」。子主题安装那一步依旧由你手动操作。

## 四、需要你操作的部分（约 5 分钟）

**第 1 步 · 建专用账号**
1. WP 后台 → 用户 → 添加新用户
2. 用户名填 `aibot`，邮箱填你自己的（可用 `你的邮箱+ai@gmail.com` 形式，避免占用真实邮箱）
3. 角色选 **编辑（Editor）** —— ⚠️ 不要选管理员
4. 强烈建议不要设置「站点登录密码」（生成应用密码后，此账号无需密码登录；若系统强制要求，随便设一个强密码即可）
5. 点「添加用户」

**第 2 步 · 生成应用密码**
1. 用 `aibot` 账号登录（或从用户列表进入该账号的「个人资料」）
2. 拉到底部 **应用密码（Application Passwords）** 区块
3. 名称填 `WorkBuddy` → 点「添加新的应用密码」
4. 屏幕上会出现一串形如 `abcd EFGH 1234 ijkl 5678 mnop` 的密码

**第 3 步 · 发给我**
把 **用户名（aibot）+ 这串应用密码** 发我即可。

> 这串密码只授权该专用账号，**随时可在同一页面点「撤销」立即失效**，不影响你自己账号的任何权限。
