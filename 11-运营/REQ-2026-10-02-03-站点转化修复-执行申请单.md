## 一、✅ 我能做（editor 权限内，页面正文）

### A. 首页首屏改造（用户指定重点）· 最高优先

**现状**（`page 13` 正文）：
```html
<p class="zi-top">道 生 一 · 一 生 二 · 二 生 三 · 三 生 万 物</p>
<h1>道境</h1>
<p class="subtitle"><span>天道酬勤</span><span>道法自然</span></p>
<div><span class="seal">七境之印</span></div>
<span class="scroll-hint">展 卷</span>
```

**问题**：**没有一个字说清"这是什么网站、有什么、下一步点哪"**。
访客落在首屏只看到一句哲学 +「道境」两个字 + 一个「七境之印」按钮 → 不知道能干什么 → 走。

**改法**（保留水墨气质，只加必要信息）：

| 位置 | 现在 | 改成 |
|---|---|---|
| 顶部小字 | 道生一…三生万物 | **保留**（气韵不能丢） |
| h1 | 道境 | **保留「道境」** |
| 副标题 | 天道酬勤 / 道法自然 | **改为一句人话**：<br>「**五千年华夏文明 · 十六朝水墨长卷**」 |
| 第三行 | （无） | **新增价值锚**：<br>「已写 9.5 万字 · 16 朝金句与文物 · **32 张手机壁纸免费**」 |
| 主 CTA | 「七境之印」按钮（无去处） | **新增**：<br>`[ 免费领取 32 张壁纸 ]` → `/collection/` |
| 次 CTA | 无 | **新增**：<br>`[ 先读长卷 → ]` → `/5000years/` |
| 印章 | 七境之印 | 保留（作为装饰，不再当按钮） |
| 展卷 | 展 卷 | 保留 |

> **原则**：**只做加法**，不动原有气韵。首屏从"只有意境"变成"有意境 + 说人话 + 有去处"。

### B. 首页「七境之门」去掉 4 个死链卡片

`<a class="todo" href="/novel|anime|film|game">` → 改成 `<span class="todo">`
（CSS 的 `.todo` 样式与"未启"角标已现成；注释在线上被 WordPress 吃掉，所以现在是**活的 404**）

### C. 藏品页：免费 zip 改为「留邮箱才给」

**现状原话**：「**不用留邮箱**，点下面的按钮就存到你的设备。」
**改成**：
- 免费 zip 保留，但**下载入口放到表单提交后**（MailerLite 自动化已跑通）
- 文案改：「**留个邮箱，32 张全套发你**（含 iPhone/Android 两种尺寸）」
- ⚠️ 同时**把裸链撤掉** —— 否则等于没改

### D. 藏品页：加「开售通知我」

复用同一个 MailerLite 表单（独立 group）→ 商品未上架也能**现在收意向**。

### E. 把表单铺到首页 + 16 个朝代页

现在 **17 个页面里 0 个捕获点**。把 `/collection/` 的 MailerLite 嵌入码复制过去。
⚠️ **必须压成一行 + 放在块级容器内**（HTML 注释里已写明此坑）。

### F. 统一免费交付分支（v2 → v3）

站点裸链给 **v2（5.5 MB）**，邮件给 **v3（6.8 MB）** —— 同一件免费品两个版本。
