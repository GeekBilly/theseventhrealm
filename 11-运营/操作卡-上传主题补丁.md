## 二、怎么上传（三选一，**A 最省事**）

### ✅ 方式 A · 上传主题包（推荐）

1. WP 后台 → **外观 → 主题**
2. 点顶部 **「安装主题」** → **「上传主题」**
3. 选 `seventhrealm-child-fixed-20261002.zip` → 立即安装
4. WP 会提示**主题已存在**，问你是否**替换** → 选 **「替换现有」**
5. 完成后确认子主题仍是**启用**状态（应该自动保持）

> **为什么推荐**：一次覆盖全部 4 个文件，不用手改；
> 而且我**已备份原文件**，出问题可回滚。

### 方式 B · 只改模板（不碰 PHP/CSS）

区块主题的**站点编辑器**能改模板：

1. 外观 → **编辑**
2. 左侧 **模板** → 找 **page**（页面模板）
3. 右上 **⋮ → 代码编辑器**
4. 全选删除 → 粘贴工作区 `seventhrealm-child/templates/page.html` 的内容
5. **保存**

⚠️ 这只改得了 `page.html`；**`functions.php` / `qijing.css` / `style.css` 改不了**（那几个得用方式 A 或 C）。

### 方式 C · 主机文件管理器 / FTP

登录你买主机时的控制面板（宝塔/cPanel 等）→ 文件管理器 →
进 `wp-content/themes/seventhrealm-child/` → 逐个文件覆盖。
适合你熟悉主机面板的情况。
