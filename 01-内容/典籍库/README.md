# 典籍库 · 引用原文工程

把《上下五千年》引用的典籍，**逐条录出可核验的原文**，建成可上线的站内文献库。

**不是全本库**——只收本书实际引用的段落（317 条，涉及 179 种）。理由：全本上亿字，而读者真正需要的是「你引用的那句话，原文是什么、上下文是什么、有没有争议」。

## 一、四条硬规矩（不可逾越）

| 类别 | 判定 | 处置 |
|---|---|---|
| **A 公有领域** | 1911 年前成书；或作者卒于 1975 年前（中国：终身 + 50 年） | ✅ 录原文、可上线 |
| **B 在版权期** | 作者卒于 1976 年后，或机构作品未满保护期 | ❌ **只做书目条目，绝不上全文** |
| **C 官方文件** | 法律/法规/国家标准及官方正式文本（著作权法第 5 条不保护） | ✅ 可录可上线 |
| **D 图·碑·画** | 藏馆享有图像权利 | ❌ **不复刻图像**，只做条目说明与出处 |

**B 类**（7 种）清单：夏商周年表、夏商周考古学论文集、最早的中国、何以中国、纣恶七十事的发生次第、国史大纲、古史辨。这些只登记书名/作者/年份与「本站引用了哪一句」，并链接到正版渠道。

**D 类**（7 种）：清明上河图、韩熙载夜宴图、同光十三绝、无字碑、述圣纪碑、大秦景教流行中国碑、郑和航海图。

## 二、录文规范

每条录文必须包含五要素：

```
### 引文 N · 一句话标题
**本站用法**：第 X 章「Y」—— 说明这条原文在正文里承担什么
> 原文段落
- 录文状态：已校 / 待校 / 需核
- ⚠️ 争议与冲突（若有，必须与正文口径一致）
```

**录文状态（原有三档 + 校对轮次新增两档）**：
- **已校** —— 流传稳定的名段，可独立核验
- **待校** —— 已录但需核对具体段落/页码
- **需核** —— 存在纪年、数字或史源歧异，暂不给单一结论
- **出处已核·文字待校**（2026-10-01 新增）—— **篇目归属、纪年、数字已核对通行记载并成立**，但仍未持点校本逐字核过文字
- **⚠️ 待补原文**（2026-10-01 新增）—— **现在录的根本不是原书原文，而是定义式概括**；属 P0 硬伤，未补原文前不得作为原文上线

### 🔍 校核字段（2026-10-01 建立）

本轮校对给每条加一行固定格式的记录，写在「录文状态」行之后：

```
- 🔍 校核（2026-10-01）：〈核了什么 / 核的结论 / 还须持点校本核什么〉
```

**为什么这样写**：校对**必须区分「我能核的」与「我不能核的」**。
本地没有点校本，**文字的逐字异同无从判断**——所以本轮核的是**出处归属、纪年、数字、史实归属**（这些靠通行记载可判断），
而**文字一律留白标「须持点校本核」**。**不把「出处确证」冒充成「文字已校」**，是本轮定下的硬规矩。

> ⚠️ **一条纪律**：**宁可写「未能确认」，也不猜。**
> 本轮有 1 条（苏轼条）明确写「未能确认此句出处」，2 条写了「疑误」但都标了「未核前不得上线」——
> **猜一个出处填进去，比留空危险得多**（见第五节第 2 条教训）。

**本站录文的性质**（每篇头部必须声明）：
> 古籍原文属公有领域，可自由录文与再发布。本站录文**不是**中华书局点校本的复制，而是据通行古籍文字重新录出，标点为本站点断。学术引用请核对点校本。

**争议必须与正文同口径**：凡正文写了「有争议」的，录文处必须同时标注，并给出不同说法各自的出处。不得在录文里偷偷裁定。

> ⚠️ **碑刻材料的两分法（易错点）**：**碑文本身（古文字）属公有领域**；
> 但**现代整理本的释文**与**拓片图像**（拍摄/拓印者享有权利）**不是**公有领域内容。
> → 用碑刻材料时，**自己据拓片录文**可以；**照抄现代整理本的释文或直接使用他人拓片图像**不可以。

### 校对怎么推进（用脚本，不要靠肉眼）

```bash
python3 proofread.py            # 全量体检，打印 P0/P1/P2 分级清单

```

**三级定义**：

| 级别 | 含义 | 谁来做 |
|---|---|---|
| **P0** | 硬伤：录文状态缺失 / 有状态却无原文块 / **录的不是原文（定义式概括）** | **必须清零**，脚本能查，本地可修 |
| **P1** | 待补：缺「本站用法」（无法关联到正文哪一章） | 本地可修，但**章号要靠人判断**——见下方教训 |
| **P2** | 待校：标了「节录·待校 / 需核」的 88 条 | **必须持点校本逐条核**，脚本无从判断文字正误 |

**P2 进度条的判据是「块内有没有 `🔍 校核` 行」，不是状态文字**（2026-10-01 定）：

```bash
python3 proofread.py          # 会打印 [████████··] 100% 这样的进度条
```

> ⚠️ **为什么用「有没有校核行」而不是状态文字判进度**：
> **核出问题的条目，状态仍然写「需核」**（如「姜维路线与史实相反」「《曲律》引文疑与原意相反」），
> 按状态文字判会把它算成「未推进」——**恰恰与事实相反，它恰恰是核过的**。
> 有校核行 = 逐条看过并写下了结论（**结论可以是「未能确认」**）。

> ⚠️ **P2 的「待校」其实有两种完全不同的东西，别混为一谈**（2026-10-01 校对轮次的最大收获）：
> ① **绝大多数是「出处未确证」** —— 内容是照通行古籍录的，只是没写清属于哪一卷哪一篇。**这类本地就能推进。**
> ② **少数是「有实质疑点」** —— 辑佚、伪古文、释读分歧、数字分歧、无定本的中译本。**这类只能持点校本核。**
> 本轮做的正是**把 ① 从 ② 里分出来**：① 推进到「出处已核·文字待校」，② 明确写清「须持某本核什么」。

> ⚠️ **P1 的教训（本轮真踩过）**：**别用「书名 → 章号」自动反查。** 《史记》被五六个朝代引用，按书名匹配会把「五铢钱」误判到第 4 章「周」（实为汉武帝，第 6 章「汉」）。自动匹配命中率仅 25%，且错的那些比不填更糟——**所以本轮 33 条全部逐条人工判断章号。**

### ⚠️ 一条必须知道的约定：⚠️ 有两种语义

录文标题里的 ⚠️ **不是单一含义**：

| 语义 | 例子 | 需要争议栏吗 |
|---|---|---|
| ① **此处有争议 / 须辨析** | 「共和行政的另一说 ⚠️ 本站周章的关键争议」 | ✅ 必须有，且**不得裁定** |
| ② **此处重要 / 本站重点** | 「密率与约率 ⚠️ 本站科学技术类最要紧的一条」 | ❌ 不需要，有「要点与分寸」即可 |

**脚本因此判定为「块内有任何 ⚠️ 说明块即视为已标注」**，不按关键词穷举（穷举必然误报）。
**「到底是不是真争议」交给人工抽查**——报告的「标题含 ⚠️」一栏就是抽查入口。
