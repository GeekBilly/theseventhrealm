# 二、徭律 · 「失期当斩」的争议 ⚠️ 本站秦章最要紧的一条

## 引文 1 · 《史记 · 陈涉世家》的说法

> **会天大雨，道不通，度已失期。失期，法皆斩。** 陈胜、吴广乃谋曰：「今亡亦死，举大计亦死；等死，死国可乎？」

- 录文状态：**已校**

## 引文 2 · 睡虎地秦简《徭律》的条文

> **御中发徵，乏弗行，赀二甲。失期三日到五日，谇；六日到旬，赀一盾；过旬，赀一甲。其得（也），及诣。水雨，除兴。**

- 录文状态：**已校**（此为学界反复引用的定式条文）
- ⚠️ **⚠️ ⚠️ 两相对照的问题（本站秦章的核心争议）**：

| | **《史记 · 陈涉世家》** | **睡虎地秦简《徭律》** |
|---|---|---|
| 失期的后果 | **法皆斩**（一律处死） | **迟到 3—5 天：斥责（谇）** |
| | | **迟到 6—10 天：罚一盾（赀一盾）** |
| | | **超过十天：罚一甲（赀一甲）** |
| 遇雨的处理 | （大雨导致失期，仍当斩） | **「水雨，除兴」——遇雨水则免除征发** |

  1. **这两条显然冲突**：**按秦简《徭律》，失期最重不过罚一甲，且遇雨可以免除，根本不至于「斩」。**
  2. **学界提出的解释（诸说并存，未有定论）**：
     - **① 时异说**：**睡虎地简属秦始皇时期，陈涉起义在秦二世元年（前 209）**——**二世时期法令可能加重，用法更苛。**
     - **② 事异说**：**《徭律》规范的是一般徭役（兴役），而陈涉等人所服的是「戍」（兵役、戍边）**，**二者适用不同的法律规定，戍律可能更严。**
     - **③ 宣传说**：**陈涉为鼓动同行者起事，可能夸大或虚构了后果**——**「今亡亦死，举大计亦死」的论证结构，需要一个「必死」的前提。**
     - **④ 律文与执行说**：**条文规定与基层实际执行存在落差**，地方官吏可能擅自加重。
  3. **学界主流倾向**：**多数学者认为②（徭役与戍役不同）是最可能的解释之一，但①与③也各有支持者，未有定论。**
  4. **本站口径（正文已采用）**：
     - **正文写「『失期当斩』之说与出土秦简《徭律》的记载存在歧异」**，并**并列上述诸说**；
     - **不作裁定**；
     - **并指出：无论取哪一说，出土简牍都使我们对秦法的理解从「暴政」的笼统描述，进入到了可以逐条比对的层面。**
- 关键词：失期法皆斩 · 谇 / 赀一盾 / 赀一甲 · 水雨除兴 · **诸说并存**

# 三、秦律十八种 · 秦代行政的细密程度

## 引文 3 · 田律（节选）

> **春二月，毋敢伐材木山林及雍（壅）隄水。不夏月，毋敢夜草为灰，取生荔、麛㲉（卵）鷇，毋……毒鱼鳖，置阱罔（网），到七月而纵之。**

- 录文状态：**已校**（学界常引的条文）
- ⚠️ **⚠️ 这一条的分量（本站秦章可用）**：
  1. **这是一条生态保护的法律**：**春季二月禁止砍伐山林、堵塞水道；不到夏季不准烧草为灰；不准捕杀幼兽、掏取鸟卵……至七月解禁。**
  2. **它的现代意义**：**这被认为是世界上较早的、成文的季节性资源保护法规之一。**
  3. **但同时说明秦法的特点**：**秦律的细密程度极高**——**几乎把行政、经济、生产的每一个环节都纳入了条文**，**这与后世对秦「严刑峻法」的印象其实是同一件事的两面：细密即严苛。**
- 关键词：春二月毋敢伐材木山林 · **细密即严苛**

## 引文 4 · 仓律 / 效律（节选）

> **（效律）** ……**计脱实及出实多于律程，及不当出而出之，直（值）其贾（价），不盈廿二钱，除；廿二钱以到六百六十钱，赀官啬夫一盾；过六百六十钱，赀官啬夫一甲……**
