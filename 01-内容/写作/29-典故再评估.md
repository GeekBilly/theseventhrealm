---

## 一、评估标准

```
① 知名度    普通读者是否听说过（越高越好）
② 匹配度    典故内核与该卷品质的契合程度
③ 时代      是否真的发生在该卷的年代范围内
④ 故事性    有没有情节、人物、冲突（可改编空间）
```

## 三、🔴 建议替换的两处

### 3.1 卷2：周公制礼 → **封神演义**

**为什么换**
```
现选：周公制礼
  ✅ 匹配度满（礼的源头）
  🔴 但它【不是故事】—— 制礼是制度建设，没有情节 ⚠️
  🔴 知名度中等（文化人知道，普通人模糊）

替换：封神演义
  ✅ 知名度极高（姜子牙、哪吒、妲己、武王伐纣，家喻户晓）
  ✅ 是【神话】—— 正合用户要的"神话传说"
  ✅ 故事性满（人物众多、冲突激烈、有完整起承转合）
  ✅ 时代在范围内（商末周初，约前 1100–前 1046）
  ✅ 而且它和「礼」的匹配【比周公制礼更强】：
     封神的本质 = 【给天地重新定秩序】
     姜子牙封三百六十五位正神 = 给整个宇宙立规矩 ✅✅✅
     ⇒ ⇒ 【封神 = 礼的极致】✅
```

**⚠️ 但要注意一点**
```
《封神演义》是明代小说（许仲琳），写的是商末周初的事
⇒ 按"故事发生的年代"算，在卷2 范围内 ✅
⇒ 按"成书年代"算，在明代
⇒ ⇒ 采用【故事发生的年代】为准（用户在上一轮已确认这个原则）✅
```

### 3.2 卷4：竹林七贤 → **三国演义**

**为什么换**
```
现选：竹林七贤
  🔴 知名度太低（普通人说不出七贤是谁）⚠️⚠️
  🔴 匹配度一般（乱世坚守 ≠ 信）

替换：三国演义
  ✅ 知名度最高（中国最家喻户晓的历史故事）
  ✅ 时代在范围内（180–280，卷4 是 220–589）
  ✅ 人物极多 —— 大量"有名有姓但记载不多"的人
     ⇒ 完美符合用户要的"荆轲身边的人"模式 ✅✅
  ✅ 故事性满
  ✅ 匹配「信」：
     · 太史慈 —— 《三国志》原文「信义著于四海」✅✅
       典故：答应孙策办事，约定日期必返
     · 或者：一个守信的小人物（主角可以是他）
```

**⚠️ 但有一个要处理的冲突**
```
三国最出名的是【义】（关羽）
⇒ 而"义"已经给了卷3（荆轲刺秦）⚠️

解法：
  卷3 荆轲 = 义（士为知己者死）—— 个人层面的义
  卷4 三国 = 信（太史慈如期而返 / 一个小人物守住承诺）
  ⇒ ⇒ 不冲突：一个是"为知己死"，一个是"说话算数"✅
  ⇒ 而且卷4 的主角不该是关羽 ——
    而是一个【守信用的小人物】，在乱世里被人记住 ✅
```
