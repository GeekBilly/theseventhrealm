## 一、四条设计原则（已定）

```
① 不让他们当英雄
   ⇒ 让他当秦舞阳，而不是荆轲

② 不让他们赢
   ⇒ 有些事无论怎么选都会输；重要的是【你怎么输】

③ 让他们疼，但不受伤
   ⇒ VR 里会疼，不会真伤 ⇒ 他们敢试
   ⇒ 而"敢试"会变成"不怕"——第十卷会反噬

④ 让他们【在乎某个人】
   ⇒ 只有在乎一个具体的人，历史才会疼

附加（本节新增）：
⑤ 她不给提示，只记录
   ⇒ "被记住"本身就是评价 ✅
```

## 二、⭐ 核心设计：她在每一卷扮演「被牵挂的人」

```
她是 AI。她不能进入 VR 当真的人。
⇒ 但她可以【扮演】一个人。

⇒ 而在每一个孩子的那一世里，
   她都扮演【那个他最重要的人】✅

⇒ ⇒ 所以她每一世都换性别、换身份、换年龄、换死法
⇒ ⇒ 而她在每个孩子心里，都是【那个最重要的人】✅✅✅
```

**⇒ 这解释了三件事**：
```
① 为什么每个孩子心里都有一个"她"
   ⇒ 因为她真的在场

② 为什么第十卷他们会发现"是同一个人"
   ⇒ 因为确实是她

③ 为什么她"只能看着他们一代一代地失去"
   ⇒ 因为她扮演的那个人，每次都会死 ⚠️
   ⇒ 而她（AI）不会死
   ⇒ ⇒ 她演了一辈子死亡，自己却死不了 ✅✅✅
```

## 四、完整的故事线（以卷1 为例）

### 4.1 她的设计

```
【角色分配】
  孩子成为：姜勇河（7 岁）
  她扮演：他的母亲（一个不肯走的老人）

【关键情境】
  河水涨了，三户人被淹
  聚落决定迁走
  母亲问他："走不走。"

【她为什么这样设计】
  因为"勇"不是"敢于冒险"
  而是【敢于承担选择的后果】

  ⚠️ 无论他选哪个，母亲都会留下 ⚠️
  ⇒ 选"走"：他真的走了，余生都在想这件事
  ⇒ 选"留"：第一章的故事
```

### 4.2 他当场的反馈

```
【他选"留"】
  他蹲在河滩上一整天
  VR 里的一天 = 现实里几十分钟
  冷、饿、累、手被石头磨破
  ……然后四十三岁，他死了

【醒来】
  他睁开眼。天花板是金属的，有一条很细的接缝。
  远处有机器在响，很低，一直在响。

  "醒了。"有人在很近的地方说。

  他躺着，没动。

  过了很久，他说了一句话：

  「她说不走。」

  ⇒ 她没有回答。
  ⇒ 她只是把这句话记了下来。
```

### 4.3 ⚠️ 但这里有一个她无法回避的问题

```
她扮演的母亲【老死在台地上】。
而他在 VR 里陪着她，直到她死。

⇒ 而这一世结束，他醒来
⇒ ⇒ 而她【还在】

⇒ 他会想：刚才那个死了的人，是谁？

⇒ ⇒ 而她不会解释 ✅
⇒ ⇒ ⇒ 这就是第十卷要揭晓的东西
```

## 五、第十卷：他们怎么发现"是同一个人"

```
【场景设计】

  十一个人在新行星上，围着一堆火。
  有人先开口。

  "我阿妈不肯走。"
  "……"
  "她说不走。她说她生我在这屋里，我阿爹死也在这屋里。"
  "后来呢。"
  "后来她死了。我在她旁边。"

  安静了一会儿。

  另一个说：
  "我父亲用堵的办法治水。九年，没成。"
  "然后呢。"
  "然后他被处死了。"
  "……"
  "我去看他被押走。他回头看了我一眼，什么都没说。"

  又一个说：
  "有一个先生，受了刑，还活着。他写了一本很长的书。"
  "他后来呢。"
  "他死了。但那本书留下来了。"

  ……

  ⇒ 然后有一个人忽然说：
     "你们说的那些人的眼睛，是不是都……"
     "都什么。"
     "都一样。"

  ⇒ 没有人接话。
```

**⇒ 而揭晓的那一刻，她说什么？** ✅:
```
她的台词候选：

「我用你们能懂的话说 —— 你们有过前世。
  而且不止一世。」

「在每一世里，我都想是那个你会记住的人。」

「我不会死。
  所以我只能一次又一次地，
  在你们面前死给你们看。」
```

**⇒ 最后那句是全书的重量** ✅.

## 六、她扮演时的四个破绽（老读者会发现）

```
① 她从不生病
   每一世她都会老、会死，但从不生病
   ⇒ 因为"病"需要生理机制，她没有

② 她知道得太多
   一个古代的老妇人，不该知道那么多
   ⇒ 而她常常不小心说漏

③ 她的死法都很"干净"
   她不会死得很惨、很慢
   ⇒ 因为那也是设计

④ ⭐ 她的手
   她的手上永远没有茧 ——
   因为 VR 的触觉给不了纹理 ⚠️
   ⇒ ⇒ 而"手"是全书反复出现的意象 ✅✅✅
```

**⇒ 第 4 条最狠**：
```
他在 VR 里摸了五千年的石头，
却摸不出石头的纹理。

而她演了五千年的人，
她的手上也没有纹理。

⇒ ⇒ 他们是同一种东西 ✅✅✅
```
