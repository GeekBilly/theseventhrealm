# 第七境 · 第一卷 上古 · 三代

## 第一章 · 留在这里的人

> 文体：历史纪录片口吻（仅用于旁白）+ 镜头语言（用于场景）
> 主角：姜勇河（品质 = 勇）
> 时代：约公元前 2500 年，黄河北岸

---

### 一

【远景】一条河，从画面左边流到右边。水面很宽，颜色是黄的。

镜头慢慢退。

台地。台地上有几十个圆形的土屋，屋顶是茅草，冒着烟。

再退。

河的这一边，台地，几十个土屋。
河的那一边，什么也没有。

再退。

两条河。一条黄的，一条清的。它们之间，是一片很大的平原。

——纪录片旁白：这是公元前两千五百年左右的中国北方。河流、台地、茅屋，看上去和几万年来的样子差不多。但有些事已经不一样了：人们开始种地，开始盖房子，开始在一个地方住上几十年。他们给这条河起了名字，但那个名字没有留下来。

留下来的，是这些人。

还有他们和这条河之间的那件事。

---

### 二

那年夏天，雨下了很久。

【特写】雨点打在水面上，一个坑，一个坑。

【近景】台地最低的那一角。水已经漫上来，没过了门槛。

【黑】夜里。能听见水声。越来越大。

有人在喊。喊的是一个女人的名字。

然后是一声很短的声音，不像喊，像什么被掐断了。

然后什么都没有了。

【空镜】天亮了。

浑黄的水面。水面上漂着木头，芦苇，一头被泡胀的猪。它在水面上慢慢地转。

【静】台地上站着人。十几个人。没有人说话。

【特写】一个女人的手，攥着自己衣服的下摆。攥得很紧。

---

### 三

水退了以后，他们在台地上开了会。

会开了三天。

第一天，没人说话。人们只是坐着，看那三户人原来住的地方。那里现在是一堆塌了的土。

第二天，一个中年人站起来。

"往上走。"

大家看他。

"上面三十里有塬。"

"那儿没水。"

"挑。"

"挑一趟半天。"

"那就半天。"

"地呢。"

"那儿的地干。"

中年人不说话了。

过了一会儿，另一个人说：

"这儿是我们埋人的地方。"

"埋人的地方多了。"

"那不一样。"

"哪儿不一样。"

【静】没人答。

第三天傍晚，多数人决定走。

---

### 四

【近景】一个土屋。门口堆着几个陶罐。

一个老女人蹲在地上，把陶罐一个一个往里塞。

她往旁边看了一眼。

她儿子站在门外，没动。他背对着门口，看着河的方向。

"收拾啊。"她说。

他没动。

"你在看什么。"

"……"

"勇河。"

他这才回头。

"走不走。"

他看着她，过了很久。

"不走。"

【特写】老女人的手停了一下。然后继续塞陶罐。

"那我也不走。"

"你走。"

"我不走。"

"阿妈——"

"我说话你听着。"她把最后一个陶罐放好，站起来，拍了拍手上的土，

"我生你的时候在这屋里。你阿爹死的时候也在这屋里。"

她往屋里看了一眼。

"我走不了。"

---

### 五

【切】第二天早上。

台地上的人开始往北走。他们背着东西：陶罐、席子、几把石锄、几袋粟。有小孩骑在大人脖子上。有狗跟着。

姜勇河站在台地边上，看着他们。

走在最后面的一个老人回过头。

"勇河。"

"嗯。"

"你也来吧。"

"我不。"

老人看了他一会儿。

"你会死在这儿的。"

"嗯。"

老人摇摇头，转身走了。

【远景】队伍往北，越走越小。台地上剩下三个人：他、他母亲、另一个老头。

【静】风把地上的灰吹起来。

---

### 六

【切】他去河边了。

【特写】他的脚，踩在河滩上。沙子很软，踩下去陷一指深。

他蹲下来。

【近景】他蹲在河滩上，看着水。

【空镜】太阳从东边升起来。水面上的光从黄变白。

【空镜】太阳到头顶。水面上的光很硬。

【空镜】太阳偏西。水面开始发红。

【空镜】太阳落下去。天黑了。

【近景】他还蹲在那儿。

——他就这样蹲了一整天。

---

### 七

第二天他又去了。

这次他带了根棍子。

他在河滩上画。画了半天，画出一大堆线：横的，竖的，弯的。

【特写】棍子的尖，在湿沙上划过。

画完，他站起来，退后几步，看。

看了一会儿，他又蹲下去，把其中一大半线抹了。

只留下一条。

那条线从河里出来，绕过台地，一直划到很远的地方。

---

### 八

他回到台地上，走到那两个老人面前。

他用棍子在地上画同样的一条线。

画完，他抬头看着他们。

那个老头看了半天，问：

"这是啥。"

他指了指河边那个拐弯的地方。又指了指台地最低的那一角。然后指了指地上那条线。

老头皱着眉，还是不懂。

他母亲倒是看懂了。她慢慢地说：

"你是要……把水引开？"

他摇头。

他指着那条线，从河边开始，一直指到台地外面。然后他做了个推的动作。

【静】

老头忽然明白了。

"你是要——挡？"

他点头。

老头笑了一声。

"挡。挡得住吗。"

他没答。

他把棍子插在地上。

---

### 九

【切】他开始挖。

【特写】他的手，握着一块磨尖的石头，往土里砸。

一下，两下，三下。

土很硬。砸了十几下，才砸出一个坑。

【特写】手指。指甲缝里立刻塞满了土。

【空镜】日头。影子从长到短，又从短到长。

第一天，他一个人。

第二天，他一个人。

第三天，那个老头来了。他没说话，蹲在他后面，开始挖。

第五天，他母亲来了。她不是来挖的。她是来送水的。

【近景】她把一个陶罐放在地上，看着他。

他回头看了一眼。

她什么也没说，转身走了。

第七天，她开始每天送水。而且把台地上剩下的陶罐全都搬了过来。

第十天，一个过路的人站在旁边看了半个时辰。

他看姜勇河挖，看那个老头挖，看那条已经成型的土垄。

他问了一句：

"你们干什么。"

老头答：

"挡水。"

那人又看了一会儿。

然后他走了。

——三天后，他带了七个人回来。

---

### 十

土垄变成了一道堤。

【远景】一百多步长，齐腰高。

他们用手，用石头，用了四个月。

【特写】堤的截面。土是干的，里面掺了芦苇——这是后来的做法，一开始他们没掺。

【切】第二年春天。水来了。

【远景】夜里。水从上游过来。

【近景】堤。

【特写】水撞在堤上，溅起来，落回去。

【长时间的空镜】天从黑到灰，从灰到白。

天亮。

堤上有一个口子。

水从那个口子灌进来，漫过了台地最低的那一角——但没有漫上去年那么高。

【静】四个人站在台地上，看着那个口子。

看了很久。

那个老头第一个走过去，蹲下身，开始用手把土往口子里填。

姜勇河跟着走过去。

---

### 十一

他没有成功。

但他们挡住了大约一半。

【切】第二年，他们把堤加高了。

【切】第三年，他们学会在土里掺芦苇。

【切】第五年，水来了，堤没破。

【切】第七年，下游的人来了。

——那件事，是下一章的事。

---

### 十二

【远景】很多年后。台地上有更多的土屋。

一个男人坐在地头。

他四十多岁了。背有点驼。手背上全是疤。

他在看河。

【特写】他的眼睛。眼角有很深的纹。

【切】屋里。他躺着。呼吸很浅。

他的儿子坐在旁边。

【切】屋外。风很大。

【切】四百年后。另一条河。一个赤脚的人站在岸边。

【切】一千年后。一个穿麻衣的人在竹简上刻字。

【切】四千年后。一个穿长衫的人在灯下写书。他写到"夏本纪"三个字，停了一下。

——纪录片旁白：他叫姜勇河。这个名字是我们从一块陶片的一个刻痕上认出来的。那个刻痕只有一笔，像一根棍子插在地上。

我们不知道他长什么样，不知道他说话是什么声音。

我们只知道一件事：

在他之前，这一带的人遇到水，只有一个办法——跑。

在他之后，有了第二个办法。

---

## ⚠️ 本版与旧版的区别

| | 旧版 | 本版 |
|---|---|---|
| 开场 | "他出生的那一年，这片土地上大概有几百万人"（数据开场） | **远景→退镜（从河退到平原）** |
| 水涨 | "第十天夜里，水漫过了台地最低的那一角" | **黑场 + 声音（喊声被掐断）** |
| 开会 | 概述三天 | **实际对话（往上走 / 这儿是埋人的地方）** |
| 决定不走 | 直接说"他没有走" | **对话（母亲塞陶罐 / 走不走 / 我不走）** |
| 看水 | "他在河滩上蹲了整整一天" | **五个空镜（日出到日落）** |
| 挖第一锹 | "他挖了第一锹" | **特写（石头砸土十几下才出一个坑）** |
| 别人跟上 | 概述 | **具体（第三天老头来 / 第十天路人 / 三天后带七个人）** |
| 结尾 | 时间跳跃（文字） | **四组跳切镜头（四百年/一千年/四千年后）** |

## ⚠️ 作者须知

### 一、本章的镜头清单

```
远景      河 / 台地 / 两条河与平原（三段退镜）
特写      雨点打水 / 女人攥衣角的手 / 陶罐 / 石头砸土 / 指甲缝 / 他的眼睛
黑场      夜里那声被掐断的喊
空镜      天亮的浑黄水面 / 一整天五个时段的太阳与水面 / 风把灰吹起
近景      台地最低的一角 / 土屋门口 / 堤
跳切      四百年后 / 一千年后 / 四千年后（三连跳）
声音先行  夜里的水声 → 喊声 → 什么都没有
静默      四个人站在台地上看着口子
```

### 二、对话的处理

```
· 极短（"往上走。""挑。""哪儿不一样。"）
· 有古语感（"阿妈""阿爹""我说话你听着"）
· 最关键的那句用动作代替（他不说"我留下"，他只是不走）
· 母亲的那段是本章唯一的长句：
    "我生你的时候在这屋里。你阿爹死的时候也在这屋里。我走不了。"
```

### 三、结尾的设计

```
【四千年后那一段】：
  一个穿长衫的人在灯下写书。他写到"夏本纪"三个字，停了一下。

⇒ 那是司马迁 ✅
⇒ ⇒ 而卷3 的主角是【任安】—— 司马迁《报任安书》的收信人 ✅✅
⇒ ⇒ 全书的第一次伏笔回环 ✅
```
