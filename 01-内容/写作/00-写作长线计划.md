## 一、核心流水线（用户定义）

```
争议典故 ──→ 侦探式考据 ──→ 高可能性推断 ──→ 故事 ──→ 文艺化 ──→ 小说
   选题        知乎回答           结论          短篇      风格化    最终形态
              （摆证据、标概率）              （有情节有人物）  （加道境世界观）
```

### 每一段的职责与判据

| 段 | 产出 | 判据（做到什么算合格） |
|---|---|---|
| **① 选题** | 一个【有争议、有材料、有反转】的典故 | 网上流传的说法 ≥2 种，且能指出矛盾点 |
| **② 回答** | 2000–4000 字知乎回答 | 每条主张都能溯源；有争议处标「学界有几种说法」；不用「最/第一」不加限定 |
| **③ 推断** | 一段 200 字以内的「我的判断」 | 明确写出「可能性高的是 X，因为 A/B/C；但 D 也不能排除」 |
| **④ 故事** | 3000–5000 字短篇 | 主角是【那一朝的普通人】；细节全部有史料出处；不虚构史实，只虚构【史书没记的部分】 |
| **⑤ 小说** | 长篇章节 | 加「道境」的世界观（三释 / 七境 / 文明之灵的传承）；允许改变历史事实 |

### ⚠️ 一条铁律（从底稿 §0 提炼）

```
【史书没记的，才是故事可以自由生长的地方】
· 喜什么时候出生、当过什么官 —— 有材料，不能改
· 喜那天晚上在想什么、跟谁说了什么话 —— 没材料，正是故事的空间
⇒ 这条界线守住了，「改变历史事实」才不会变成「不尊重历史」
```

## 六、第一篇的具体安排（现在就能动）

### ⭐ 建议首发：「黑夫与惊，后来怎么样了」

**为什么选它**：
```
① 材料最硬：两件木牍（现存最早的家书实物），湖北省博物馆藏
② 留白最大：信里有「淮阳」「反城」，但【没有战役名、没有生死记录】
③ 情感最强：一个士兵在信里反复追问「家里收到我的爵位文书没有」
④ 天然是三段式的：
     回答 = 这两封信说了什么、年代怎么定、哪些是推测
     故事 = 前 223 年，一个叫黑夫的人写下最后一封信
     小说 = 加「道境」：文明之灵的传承（他的爵位文书，最终到了吗）
⑤ 和你的「想法」形成呼应：你写「人生过半，只管去做」；
   黑夫写「报必言相家爵来未来」—— 都是【一个人对留下来的执念】
```

**回答的骨架**（沿用你「嬴政灭六国」那篇的套路）：
```
先说结论：我们对这两封信的了解，比对写信人本人多得多。

一、两件木牍是什么（22×4 厘米，一件 6 行、一件 5 行）
二、信里到底写了什么（要钱、要布、问爵位文书）
三、「写在公元前 223 年」是怎么推出来的（淮阳、反城的年代线索）
四、⚠️ 哪些是推测：
     · 他们是兄弟吗     → 简文没写
     · 他们战死了吗     → 没有任何材料
     · 爵位到了吗       → 不知道
五、但有一件事是确定的：这两封信被【随葬】了
     → 谁会拿两封家书陪葬？研究者推测墓主就是收信人「衷」
     → 【他把弟弟的信，带进了自己的墓里】
```

**故事的方向**：
```
视角：衷（收信人）
场景：他收到信的那天 / 他决定把信放进自己墓里的那一天
不写战场上发生了什么（没材料，不编）
只写：他等信、读信、回信、收不到回信、最后把信带走
```
