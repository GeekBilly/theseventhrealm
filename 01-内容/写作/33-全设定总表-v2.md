# 一、全局设定

## 1.1 世界与主题

| 项 | 内容 |
|---|---|
| 品牌 | 第七境 / THE SEVENTH REALM |
| 第七境三层含义 | ① 七大洲 → 亚洲 ② 人的第七重境界 = **无我** ③ 人类命运共同体 |
| 核心等式 | **无我 = 永生** |
| 永生之法 | 「不在肉身，在**文明之灵的传承**」 |
| 人类的位置 | **无地外文明，人类是宇宙唯一文明** |
| 与《三体》关系 | 借其设定，反其道：大刘=生存的恐怖；本文=**孤独的责任** |
| 中华文明为何没断 | **融合而非征服**（和）· 表意文字 · 科举带来的认同（学） |

## 1.2 纪年体系

```
公元前   约前 2700 ──────────────── 前 1 年
公元     公元 1 年 ──────────────── 公元 2148 年
星际元   S.E. 1 年（= 公元 2149）─── 银河

换算：S.E. N = 公元 (2148 + N)
里程碑：1949 + 200n → 2149(S.E.1) / 2349 / 2549
缩写：S.E.（Star Era）
```

| 前九卷 | 九部"电影"（孩子在 VR 里亲身经历） |

## 1.4 VR 技术（S.E. 时代）

```
路线：外周刺激（不是脑机接口）—— 因为"不是植入，是真经历过"

视觉 ✅ 完全可解
听觉 ✅ 完全可解
嗅觉 ✅ 可解，但有气味库上限   → "他闻得到血，闻不到花"
味觉 ⚠️ 只能合成基本味         → "他吃过五千年的饭，一口也没真正吃过"
触觉 ⚠️ 能给压力温度，给不了纹理 → "他能说出每块石头的重量，说不出它的手感"
重力 ⚠️ 重力舱 + 压力分布，快速动作失真 → "脚下少一点什么"
痛觉 ⚠️ 有信号但不真受伤       → 第十卷现实会疼 ⇒ 性格缺陷

实体锚点：船上几十件通用实体（石头/木棍/粗布/陶碗/铜刀/绳/兽皮/谷）
          映射成五千年的所有触感
          「那件粗布，是这艘船上唯一的一块布……它记得所有人。」
```
