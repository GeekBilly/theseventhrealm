## 一、被解除的约束

```
❌ 三户轮换表（4+4+3）
❌ 每卷 11 人固定分户
❌ 仿射平面 / 同户次数最优（2 次 / 3 次那些）
❌ 姓名表 11×9 必须填满
❌「每对恰好同户一次」这类数学要求
❌「每一世都在一起」
```

## 二、保留的核心

```
✅ 【11 个灵魂】—— 保留
   他们是 11 个独立的主体，各自有自己的一世（或多世）
   第十卷相遇

✅ 【成为过家人】这个机制 —— 保留
   但不再强求每一世

✅ 【第十卷的亲切感】—— 保留
   但换了更自然的解释（见第四节）

✅ 【姓名系统】—— 保留
   姓（体现朝代）+ 品质字（恒定）+ 末字（该朝文化符号）
   但不必为"不出现的人"也起名
```

## 三、出场原则（新）

```
① 按历史事件的顺序
② 按需出场 —— 那个事件需要谁，谁就出现
③ 不凑数 —— 不必每卷 11 人齐
④ 容许境遇不同 —— 有人一世孤独，有人儿孙满堂
⑤ 第十卷时，每个人至少和另外 2–3 人有【深厚的前世关系】就够
```

### 3.1 关系的四种形态

```
① 家人      —— 最重的一种
② 同乡/同族 —— 次重
③ 同僚/师徒 —— 中等
④ 对手/敌人 —— 也是关系，而且更难忘 ⚠️
```

**⇒ 而"对手"这一层很要紧**：
```
· 一个人对另一个人有【说不出的愧疚】
  ⇒ 因为某一世他害过他
· 一个人对另一个人有【说不出的距离】
  ⇒ 因为某一世他们是主仆，或敌我

⇒ ⇒ 第十卷不只是温情重逢，
   而是【十一个人要面对十一世的全部账】✅✅
```

---

## 四、⭐ 第十卷「亲切感」的两层解释

```
第一层 · 所有人之间：模糊的亲切感
  ⇒ 来源：他们共享【同一个 VR 世界、同一段历史】
  ⇒ 类比：同一个村子里长大的人 ——
          即使不认识，也有共同的气味 ✅

第二层 · 少数人之间：具体的、说不出的熟悉
  ⇒ 来源：那 2–3 世的深厚关系（家人 / 对手 / 师徒）
  ⇒ 表现：一个动作、一句话、一个习惯，对方立刻认出 ✅
```

**⇒ 两层叠加，比"每一世都是家人"更自然，也更丰富** ✅

## 五、卷一的出场（按历史事件）

| 段 | 时代 | 主角 | 核心事件 | 该出场的人 |
|---|---|---|---|---|
| 一 | 约前 2500 | **勇**（姜勇河） | 河水涨了，多数人迁走，他留下筑堤 | 他的家人 · 邻居 · 反对他的人 |
| 二 | 约前 2100 | **柔**（大禹） | 鲧堵失败被处死，禹改疏 | 鲧（父）· 舜 · 一起挖的人 |
| 三 | 约前 1050 | **礼**（卜人） | 商亡周兴，周公制礼 | 商王 · 周武王 · 周公 · 旧同僚 |

**⇒ 三段之间是【同族的三个时代】**：
```
姜勇河（前2500）→ …约15代人… → 大禹（前2100）→ …约30代人… → 卜人（前1050）
⇒ 他们【不是同一个人】，但是【同一族】✅
⇒ 而"传承"就发生在这条血脉上 ✅✅
```

**⇒ 其他 8 个灵魂在卷1 里可能出场，也可能不出场** ——
```
出场标准：那个事件需不需要他
⇒ 不必凑数 ✅
```
