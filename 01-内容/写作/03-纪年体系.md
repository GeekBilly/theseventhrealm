# 第七境 · 纪年体系

> 用户 2026-10-05 定：
> 「第十卷起始年用 2149 年，和 1949 年始终保持整倍数，
>  可以把人类历史分为公元前，公元，和星际元」

---

## 一、三大纪元

| 纪元 | 起 | 止 | 长度 | 含义 |
|---|---|---|---|---|
| **公元前** | — | 前 1 年 | — | 传说的时代 |
| **公元** | 公元 1 年 | **公元 2148 年** | 2148 年 | 有文字、有信史的时代 |
| **星际元** | **公元 2149 年** | — | — | 人类离开地球之后 |

### 换算

```
星际元 1 年  =  公元 2149 年
星际元 N 年  =  公元 (2148 + N) 年
公元 M 年    =  星际元 (M − 2148) 年   （M ≥ 2149）
```

---

## 二、为什么是 2149（用户的设计）

```
2149 − 1949 = 【200】✅ 整倍数

⇒ 所以里程碑年全是 1949 + 200n：

   1949        （基准年）
   2149        星际元 1     ← 人类星际航行元年
   2349        星际元 201
   2549        星际元 401
   2749        星际元 601
   …

⇒ 好处：任何一个"元年"都落在整百年份上，
        纪年换算永远是整数，不会出现尴尬的零头
```

## 四、这套纪年对小说的三个好处

### ① 开篇就有了"未来人的口气"

```
叙述者在星舰上，她说的时间是【星际元】；
而她讲的历史，用的是【公元】和【公元前】。

⇒ 一个句子里同时出现两个纪元，读者立刻明白：
  "我"在听一个来自未来的人，讲很久以前的事。
```

### ② 三纪元 = 三次文明跃迁

```
公元前 → 公元     ：从传说进入信史（文字成为证据）
公元   → 星际元   ：从一颗行星进入星际（人类离开摇篮）

⇒ 呼应「无我 = 永生」：
  "公元"这个词本身是西方纪年（基督纪元），
  而"星际元"不属于任何一个民族 ——
  它属于【人类命运共同体】✅
```

### ③ 1949 作为锚点的意义

```
1949 是基准年（新中国成立），
而 200 年后，人类离开地球。

⇒ 从"站起来"到"飞出去"，正好两百年 ✅
```

## 五、书中怎么写年份（体例）

```
叙述现在（星舰上）    「星际元三十七年」
叙述历史（公元后）    「公元 223 年」
叙述历史（公元前）    「公元前 213 年」
跨纪元表述            「公元 2149 年，也就是星际元元年」

⇒ 建议：每卷卷首标注该卷的纪元与年份范围，
        像史书的分卷题记
```
