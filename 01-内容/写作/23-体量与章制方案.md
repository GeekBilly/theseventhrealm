# 第七境 · 体量与章制方案

> 用户 2026-10-05：
> 「第一卷总字数我们之前估计了多少？还有每一卷里都要出现九个人，
>  所以这九个人是一点一点出现的，也不是一次出现的，出场顺序也有考究，
>  顺着历史的脉络自然而然的出场，也就是每一卷里其实九种品质都会出场，
>  只是侧重不同，根据这个，还有需要覆盖的年代跨度来定多少章，每章多少字，
>  这一卷就是一部小说了，而且是一个长篇，超长篇」

## 一、字数与章制

### 1.1 之前估的（来自 01-写作工程量化测算）

```
每卷      10–15 万字
全书      100–150 万字
每年产能  7–10 万字
工期      10–12 年
```

### 1.2 三个档位

| 档 | 每卷 | 每章 | 章数 | 九卷 | 含卷十 |
|---|---|---|---|---|---|
| 保守 | 10 万 | 4000 | 25 | 90 万 | **102 万** |
| **推荐** ⭐ | **12 万** | **4000** | **30** | **108 万** | **120 万** |
| 充分 | 15 万 | 4500 | 33 | 135 万 | 147 万 |

**⇒ 推荐档：每卷 12 万字 / 30 章 / 每章约 4000 字**
**⇒ 全书约 120 万字 —— 与《平凡的世界》(100 万字)、《战争与和平》(中译 130 万字) 同一量级** ✅

## 三、⭐ 九人出场的设计原则

### 3.1 底层原则

```
九个人 = 【一个文明成长所需要的九种角色】
⇒ 他们按"社会生长的顺序"出场
```

| 顺序 | 品质 | 被需要的时刻 | 角色 |
|---|---|---|---|
| 1 | **勇** | 什么都不确定 | 第一个敢动手的人 |
| 2 | **礼** | 需要秩序 | 立规矩的人 |
| 3 | **义** | 有了纠纷 | 判断对错的人 |
| 4 | **信** | 需要协作 | 守得住话的人 |
| 5 | **仁** | 有了弱者 | 看得见人的人 |
| 6 | **智** | 遇到难题 | 想得出办法的人 |
| 7 | **善** | 遇到灾荒 | 肯救济的人 |
| 8 | **真** | 有了疑问 | 敢较真的人 |
| 9 | **梦** | 望向远方 | 把目光放到远处的人 |

### 3.2 ⭐ 但每卷的顺序【不同】

```
每个时代"最先需要"的品质不一样
⇒ 出场顺序随之变化
⇒ 而本卷主角【先出场】（因为他/她是视角人物）
```

**示例（三卷对照）**：

| 卷 | 主角先出场 | 之后依次 |
|---|---|---|
| **1 起源**（什么都不确定） | **勇** | 信 → 义 → 礼 → 仁 → 智 → 善 → 真 → 梦 |
| **4 分裂**（乱世、离散） | **信** | 勇 → 智 → 义 → 仁 → 礼 → 善 → 真 → 梦 |
| **8 觉醒**（救亡、启蒙） | **真** | 勇 → 智 → 义 → 仁 → 信 → 善 → 礼 → 梦 |

**⇒ 每卷的出场顺序，本身就是一次"时代诊断"** ✅
```
· 卷1 把【礼】放在【义】之后（先有纠纷才需要规矩）
· 卷4 把【礼】放到很后面（乱世里礼先崩）
· 卷8 把【礼】放到倒数第二（旧礼被质疑）
⇒ ⇒ 老读者能从顺序里读出时代 ✅✅
```

## 四、卷一的章目（30 章 · 12 万字）

## 五、这套结构的五个好处

```
① 卷 = 一部长篇小说，可以独立出版 ✅
② 每卷 30 章，每章 4000 字 —— 是网文/长篇小说最舒服的章节体量
③ 九人陆续出场，读者有"认识新朋友"的节奏感 ✅
④ 出场顺序随时代变化 ⇒ 顺序本身在讲故事 ✅
⑤ 纪录片腔的时间跳跃，让"一生"能接住几百年 ✅
```
