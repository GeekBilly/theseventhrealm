## 二、⭐ 核心风格：十条

### ① 固定开场白

```
公众号：「大家好，我是Molly的爸爸，猴小贼。」
        「欢迎关注，一起上路。大家好，我是Molly的爸爸，猴小贼。」
```

**⇒ 建立人格，让读者知道"谁在说话"** ✅

### ② 从【具体】切入，不从【抽象】切入

```
❌ 抽象："人工智能正在改变世界。"
✅ 具体："1950年，计算机科学之父艾伦·图灵发表了划时代的论文
        《计算机器与智能》。……今年是2025年，距离图灵提出这个问题
        已经过去了75年。"
```

### ③ 结论先行，且短

```
"对于机器能否思考这个问题，我的答案也很简单。
 不能。"
```

### ④ 自嘲

```
"于是我一转念，竟把自己由一胎家庭变成了二胎家庭。
 白天在工作中训练人工智能。
 晚上回到家里训练人类智能。
 这个感觉说不上来，总觉得哪里不对。
 也不知道付出了这么多，等我有需要的时候，哪个智能能扶我去看病。
 Hmm...
 大概还是得靠自己。（所以养老规划可以从现在做起了...)"
```

### ⑤ 对比 + 提炼

```
"训练AI，讲究的是数据清洗、指令明确、强化反馈。
 而养育人类，核心无非是故事熏陶、以身作则、爱与边界。
 看似南辕北辙，内核却都是'输入'与'成长'。"
```

### ⑥ ⭐ 金句能力（最突出）

```
"和谐，不是变成对方，而是在清晰的边界上，建立对话的协议。"
"前者是工具，愈锋利愈好；后者是主人，愈丰盈愈好。"
"AI负责穷尽所有的可能；
 而人类，依然负责仰望星空，决定我们要去向何方。"
"我们四个人的属相，都挨着，还都在一根食指之上啊。"
"我是一只狮子。只不过看起来有点像兔子。"
"瞬间即是永恒。诺。"
"人的一生只有一个又一个微小的当下，直到世界的尽头。"
```

### ⑦ 对话直接引，不加"他说"

```
"爸爸，爸爸，宝盒用英文怎么说？"
我说："Box。"
她像一个成年人一样的口气说："我问的是宝盒~"
```

```
"你到底要不要回来接我的班？"
"我不回去。"
```

### ⑧ 诚实（承认不确定）

```
"应该没有太多的记忆，只能凭借着家人的只言片语来支撑这部回忆录了。"
"关于儿时最早的记忆现在已经有些模糊了，只有一些支离破碎的片段。"
"不敢说是不是一个标准的见证了中国从建国到崛起的全部历程的普通工人家庭。"
```

### ⑨ 结尾轻收 + 余味

"我，失败了吧？爸爸。"

## 四、⚠️ 我写那三章犯的错

| | 用户 | 我 |
|---|---|---|
| 起点 | 具体（1950年图灵 / 一道痂） | 抽象（"公元前2500年，几百万人"）⚠️ |
| 说话者 | 有明确的"我" | 全知旁白，没有"我" ⚠️ |
| 结论 | 先行且短（"不能。"） | 铺陈 |
| 诚实 | 承认记不清 | 假装全知 ⚠️ |
| 金句 | 每篇都有 | 几乎没有 ⚠️ |
| 结尾 | 轻收 + 余味 | 跳出（四千年后）⚠️ |
| 标注 | 无 | 满篇【特写】【空镜】⚠️ |
| 转折词 | 而 / 却 / 不过 | 少 |
| 英文插入 | Hmm... | 无 |

## 五、《第七境》的正确调子

```
【用 AI 母亲的第一人称"我"来讲】

她就是这个"我"：
  · 有固定开场（但不用"大家好"）
  · 从具体细节切入
  · 承认不确定
  · 提炼金句
  · 结尾轻收，留余味
  · 偶尔自嘲

⇒ 而她讲的是历史（第三人称的人）
⇒ ⇒ 所以是【她的口吻 + 别人的故事】✅✅✅
```

### 改写示例

**我原来写的（抽象 + 旁白）**：
> 【远景】一条河，从画面左边流到右边。水面很宽，颜色是黄的。
> 镜头慢慢退。
> 台地。台地上有几十个圆形的土屋，屋顶是茅草，冒着烟。

**改成（她的口吻）**：
> 他脚背上有一道口子，结了痂。
>
> 那道痂是七岁那年夏天留下的。他去河里捡一块石头，踩滑了。
> 那年水不大。第二年夏天，水就大了。
>
> 他们那个聚落有三十几户人，住在一条河的北岸，在一块比河面高出二十来米的台地上。
>
> 这个高度是选的。再低一点，水会淹上来；再高一点，取水要走太远。
>
> ——后来的人总结出一个词，叫"就水而居，择高而处"。
> 但在当时没有这个词。
> 他们只是试过很多次。淹死过一些人。然后记住了。
>
> 而我要讲的那个人，那年七岁。

**⇒ 差别**：
```
· 有"我"（"我要讲的那个人"）
· 从细节进（一道痂）
· 数字精确（七岁 / 三十几户 / 二十来米 / 第二年）
· 诚实（"当时没有这个词"）
· 结尾留余味（"而我要讲的那个人，那年七岁。"）
```
