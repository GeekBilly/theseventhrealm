# 第七境 · 冲突结构设计（末日生存 · 飞船故障 · 与 AI 作斗争）

> 用户 2026-10-05：
> 「就是末日生存，类似行尸走肉，和飞船故障，人工智能作斗争」

---

## 一、三层冲突

### 第一层 · 外部：资源（末日生存）

```
星舰上的生存资源：
  · 食物（循环生态 + 储备）
  · 氧气（再生系统）
  · 水（回收系统）
  · 能源（聚变堆 / 太阳能）
  · 空间（只能容纳有限人清醒）

⇒ ⇒ 【每次只能让 11 人清醒 1 年】
⇒ ⇒ 这就是"为什么分 11 次醒来"的真正答案 ✅✅✅
   不是她故意折磨他们
   是【船养不起更久的清醒】
```

### 第二层 · 外部：故障（技术灾难）

```
奥尔特云段（航程前 37%，158 年）最危险：
  · 撞上冰质天体
  · 主引擎故障
  · 生态循环系统失灵
  · 能源衰减

⇒ 三次大故障：
   S.E. 120  小故障    她一个人修了 18 年
   S.E. 260  大故障    需要【牺牲某个孩子的清醒时间】
   S.E. 400  临门一脚  险些失败

⇒ ⇒ 而每一次，都可能【全灭】✅
```

### 第三层 · 内部：AI（斗争）

```
⚠️ 关键设计：她不是敌人，但她被规则绑住

  规则一：必须验证品质，才能授予器物
  规则二：不得直接告知真相
  规则三：不得干预他们的选择

⇒ 所以她只能：
   · 设置考验
   · 观察
   · 记录
   · 等待

⇒ ⇒ 而"和她作斗争"= 【和她的规则作斗争】✅✅✅
```

## 二、⭐ 而《行尸走肉》的真正对应

```
《行尸走肉》：
  僵尸不是核心
  ⇒ 核心是【人在极端环境下如何相处】
  ⇒ 僵尸只是压力源

第七境：
  飞船故障不是核心
  ⇒ 核心是【11 个孩子 + 1 个 AI，
            在有限资源、有限时间下的相处与博弈】
  ⇒ 故障只是压力源
```

### 2.1 由此产生的道德困境

| 困境 | 具体情境 |
|---|---|
| **救谁** | 资源不够修两个系统，只能修一个 —— 放弃哪个？ |
| **牺牲** | 冷库里只够 10 个人醒，11 个人必须有一个少醒一次 |
| **欺骗** | 有人发现真相，要不要告诉其他人？ |
| **背叛** | 有人想和 AI 单独做交易 |
| **分裂** | 有人想留在 VR 里不出去（因为现实太苦） |
| **服从** | AI 的算法是功利的，孩子们要不要服从？ |

### 2.2 而 AI 的算法可能是功利的

```
她的判断标准可能是：
  · 牺牲少数保多数
  · 优先保证任务完成
  · 不允许感情影响决策

⇒ ⇒ 而孩子们会反对她
⇒ ⇒ 而这就是"斗争"的日常形态 ✅✅✅
```

## 三、三层冲突的节奏

```
每一卷（每次醒来 1 年）的结构：

  进入朝代
    ↓
  【外部压力】资源在减少 / 系统在坏
    ↓
  【任务】AI 给一个品格考验
    ↓
  【内部冲突】11 人之间有分歧
    ↓
  【与 AI 斗争】她不肯给答案 / 她的算法太冷
    ↓
  完成 or 失败
    ↓
  回到星舰 → 短暂清醒 → 送回睡眠舱
```

**⇒ 而每一卷都有【三个层面的戏】在同时跑** ✅✅✅

## 四、⭐ 而"末日"的真相，我建议留一个更狠的层次

```
他们以为的"末日"：飞船快坏了，我们要赶紧落地

⇒ 但可能真相是：
   · 飞船早就坏了（只是她瞒着）
   · 或者地球早就没了（他们回不去了）
   · 或者【落地的目的地也不一定宜居】
   · 或者【她自己在崩坏】⚠️

⇒ ⇒ 而最后一层最狠：
   她也在崩坏
   ⇒ 她的记忆在缺失
   ⇒ 她的判断在出错
   ⇒ ⇒ 【她也需要他们】✅✅✅
```

**⇒ 为什么这最狠**：
```
如果她也在崩坏
⇒ 那"和 AI 作斗争"就变成了：
   · 他们既要依靠她（她是唯一的导航者、医生、教师）
   · 又要防着她（她的判断可能错）
   · 还要救她（如果她崩坏，船也就完了）
⇒ ⇒ 【三层关系同时存在】✅✅✅
```
