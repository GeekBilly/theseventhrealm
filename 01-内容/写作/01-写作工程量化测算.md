### 写作速度的取值依据

```
深度历史写作（含考据、校对）实际速度：
  粗稿    800–1200 字/小时
  可发布  300–500 字/小时（含查证、改稿、反复）

⇒ 取保守值 500 字/小时
⇒ 每年可写字数（纯写作时间）：
     270 小时/年 × 500 = 13.5 万字
     406 小时/年 × 500 = 20.3 万字

⚠️ 但这只是"纯写作"。实际还要扣：
   · 网站维护 / 平台运营        −20%
   · 审稿来回（你改我改）        −20%
   · 灵感枯竭期 / 生活中断       −10%
   ⇒ 实际系数 ≈ 0.5

⇒ ⇒ 【现实产能：每年 7–10 万字】
```

## 三、工期测算（三个方案）

### 方案甲 · 稳写 ⭐ 我推荐

```
每年 8–10 万字 ｜ 每卷 10 万字 ｜ 全书 100 万字
⇒ 工期 【10–12 年】（2026 → 2036/2038）
⇒ 但每 12–15 个月可完稿一卷，不是"12 年后才有东西"
```

### 方案乙 · 精写（慢）

```
每年 5–7 万字 ｜ 每卷 15 万字 ｜ 全书 150 万字
⇒ 工期 【21–30 年】
⇒ 特点：可以极细、极抒情，但周期太长，风险高
```

### 方案丙 · 精简（快）

```
每年 12–15 万字 ｜ 每卷 8 万字 ｜ 全书 80 万字
⇒ 工期 【5–7 年】
⇒ 特点：节奏快，但会牺牲你最看重的"病态的细节执着"
```

**⇒ 我的建议：甲，但卷一按乙的精度写**
```
理由：卷一「起源」是打样的卷 —— 
     它要定下全书的语气、节奏、科幻框架，
     慢一点、精一点值得。
     卷二之后回到甲的速度。
```

## 四、⭐ 关键设计：三层并行，不要串行

**❌ 错误做法**：先写完 16 朝的知乎 → 再写小说 → 12 年后才有第一本书
**✅ 正确做法**：三层同时推进，每一层【独立成立】

```
┌─ 第一层 · 史实（已完成）────────────────────┐
│  16 朝正文 9.8 万字 —— 网站已上线             │
│  状态：✅ 完成                                │
└──────────────────────────────────────────────┘
┌─ 第二层 · 侦探与故事（2026-10 → 2028）───────┐
│  16 朝 ×（2 篇回答 + 1 篇故事）= 48 篇        │
│  平均 4000 字 ⇒ 约 19 万字                    │
│  节奏：每 2 周 1 篇 ⇒ 96 周 ≈ 1.8 年          │
│  ⭐【每一篇都独立发布】⇒ 立刻有产出            │
│  ⭐【同时就是小说的素材和试写】                │
└──────────────────────────────────────────────┘
┌─ 第三层 · 小说（2027 起，与第二层并行）──────┐
│  卷一「起源」约 12 万字                        │
│  素材来自第二层已积累的秦/汉/三代部分          │
│  ⇒ 写完一卷发一卷                              │
└──────────────────────────────────────────────┘
```

**⇒ 实际时间线**：
```
2026 Q4 – 2027 Q1   三皇五帝 + 夏 + 商 的回答与故事（第二层启动）
2027                卷一「起源」完稿 ← 【第一本书】
2027 – 2028         周秦汉 + 卷二「三代」
2028 – 2029         秦汉 + 卷三「帝国」← 【第二本书】
……
```
