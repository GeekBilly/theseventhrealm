# 第七境 · 末字设计（取自各朝典籍 · 人物 · 神话）

> 用户 2026-10-05：
> 「末字是不是可以和我们之前朝代里对应的典集人物和神话做一个匹配什么的」
>
> **⇒ 于是每个名字的第三个字，都是一个可以追溯的文化符号。**

---

## 一、设计规则

```
姓名 = 【姓】（常见 · 体现朝代） + 【品质字】（九卷恒定） + 【末字】（取自该朝文化符号）
```

**末字的三个来源**：
```
① 典籍   该朝的代表性文献
② 人物   该朝的代表性人物（取其名或字中的一字）
③ 神话   该朝的传说与象征物
```

**⇒ 老读者看到那个字，能想起那一朝的事** ✅

## 四、这个设计带来的额外收益

```
① 每个末字都是一个文化符号 ⇒ 名字本身在讲历史 ✅
② 老读者看到"姜勇河"，会想起河图洛书 ✅
③ 卷九的"孙勇星/孙礼航/孙义光" —— 一看就是未来 ✅
④ 卷一的"河洛龙龟" —— 一看就是上古 ✅
⑤ ⇒ 九个名字放在一起，就是一部缩微的中国文化史 ✅✅
```
