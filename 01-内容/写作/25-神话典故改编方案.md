# 第七境 · 神话典故改编方案

> 用户 2026-10-05：
> 「十卷故事都要以每个朝代的最典型的神话传说或者典故为蓝本来改编，
>  既要把中国传统文化中最振奋人心的故事写好，
>  又要把主人公对于历史的理解和思考还有感受沉淀，打磨，烙进灵魂的深处，
>  类似柯南的贝克街的亡灵一样，罪恶王冠一样，
>  主人公现实中可能在冬眠，进入虚拟世界之后身体不会受到伤害，
>  可以在不同的历史节点做出不同的选择，类似网络游戏」

---

## 一、这个设定的四层含义

```
① 每卷 = 一个神话/典故的【亲身经历版】
   ⇒ 不是"讲"典故，是"活在"典故里 ✅

② 主人公在虚拟世界里【身体不会受伤】
   ⇒ 所以他可以试错、可以冒险、可以死 ✅
   ⇒ 而死亡不是终结 —— 重来一次，就像游戏读档 ✅

③ 他能在历史节点做【不同的选择】
   ⇒ 而每一次选择都在【塑造他的灵魂】✅

④ 最终"烙进灵魂深处"
   ⇒ 这就是第十卷"前世轮回"的物理基础 ✅✅
```

---

## 二、⚠️ 必须先定的：「选择」能改历史吗？

| 方案 | 内容 | 优点 | 缺点 |
|---|---|---|---|
| 甲 · 完全不可改 | 无论怎么选，结局一样；但主角理解"为什么" | 最悲壮；史实零损伤 | 玩家挫败感 ⚠️ |
| **乙 · 局部可改** ⭐ | 改不了大历史，但能改【身边一个人的命运】 | 宏观史实 + 微观自由 ✅ | 需要精细的分层设计 |
| 丙 · 完全可改 | 平行历史 | 最自由 | 不再是历史小说 ⚠️ |

**⇒ 我推荐乙**

```
"他救不了一个朝代 —— 朝代照样会亡。
 但他救过一个人。
 而那个人，在正史里没有名字。"
```

**⇒ 而且"乙"让每一次选择都有重量**：
```
· 你改变不了"西晋会亡"，但你能决定
  【要不要把那个孩子带过江】
· 你改变不了"这个村子会被屠"，但你能决定
  【先救谁】
⇒ ⇒ 历史是铁的，人是活的 ✅✅
```

## 三、⭐ 十卷典故提案

### 卷1 · 起源（新石器 · 聚落）· 品质「勇」

| 候选 | 出处 | 与「勇」的契合 |
|---|---|---|
| **精卫填海** ⭐ | 《山海经·北山经》 | 炎帝之女溺于东海，化为鸟，**明知填不平，仍衔石不止** |
| 夸父逐日 | 《山海经·海外北经》 | 追日而死，弃杖化为邓林 |
| 女娲补天 | 《淮南子·览冥训》 | 炼五色石补天 |

**⇒ 我推荐【精卫填海】**
```
理由：
① "明知不可为而为之" = 勇的极致 ✅
② 她死过、化过形、仍然继续 —— 和"虚拟世界死了不真死"完全对应 ✅✅
③ 与第一章【姜勇河挖第一锹】直接呼应：
   精卫衔第一块石 = 姜勇河挖第一锹 ✅✅✅
④ 结尾可以打通："他后来才知道，
   在他们之前很久，有一个女孩也这么做过——
   她掉进海里，变成一只鸟，然后开始填海。"
```

### 卷2 · 三代（商 · 周）· 品质「礼」

| 候选 | 出处 |
|---|---|
| **周公制礼作乐** ⭐ | 《尚书》《史记·周本纪》 |
| 玄鸟生商 | 《诗经·商颂·玄鸟》 |
| 凤鸣岐山 | 《国语·周语》 |

**⇒ 推荐【周公制礼作乐】为主，玄鸟/凤凰为意象**
```
"礼"不是抽象概念，它是【一个人花了多少年，
 去规定别人怎么吃饭、怎么走路、怎么见父亲。"
```

### 卷3 · 帝国（秦 · 汉）· 品质「义」

| 候选 | 出处 |
|---|---|
| **荆轲刺秦** ⭐ | 《史记·刺客列传》 |
| 孟姜女哭长城 | 民间传说 |
| 霸王别姬 | 《史记·项羽本纪》 |

**⇒ 推荐【荆轲刺秦】**
```
"士为知己者死" —— 义的最纯形态 ✅
而且它发生在秦统一之后，正是卷三的时代 ✅
```

### 卷4 · 分裂（三国 · 两晋南北朝）· 品质「信」

| 候选 | 出处 |
|---|---|
| **竹林七贤** ⭐ | 《世说新语》《晋书》 |
| 梁祝 | 民间传说 |
| 木兰辞 | 《乐府诗集》 |
| 洛神赋 | 曹植 |

**⇒ 推荐【竹林七贤】**
```
时代特征：乱、篡、离散
主角品质：信（在人人背信的时代里，他守住了一句承诺）
⇒ 竹林七贤里，有人守住了，有人没守住
⇒ ⇒ 主角是【唯一一个到最后还没变的人】✅
```

### 卷5 · 盛世（隋 · 唐 · 五代）· 品质「仁」

| 候选 | 出处 |
|---|---|
| **玄奘取经** ⭐ | 《大唐西域记》《大慈恩寺三藏法师传》 |
| 白蛇传 | 民间传说 |
| 聂隐娘 | 《传奇》裴铏 |
| 长恨歌 | 白居易 |

**⇒ 推荐【玄奘取经】**
```
"仁" = 看得见人
⇒ 玄奘一路见到的，是【人】：盗匪、国王、病人、异教徒
⇒ 他带回的不是经，是【对人的理解】✅
⇒ 而且它天然是"游戏式的长途旅行" ✅✅
```


## 四、这套设计的六重收益

```
① 每卷有一个【读者熟悉的故事骨架】
   ⇒ 门槛低，好进入 ✅
② 但视角是"亲身经历"，不是"听说"
   ⇒ 熟悉的故事，陌生的体感 ✅✅
③ 主角可以【在不同节点做选择】
   ⇒ 而选择不改变大历史，只改变【一个人】✅
④ 每一次死亡与重来，都在【塑造灵魂】
   ⇒ 这是第十卷"前世轮回"的物理基础 ✅
⑤ 九个品质与九个典故一一对应
   ⇒ 品质不是标签，是【选择的结果】✅
⑥ 传统文化的振奋故事被"真的经历一遍"
   ⇒ 而不是被复述 ✅
```

## 五、⚠️ 需要一起定的三件事

```
① 「选择」能改历史的程度：甲 / 乙 / 丙
   （我推荐乙：改不了大历史，能改一个人的命运）

② 主角在典故里扮演什么角色？
   · 典故里的某个人（荆轲本人？精卫本人？）
   · 还是"外来者"，被卷进去的人？
   · 还是每次重来可以换身份？
   ⇒ 我倾向"外来者"—— 因为他是来经历的，不是来当英雄的

③ 「身体不会受伤」这个设定，在文本里怎么表现？
   · 他死了会怎样？（重来？还是继续看？）
   · 他知道自己不会死吗？（知道 / 不知道 / 慢慢发现）
   ⇒ 这决定整部书的【紧张感来源】
```
