## 怎么重跑

```bash
cd 01-内容/成书稿
python3 build-book.py
```

四步全部幂等：年表、16 章、引用索引、全书合成。**改了任何一稿或事件库，重跑即可同步，不要手改生成物。**

## 数据来源与规则

- 年表 ← `历史长卷/事件库/all.csv`（负数为公元前；传说/有争议已写在事件文本里）
- 各章 ← `历史长卷/朝代稿/<slug>.md`，自动剔除：开头三行内部版本说明、`## 附：给 ops 的更新对照`、`## 引用出处`（移到索引），并将争议说明段保留为章末「本朝争议」
- 章序号用中文数字；起止年取自各稿一级标题

## 口径（全书统一，改动前请确认）

1. 凡引用必有出处；金句必注篇名。
2. 争议一律「正文括注 + 章末本朝争议」双写，不回避、不裁定。
3. 不神化、不矮化；不出现当代政治（第十六章 1949 后只记文字/出版/教育/信息技术事实）。
4. 公元前写作「前 X」；传说纪年必标「传说」。
