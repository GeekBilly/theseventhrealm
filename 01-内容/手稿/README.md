## 三、文件命名规则

- **前置材料**排 `00–09`：`00` 故事梗概 / `01` 写作大纲 / `02` 人物 / `03` 世界观与设定 / `04` 背景 / `05` 其它
- **章节**从 `10` 起：`10`＝第一章、`11`＝第二章……`23`＝第十四章（材料与章节不会互相插队）
- 例：`06-机械义警/10-第一章-尘埃.md`、`06-机械义警/23-第十四章.md`
