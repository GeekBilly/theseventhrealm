## 四、验收口径

- 全身入画、白底单色、无文字水印、无现代器物
- 道具方向正确（弓弦在手内侧、枪尖朝外）
- 与人物锚点一致：发型、主道具、身份标志不能换
- 英雄／始祖类 8.5 头身以上；线条不超量（无密集排线、无碎笔），眉宇有英气而端凝
- 五官按漫画语法画（大眼、粗上眼线、简鼻线），无解剖式皱纹／眼袋；发型飘逸不显老
