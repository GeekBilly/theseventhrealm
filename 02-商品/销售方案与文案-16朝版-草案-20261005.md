## ✅ 措辞修订：「神兽」→「典籍与传说」（2026-10-05）

**用户指出**：「三国有洛神做底纹了，再用神兽就不合适了」

**核查**：确实不止洛神一处不合适 ——
```
三皇五帝 龙马 / 夏 灵龟 / 秦 黑龙 / 汉 白虎   → 神兽 ✅
商 玄鸟 / 周 凤凰                              → 神鸟（不是兽）
三国 洛神宓妃                                  → 神祇（不是兽）
两晋南北朝 白鹅                                → 文人典故（连"神"都不是）
```

**⇒ 不只是「兽」不准确，连「神」都不够。** 改用：

```
原文  每朝配一只神兽作底纹。
现文  每朝的底纹，都取自那一朝的典籍与传说。
```

**理由**：「典籍与传说」可涵盖神话传说（龙马/灵龟/玄鸟/凤凰/黑龙/白虎）、

且比"神兽"更有文化感，与全站调性一致。
