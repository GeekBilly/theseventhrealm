# B 线 · 姓氏视觉标识可行性（2026-10-02）

> **用户的问题**：百家姓有没有家族徽章之类的可识别标志，做类似朝代底纹的东西？
> **一句话答案**：**没有可用的现成徽章**（且最方便的那个是法律地雷），
> 但有一条**更安全、也更高级**的路 —— **族谱版式**。

---

## 一、结论速览

| 方向 | 能不能用 | 结论 |
|---|---|---|
| 欧洲式纹章 | — | ❌ **中国根本没有** —— 无纹章官、无个人世袭盾徽体系 |
| 🔴 **「百家姓图腾」（王大有）** | **绝对不能** | **已有侵权判例，2025 年判赔 40 万元永久授权** |
| 商周青铜器「族徽」 | ❌ 不可行 | 是**族氏铭文（文字）**，且**不能映射到今天姓氏**；素材需授权 |
| 堂号 / 郡望 | ⚠️ 受限 | 数据存在，但**上图开放数据仅授权非商业使用**；且"一姓一堂号"不成立 |
| **族谱版式语汇** | ✅✅ **最安全** | **版式规则与风格不受著作权保护，自绘即可** |
| 公版纹样母题 | ✅ | 饕餮/云雷/云气/缠枝 **母题**公版，但**必须自绘**，不能抠扫描件 |
| 仿汉印 | ✅ | 汉印母题公版 → **自刻或自绘** |

## 二、🔴 必须整条线避开的（已写进 `README-总原则.md` P1-4）

### 「百家姓图腾」

- 主流版本出自 **王大有**，2002 年起创作，2005 年出版《寻根万年中华》收录 **128 幅**（另一版 129 幅）
- **已做著作权登记**，法院多次认定具独创性

**判例**：

| 案件 | 结果 |
|---|---|
| **2025 山西临汾中院** | 景区擅用 **103 幅** → 支付 **40 万元**取得永久授权 + 署名 |
| (2008) 朝民初字第 12476 号 | 王大有 诉 出版社 |
| (2007) 二中民终字第 13723 号 | 同上 |
| 2008 西城法院 | 129 幅图腾案 |

> ⚠️ 「图腾是全人类共同成果、作者只是美化」的抗辩**未被采纳**。

**⇒ 禁止使用**：所有网络图包、姓氏图腾生成器、AI 仿制版、以及任何「参考其造型」的做法。

### 其他陷阱（摘要，完整 12 条见调研原文）

| 陷阱 | 说明 |
|---|---|
| AI 生成的"姓氏图腾" | 简单提示词输出**不构成作品**（苏州/张家港案），既拿不到权利又可能撞现有作品 |
| 商业字库 | 方正五款（黑体/书宋/仿宋/楷体/甲骨文）免费发布使用；**其余须付费** |
| 故宫/国图/上博官网图片 | 三家声明均要求书面许可，国图与上博**明确禁止商用** |
| 台北故宫 OpenData、中研院数据库 | 条款未核实，且**按地区限制访问** |
| 日本家纹 / Wikimedia CC BY-SA | 图案公版但文件受"署名+相同方式共享"约束，**付费商品不宜** |
| 古籍影印本/点校本 | 专有出版权 + 版式设计权（《殷周金文集成》等） |
| 名人题字、现代书法 | 多在保护期内 |

## 三、✅ 可以走的路：**族谱版式**（建议作为溢价档的视觉标识）

### 为什么它正好合适

| | 朝代线的做法 | **姓氏线可以对应做** |
|---|---|---|
| 溢价开关 | 具象底纹（玄鸟/凤凰） | **族谱版式**（朱丝栏 / 版框 / 鱼尾 / 书口） |

**关键理由**：**版式规则与风格不受著作权保护** —— 自绘最安全，且比"图腾"高级得多。

### 具体元素（全部自绘）

| 元素 | 说明 | 可用于 |
|---|---|---|
| **朱丝栏** | 红色竖格线，古籍写经与族谱常用 | 底纹 |
| **版框 / 四周双边** | 书页外框 | 版心 |
| **鱼尾 / 书口** | 版心处的鱼尾标记 | 中缝 |
| **世系表格** | 族谱的世代排列格式 | 底纹（淡） |
| **仿汉印** | 自刻或自绘 | 姓氏印记（替代统一印章） |
| **郡望 / 谱籍地理** | 地名是**事实信息**，可自由使用；地图自绘 | 小字标注 |

### 郡望数据的来源注意

- ❌ **不要**用上图开放数据（**仅授权非商业使用**，付费商品须另行书面许可）
- ❌ **不要**用国图资源（禁止商用）
- ❌ **不要**用网络"堂号大全"（有汇编权利）
- ✅ **可以**用**公版古籍原文**：《元和姓纂》《通志·氏族略》
- ⚠️ 但要避开**现代点校本/影印本**（有专有出版权）

> ⚠️ **「一姓一堂号/郡望」不成立**：大姓常多堂号多郡望，小姓常无。
> 所以**郡望不能作为所有姓氏的标配** —— 只能作为**可选的高级项**（如 B-4 定制档）。

原来的分档只有"数量和定制"两个维度。**现在有了第三个：版式层级**。

| 档 | 视觉 | 依据 |
|---|---|---|
| **B-1/B-2 基础档** | 宣纸白 + 毛笔主字 + 印章（现状） | 已有 ✅ |
| **B-3 全量档** | 同上 | 已有 ✅ |
| ⭐ **B-4 定制档（¥199）** | **+ 族谱版式**（朱丝栏/版框/仿汉印）**+ 郡望小字** | **本方案** |

> **好处**：B-4 不再只是"贵"，而是**看得出贵** —— 这正是分档定价能立住的前提。
