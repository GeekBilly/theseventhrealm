## 三、已核证的出处底稿（可引）

1. ⭐ **河图洛书**：先秦《易·系辞上》只有「河出图，洛出书，圣人则之」，**没有龙马神龟**；
   「龙马负图／神龟负书」首见于**西汉孔安国《尚书》传**——
   「伏羲王天下，龙马出河，遂则其文以画八卦，谓之河图」、
   「天与禹洛出书，神龟负文而出，列于背，有数至于九」。
   《汉书·五行志》引刘歆：「虑戏氏继天而王，受河图，则而画之，八卦是也；禹治洪水，赐洛书，
   法而陈之，洪范是也。」
   ⇒ **伏羲＝河图＝龙马；禹＝洛书＝神龟**。属汉代定型的传说层，非先秦信史。
2. 《史记·封禅书》：「黄帝采首山铜，铸鼎于荆山下。鼎既成，有龙垂胡髯下迎黄帝……故后世因名
   其处曰鼎湖，其弓曰乌号。」 ⇒ 成语「龙去鼎湖」指**帝王去世**，作壁纸寓意偏丧，**不用**。
3. 《尚书·洪范》原文：「鲧则殛死，禹乃嗣兴，**天乃锡禹洪范九畴**，彝伦攸叙。」
4. 《楚辞·天问》「应龙何画？河海何历？」王逸注：「或曰禹治洪水时，有神龙以尾画地，导水所注
   当决者，因而治之也。」洪兴祖补注引《山海经图》：「夏禹治水，有应龙以尾画地。」
5. 《拾遗记》卷二：「禹尽力沟洫，导川夷岳，**黄龙曳尾于前，玄龟负青泥于后**。」
6. 夏之九鼎：《左传·宣公三年》「昔夏之方有德也，远方图物，贡金九牧，铸鼎象物，百物而为之备，
   使民知神奸」；《史记·封禅书》「禹收九牧之金，铸九鼎」。（器物，非瑞兽）

🔴 **结论（关键，勿再重复试参数）**：龙马/灵龟**在字区比商周更留白**（9% vs 26–31%），
所以「压字」不是字区浓度问题；真正的差距是**全幅墨韵**——商周的通幅感来自**主体自身的
大写意飞白笔触**（玄鸟翅膀、凤凰尾羽本身就是大片淡墨），而雾模式只把「生图自带的那一团云」
压淡复用（局部），加上龙马/灵龟是**实心填充**式笔触、不铺展 ⇒ **视觉上像「白纸上贴了一匹马」**。

⇒ 这个差距**合成参数改不动**（`haze` 再大也只加深原图那一团云；平铺路线已因矩形贴片伪影
于 2026-10-04 否决，**不重试**）。可走的三条路：
1. **接受现状**（若定位「淡雅一兽」即定稿，接版式即可上架）；
2. **主体上移**（`--ay=0.31` 已出候选 `_cand-longma-B.png`/`_cand-linggui-B.png`，位置改善有限）；
3. **重生生图**（提示词加「大写意、枯笔飞白、通幅墨韵晕染」，成本 5–10 分/张，需用户定方向）。

⚠️ 候选件命名一贯用 `_cand-<slug>-<档>.png` 前缀，**不是上架件**，验收后要么转正要么删。

## 六、⭐⭐ 不裁头的几何约束（2026-10-04 定，**后 12 朝照抄这条**）

🔴 **先记住这个坑**：模板 `.texture{object-fit:cover}` 把底纹 1536×1024 拉到 1920×1280 后
**居中裁掉上下各 100px** ⇒ 成品里**可见的只是原图 y∈[80, 944]**。
2026-10-04 前四版（含 D 档）**全部静默裁掉了主体顶部**（D 档三皇五帝切掉身高约 120px），
因为 `place()` 里的 ax/ay 是**墨迹质心**比例，肉眼所见位置与它不等价 —— 别靠感觉调。

**反解公式**（已知 scale S，让主体顶端贴安全线、右端贴右边界）：
```
TOP=95（可见区上界 80 + 余量 15）   RIGHT=1526   H=1024  W=1536
ay ≥ (TOP + (ȳ − ymin)·S) / H          # ȳ/ymin 取 build_key() 抠出的主体 mask
ax = (RIGHT − (xmax − x̄)·S) / W
```
**验收办法**（不用看图）：对成品 1920×1080 截图取**顶部 24px 带、x>900** 区域，
统计 `灰度<240` 的占比 —— **>0 就是被切了**。实测：D 档 46.98%（三皇五帝）/18.52%（夏），
F、G 档 **0.00%**。

| 档 | scale | longma ax/ay | linggui ax/ay | 占位 | 状态 |
|---|---|---|---|---|---|
| D | 0.85 | 0.750 / 0.270 | 0.750 / 0.270 | 右上约半幅 | ❌ 裁头 99/116px（备份在 `底纹/_D版备份-20261004/`） |
| F | 1.20 | 0.614 / 0.501 | 0.684 / 0.524 | longma x[28,99]% y[10,99]% | 备选（更满） |
| G | 1.28 | 0.588 / 0.528 | 0.663 / 0.553 | 更满，底部溢出 134px | 备选 |
| ⭐**H** | **0.85** | **0.750 / 0.3965** | **0.750 / 0.4131** | longma x[51,100]% y[11,75]%｜linggui x[53,97]% y[11,69]% | ✅ **用户定稿**（D 版大小下移露头，2026-10-04） |

⭐ **H 档＝用户定稿**：就是在 D 版的 **S0.85 + 横向 75% 不动**的前提下，只把 ay 从 0.27 抬到
0.3965/0.4131 ⇒ 主体整体下移 129/146px（原图）／162/183px（成品），头完整露出。
`gen-texture-full.py` 的 `TEX` 默认值已改定稿值（重跑即得 `longma-full.png`/`linggui-full.png`），
`.texture` 文件名不变 ⇒ `gen-evolution.py` 无需改动。
✅ 落位背书（几何，非目视）：主体下缘 y=75%/69% → 成品 y≈860/776，**未压到品牌行（y≈940）**；
主体左边界 51%/53% → 成品 x≈979/1018，**未压到左下落款（x≈210）**。

⚠️ `scale>1` 会把 raw 放大到 1536×1024 之上（轻微软化可接受）；左下品牌/±落款区要留意别被
主体压住 —— 商周的玄鸟本来也压到品牌行上方，属既定风格，但**每期必须过一次目视验收**。

⚠️ **摩羯为什么要降到 S0.60**：它生图的主体几乎满幅（墨量 41%、云仅 22%、主体占宽 85%），
套 S0.85 会压到画面中央、吃掉字区；降到 0.60 才与另两朝同档。
⇒ **判据**：合成前先看 `build_key()` 报的「墨量/云雾占比」，>35% 墨量的图要先降 scale。

⚠️⭐ **`haze` 调不动字区浓度**（2026-10-05 实测，别再白试）：
haze 只调制**云雾底**，字区墨量由**生图主体自身的墨量**决定。实测 baie `haze 0.13→0.24`
字区墨只从 12.5%→13.1%；mojie `0.13→0.08` 干脆 **37.9%→37.9%**（一字不差）。
⇒ 字区太浓/太淡只能靠 **scale（改主体大小）或重生图**，调 haze 是无效功。

### 11.2 🔴 本批踩的坑：raw 的云雾与兽体粘连 ⇒ 雾模式抠图必留硬边

`mode='雾'` 的标准流程是「抠主体（含脚边云）→ 缩放 → 质心锚定叠回」。本批三张 **raw 的云雾
比九朝浓得多**（体积墨 **35–40%** vs 九朝 ~12%），于是：

   **三张全部裁头 100–140px**（第一版成品狮/鹤/麟上半身都没了）。
2. 加兽体窗口（`WINDOW`，见下）修正落位后，成品的**云脚边界出现 1px 硬线**
   （实测 y=701 处灰度 207→242 直接跳变）。羽化 σ3、σ12 都救不回 —— 因为边界外是白纸、
   `(252−L)/30` 天然为 0，乘任何窗函数还是 0。

### 11.3 ✅ 解法：新增 `mode='原位'`（原位减云，**不缩放/不位移/不抠图**）

```
cv = 255 − (255−L)·k                      # 云与纸整体压淡到 k
w  = clip((ink−L)/span) × smooth(mm, 20)  # 「墨够浓」×「与主体相连」
cv = cv·(1−w) + L·w                        # 主体处恢复原浓度
```

- ① `clip((ink−L)/span)`：只有墨够浓才保留 ⇒ 淡云一律走压淡；
- ② `smooth(mm, 20)`：**孤立云团不保留** —— 少了这一项，云团里最浓的几坨（L<135）
  会被当"浓墨"留下来，在画面正中形成一坨黑云压住文字区（实测贡狮/麒麟都有）；
- ③ 用**平滑** mask 而非硬 mask ⇒ 边界不会出现硬线（这是本方案成立的关键）。

⚠️ 代价：主体位置＝生图原始位置 ⇒ **成品上下取景改由 `gen-evolution.py` 的 `tex_pos`
（object-position）承担**，与商周 §九 同一手法。

### 12.4 ✅ 解法：给「原位」加几何步 `zoom` / `shift`

```python
def zoom_shift(cv, zoom=1.0, shift=0.0):
```
